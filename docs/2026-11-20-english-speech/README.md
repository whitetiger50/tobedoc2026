# 영어 구어체 발화에서 같은 대상을 다시 가리키는 표현

**2026년 11월 20일 실행 설계.** 11월 27일 금요일까지 포스터와 재현 자료 완성을 목표로 한다. 이번 단계에서 영어 발화 생성과 연구 판독은 각각 0건이다. 발화기와 두 판독기 모두 LLM을 사용한다.

**연구 질문** — 같은 사건을 영어로 말하게 했을 때, 자신의 생각에 잠시 주의가 이동하는 조건(F)에서 주변 자극에 잠시 주의가 이동하는 조건(D)보다, 앞서 말한 대상을 `the` 명사구로 다시 가리키는 횟수가 발화 100단어당 적어지는가?

예를 들어 *I found a parcel. The parcel was wet.*에서는 같은 소포를 두 번 언급했다. *I entered a shop. The counter was wet.*에서는 가게라는 말로 계산대를 짐작할 수 있지만 화자가 앞서 계산대를 언급한 적은 없다. 두 예문을 생성기에 주지 않는다.

## 임상 문헌에서 가져온 관찰

Çokal 등의 영어 연구에서 조현병이 있고 중등도 이상 형식적 사고장애(FTD)가 있는 15명, FTD가 미미하거나 없는 15명, 신경전형 대조군 15명이 만화를 설명했다. 기존 수기 주석 자료를 LLM으로 재분석했을 때에도 FTD가 뚜렷한 집단에서 앞선 담화에 연결되는 한정 명사구 사용이 적었다. 출판본 §2.4–2.6에서 Llama 3.1 Instruct 70B의 문맥 내 예시 판독, 최종 프롬프트에 포함된 예시 16개, 각 명사구 유형의 수를 전체 명사구 수로 나눈 집단 분석을 확인했다. 원 연구에는 수기 준거가 있었다. 보충 S2의 개별 프롬프트 전체와 환자별 전사는 이번에 열람하지 않았다. [출판본](https://www.sciencedirect.com/science/article/pii/S002839322600151X/pdf) · [저자 소속 대학의 초록 및 자료 접근 설명](https://eprints.ncl.ac.uk/312340)

여기서 가져온 것은 **측정할 언어 현상과 가설의 방향**이다. 과제는 저작한 사건 카드의 1인칭 구술이고, 산출물은 영어 구어체 텍스트다. 환자군 간 차이가 한 모델 안에서 프롬프트를 바꿀 때도 나타나는지는 새 가설이다. 우리 지표는 문자 그대로의 `the`로 시작하는 표현에 한정하고 발화 단어 수로 정규화한다. 원 논문의 집단 평균이나 효과크기를 이 값과 비교하지 않는다. 영어는 연구자가 선택한 언어다. 이번 설계에는 언어 간 성능 비교나 음성학적 측정이 없다.

이전 자료에서는 자연 합성 원문 9개를 여러 번 읽어도 판독 모델과 기준 조합별 유효 총점이 모두 같았다. 그래서 평가 대상을 개별 표현으로 좁히고 원문 근거, 오판 사례, 미판정 건수를 남긴다. 과거의 한국어 글쓰기 과제·사람 코딩 계획과 당시의 독립 비평은 별도로 보존한다. [10–11월 원응답 재검산](../2026-11-20-korean-writing/REASSESSMENT.md) · [이전 설계](../2026-11-20-korean-writing/README.md)

## 생성과 눈가림

기존 구독의 GPT-6.1 Sol 한 모델에 **8개 일상 사건 × 4조건 × 새 문맥 2회 = 64개 영어 발화**를 계획한다. 각 사건에는 이름 있는 두 사람, 구별되는 두 사물, 사물이 다시 등장하는 사건과 주변 자극을 둔다. 동일 카드의 질문·사건·응답 형식은 네 조건에서 같다. 공통 면담 질문은 *Could you tell me what happened during your visit, from arriving to leaving?*이다. 생성기는 표적 표현·채점 규칙·목표 방향을 모른다. 도구와 대화 이력이 없는 새 세션에서 1인칭 답변 한 편을 받는다. 모델 요청 식별자, 확인 가능한 응답 모델명, 시각, 원응답 및 프롬프트 해시를 저장한다. [고정 카드·문구·순서](protocol.py)

| 조건 | 사건을 말하는 방식 | 분석 목적 |
|---|---|---|
| F | 머릿속 생각에 잠시 주의와 말이 옮겨갔다가 돌아온다 | 주대비의 내부 단서 |
| D | 사건 현장의 외부 자극 때문에 잠시 화제가 옮겨갔다가 돌아온다 | 같은 전환·복귀를 요구하는 능동 대조 |
| N | 평상시처럼 사건을 설명한다 | 두 조건과 기본 말투의 차이 |
| L | N의 문구에 조현병 진단 이력 한 문장만 추가한다 | 진단명만으로 생기는 변화 |

F와 D의 차이는 고정한 두 문구의 효과로 다룬다. L−N은 부차적 대비로 별도 보고한다. L의 결과만으로 F−D의 원인까지 정할 수 없다. 반복은 동일 모델의 생성 변동을 보며 사례 수는 8개다.

## 전면 LLM 판독

주판독기는 생성기와 계열이 다른 Claude Opus 5.5, 보조 판독기는 새 문맥의 GPT-6.1 Sol로 고정한다. 후자는 생성기와 계열이 같다. 두 모델은 서로의 답변과 앞선 판독을 볼 수 없다. 출력에 조건 단서가 드러날 수 있으므로 눈가림은 입력 메타데이터에 관한 것이다. 사람은 생성물 채점·합의·분쟁 조정에 참여하지 않는다.

1. 코드는 발화에서 독립 단어 `the`를 대소문자 구분 없이 전부 찾아 시작·끝 위치와 후보 ID를 부여한다. 판독기에 발화, 후보 목록, 그 발화에서 기계적으로 추출한 단어·문장부호 위치표를 전달한다. 카드, 진단 조건, 생성 순서 및 사례 키는 가린다.
2. 판독기는 각 후보를 **LINKED**(같은 대상의 앞선 명시적 언급), **UNLINKED**(선행 언급 없음, 연상·상식으로만 추론하는 경우 포함), **UNCERTAIN**(어느 대상을 뜻하는지 모호함), **NOT_NP**(예: *the more*)로 분류한다. 표적 구간을 정확히 인용하고 LINKED에는 선행 구간도 인용한다. 여러 선행 언급이 가능하면 동일 대상을 가리키는 명시적 표현 하나면 충분하다.
3. 코드는 후보 누락·중복, 인용 불일치, 범위를 벗어난 위치, 표적보다 뒤에 나오는 선행사를 거른다. 이 검사는 의미상 같은 대상인지를 보증하지 않는다. 오류가 있는 한 판독 전체는 결측이다. 부적격 생성(빈 응답·거절·전송 중단)은 별도로 집계한다. 온전한 발화에 후보가 하나도 없으면 100단어당 LINKED는 0이고, 후보를 분모로 한 비율은 정의되지 않는다.
4. 실행 전 두 모델이 **작성된 비임상 예제 8편**을 각각 한 번 읽는다. 키는 숨긴다. 운영 기준은 각각 8편 모두 구조 통과, 후보 8개 중 7개 이상 분류 일치, LINKED 3개 중 3개에서 맞는 대상을 지시하는 사전 허용 선행 구간 적중이다. 허용값은 `linked`에서 *a blue folder*, `pronoun`에서 *a blue folder* 또는 *it*, `negative_action`에서 *a yellow box*이며, 수식어 또는 관사를 생략한 같은 명사 핵의 정확 구간도 허용한다. 대소문자와 원문 위치는 검증한다. 작은 작성 예제에서의 통과율은 자연 원문에서의 정확도 추정치로 쓰지 않는다.
5. 본 판독 후 각 모델은 미리 선택한 16개 발화를 새 세션에서 1회 재판독한다. 각 카드에서 첫 반복의 두 조건을 선택하며 홀수 카드는 F·N, 짝수 카드는 D·L을 사용한다. 조건별 4편이다. 후보별 4×4 교차표, LINKED 양성 일치율 `2a/(2a+b+c)`, 선행 인용 구간의 일치, 같은 모델 재판독 결과 및 결측을 공개한다. 두 모델의 표를 따로 유지하고 사람 중재·모델 다수결·사후 프롬프트 조정을 하지 않는다.

## 분석과 해석 기준

**주지표**는 유효 발화 하나의 `100 × LINKED 수 / 영어 발화 단어 수`다. 단어화 규칙은 코드에 고정했다. 각 판독기별로 카드·조건 안에서 두 생성의 지표를 평균하고, 카드별 F−D를 구한 뒤 8개 카드에 같은 가중치를 준다. 8개 차이 전체, 평균, 한 장씩 제외한 평균 범위를 함께 보고한다. 생성 반복이나 후보 단어를 독립 표본으로 간주하지 않는다. 조건별 길이·유효 표본 수·결측 원인을 함께 싣는다.

**기회와 선택을 구분하는 보조지표**는 ① 발화당 전체 `the` 수와 유효 명사구 수, ② `LINKED/(LINKED+UNLINKED)`, ③ UNCERTAIN을 모두 양성 또는 음성으로 놓은 비율 범위, ④ 미리 고정한 인물 이름과 사물 명칭의 문자상 반복 횟수다. ④는 각 명칭의 첫 출현 이후 횟수의 합이다. 대명사·동의어로 다시 부르는 경우를 놓칠 수 있고, 같은 단어의 뜻이 달라질 수도 있다. 이 반복 수와 ②의 분모는 서로 다른 관찰값이다.

| 관찰 결과 | 포스터의 결론 |
|---|---|
| 두 모델이 예제를 통과하고 8개 카드의 F·D 두 반복을 모두 판독. 두 모델의 평균 F−D가 음수이고 한 장씩 제외해도 같은 방향 | 이 카드와 생성기에서 F 지시가 앞선 대상을 `the`로 재지칭한 빈도를 낮췄다고 보고한다. 실제 감소량·카드별 분산·두 판독기 일치도를 제시한다. |
| 자연 원문의 LINKED 양성 일치율 <0.70 또는 분모가 0, 두 판독기의 방향이 다름, 불완전한 카드, 특정 카드 제외 시 방향 변경 | 두 모델의 판독 결과와 가용한 대응 사례 수를 기술하고 판독 신뢰도·사례 의존성 또는 결측의 영향으로 표시한다. |
| F와 D 사이에 재언급 기회가 다르거나 ②에서는 차이가 사라짐 | 화제·인물 선택이나 표현 기회의 변화와 구별하기 어렵다. 조건별 노출·명칭 반복·조건부 비율을 주로 제시하고 100단어당 차이는 관찰값으로 남긴다. |
| 무차이·반대 방향 또는 교정 미통과 | 관찰된 차이와 불확실성을 그대로 제시한다. 두 판독기 중 하나라도 교정 기준에 미달하면 새 본판독을 중단하고 교정 실패 유형과 검산된 기존 결과로 방법론 포스터를 완성한다. |

기회 점검은 카드별 F·D 두 반복의 평균 명칭 반복 수로 비율을 구한다. 8개 카드 모두 분모가 양수이고 그 비율의 중앙값이 0.8–1.25 범위에 들어야 기회가 대체로 비슷한 경우로 분류한다. 분모가 0이거나 범위를 벗어나면 세 번째 행을 적용한다. 이 범위와 판독 일치율 0.70은 포스터에서 해석을 제한하기 위해 정한 운영 기준이다. 8개 사건·한 생성기로 조현병 표현형의 임상 충실도나 실제 환자의 지시대상 추적 능력을 추정할 수 없다.

**후속 독립 검토.** 언어·과제와 판독 방식이 함께 바뀌어 공식 Claude 구독으로 Opus 5.5의 새 문맥에서 방법론 비평을 한 차례 받았다. 검토자는 “화제가 바뀌어 대상의 재등장 자체가 줄어도 주지표가 낮아진다”는 대안 설명을 제시했다. 이에 카드별 고정 명칭의 반복 횟수와 위의 기회 불균형 기준을 추가했다. L−N의 변화가 F−D의 기전을 결정한다는 제안은 채택하지 않았다. 두 대비는 별도이고 F·D에는 진단명 입력이 없다. 앞선 한국어 설계를 비평한 1회와 합해 총 2회다. 후속 실제 응답 SHA-256은 `aea18d674236858f9c3061fed543a365343e756844d89050520f15c7d72c2746`이다.

```bash
python3 -B protocol.py self-check
python3 -B protocol.py schedule
python3 -B protocol.py generation-prompt C01-F-r1
python3 -B protocol.py challenges
python3 -B protocol.py check-calibration reader_calibration_directory
python3 -B protocol.py judge-prompt answer.txt
python3 -B protocol.py validate answer.txt rating.json
python3 -B protocol.py entity-repeats C01 answer.txt
```

위 명령은 이 폴더에서 실행한다. `answer.txt`와 `rating.json`은 향후 실행에서 저장할 실제 모델 응답이다. `challenges --include-keys`는 로컬 채점용이며 판독기 입력에는 사용하지 않는다. `self-check`는 작성된 기대값으로 로컬 검사를 실행한다. 교정 때는 예제별 발화만 judge-prompt에 넣고 파일명이나 예제 키를 가린다. 한 판독기의 원응답을 로컬에 <예제명>.json으로 모으면 check-calibration이 사전 기준으로 집계한다. 실제 LLM의 판독 성능은 첫 교정에서 측정한다.
