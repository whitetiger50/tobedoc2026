# 영어 모의 면담에서 발화기가 담화 와해와 내용 빈곤을 구별해 표현하는가?

**11월 27일 포스터 설계 · 2026년 11월 20일 고정안.** 이번 주 연구 대상은 영어로 말하는 가상 면담자와 화자의 텍스트다. 판독은 전부 LLM이 맡는다. 이후 영어 임상 발화를 평가할 수 있는 정신건강의학과 전문의가 같은 원문·질문·판독표로 독립 판독할 수 있게 준비했다. 신규 연구 발화, 실측 LLM 판독, 전문의 판독은 설계 시점에 모두 0건이다.

**질문.** 동일한 사례·질문·기반 모델에서 이미 개발한 발화 모듈의 영어 출력판은 간소화한 역할 지시보다, 대화 성향에 따라 **발화 내 탈선**과 **발화 내용 빈곤**을 각각 구별해 표현하는가? 임상적으로 설득력 있는 재현을 판단하려면 이후 전문의 검증과 동일 과제의 독립 임상 준거가 필요하다. 포스터는 합성 발화에서 두 특징의 선택적 조절과 판독 가능성을 검토하는 파일럿이다.

## 항목을 선택한 근거

| 판독 항목 | 한 발화에서 판정할 사건 | 경계·원저 |
|---|---|---|
| **공동 주지표 1 · 발화 내 탈선** (*derailment*) | 화자의 한 답 안에서 앞뒤 생각을 잇는 관계가 현저히 약해져 흐름을 따라가기 어렵다. 양쪽 구절과 전환 위치를 제시한다. | 이유를 설명한 연상·자연스러운 곁가지·면담자의 질문 전환을 가려낸다. TLC의 탈선 정의를 따른다. TLI의 *looseness*는 더 넓으며 질문과의 관련성도 포함할 수 있다. [Andreasen, 1986](https://doi.org/10.1093/schbul/12.3.473) · [Liddle 등, 2002](https://doi.org/10.1192/bjp.181.4.326) |
| **공동 주지표 2 · 발화 내용 빈곤** (*poverty of content of speech*) | 말은 이어지는데도 일반론이나 순환적 표현이 많아, 청자가 얻는 구체적인 정보가 적다. 무엇이 얼마나 전개됐는지를 원문에서 확인한다. | 짧고 정확한 답, 비공개 의사, 구체적이지만 엉뚱한 답, 카드 속 사실 누락과 구별한다. 짧아 판단 기회가 부족하면 별도 표시한다. TLC의 내용 빈곤이 직접 근거이며, TLI의 *weakening of goal*은 아이디어 전개 빈곤에 인접한 항목이다. [TLC 정의](https://doi.org/10.1093/schbul/12.3.473) · [TLI 원저·부록](https://doi.org/10.1192/bjp.181.4.326) |
| **보조 1 · 질문 초점 이탈** (*tangentiality*) | 답변 안의 이야기는 이해할 수 있어도 질문이 요청한 내용에 끝내 도달하지 않는다. 놓친 질문 초점을 명시한다. | 우회한 뒤 답을 주면 그것만으로 양성 처리하지 않는다. 명시적 거절과 구분한다. [TLC 원저](https://doi.org/10.1093/schbul/12.3.473) |
| **보조 2 · 의미 이해를 방해하는 지시 실패** (*unclear reference*) | 대상을 둘 이상으로 해석할 수 있거나 필요한 대상이 앞 문맥에 없어 청자가 발언의 뜻을 결정하기 어렵다. | 정상적인 대명사·상황 추론을 허용한다. CDI의 *confused reference*, *missing-information reference*를 참고한 통합 항목이다. 두 유형의 원척도 점수나 CDI 총점을 계산하지 않는다. [Docherty 등, 2006](https://doi.org/10.1176/ajp.2006.163.12.2111) |

**근거의 강도.** Liddle 등은 조현병 환자 87명의 TLI 점수를 요인분석했고, 와해와 빈곤은 서로 구별되는 요인으로 나타났다. 원 연구의 평가자 간 ICC는 개별 *looseness* .79, *weakening of goal* .74, 두 하위척도 .82와 .88이었다. 8개 그림에 각 1분씩 발화하고 추가 질문도 한 과제였으며, 신뢰도는 훈련받은 평가자 5명이 전사 25건을 판독해 구했다. 이 수치는 이번 영어 모의 면담 판독표의 신뢰도 추정치가 아니다. Andreasen과 Grove의 94명 대조군·100명 환자 비교에는 조증 등 여러 진단군도 포함됐다. 두 특징의 출현은 진단 특이성을 보장하지 않는다. [TLI 전문, 표 1·부록](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/FEFB9ADC871CDFE528B4B87F99A4F054/S0007125000027598a.pdf/thought-and-language-index-an-instrument-for-assessing-thought-and-language-in-schizophrenia.pdf) · [Andreasen & Grove, 1986, 초록](https://doi.org/10.1093/schbul/12.3.348)

앞선 안의 ‘선행사가 있는 `the` 명사구/100단어’는 이번 채점에서 제외한다. 환자 연구는 영어 만화 설명에서 명사구 분포를 비교했고, 해당 대리지표를 임상 충실도 점수로 검증하지 않았다. 환청·망상 내용은 이번 조작에 포함하지 않는다. 말속도·침묵·정동은 텍스트 두 턴에서 판정할 정보가 없다. [Çokal 등, 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC6145886/) · [Çokal 등, 2026](https://doi.org/10.1016/j.neuropsychologia.2026.109505) · [이전 설계와 코드](../2026-11-20-english-speech/README.md)

## 생성 설계

- **6개 새 가상 사건 × 3개 의사소통 성향 × 2개 발화기 조건 × 2턴 = 36개 면담, 72개 답변.** 각 사건에는 화자가 알고 있고 말할 수 있는 사실 4개와 공개하기 부담스럽지 않은 경험이 있다. 진단명·목표 단어·참고 답변을 제공하지 않는다. 1턴은 사건 전체를 말하는 개방형 질문, 2턴은 사건의 한 문제와 해결 과정을 묻는 개방형 후속 질문이다. 특정 사실의 정확한 회상 자체를 임상 점수로 쓰지 않는다. [사례·질문·순서](study.py)
- **성향 조작**은 평소 서술, 연상으로 주의가 옮겨가는 성향, 사건을 전반적 인상 수준에서 말하는 성향이다. 동일 사건의 사실·가드·자발성 입력은 고정하고 각각 조직성 또는 표현 필드 하나만 바꾼다. 임상 항목명·평정 기준·모범 발화는 감춘다. 입력이 겨냥한 성향을 출력에서 찾으므로 주된 추론은 발화의 *조절 가능성*이다. 이 문구가 실제 환자의 증상 기전을 구현한다는 가정은 두지 않는다.
- **개발판과 대조군**은 같은 기반 모델 GPT-6.1 Sol과 같은 영어 사례·질문 형식을 쓴다. 개발 당시 선택된 v0.2는 시스템 문구에 한국어 출력이 명시돼 있어 그 한 문구만 영어 출력으로 교체한다. 나머지 시스템 지시는 한국어다. 대조군에는 같은 v0.2의 역할·사실·성향·이력 준수에 필요한 최소 지시를 유지하고 세부 발화 지시를 덜어낸다. 추정 대상은 **이 추가 지시 묶음 전체**다. v0.2 원문 해시는 `721203cb5a1ece9c3f93dfb1fb3ed172fc734439a6ed89a7e47f86ab2bf9e269`다. 과거 CLI 기본 v0.4와 구별한다. [동결 원본 검증·영어 입력 조립](generation.py)
- 면담별로 다른 세션을 사용하고, 두 번째 요청에는 해당 면담의 첫 질문·실제 첫 답변만 넘긴다. 2턴 비교에는 앞선 답변을 통한 영향도 포함된다. 각 셀은 1회 생성이므로 실행 간 생성 변동은 별도 추정할 수 없다. 생성 원문·입력 해시·모델 요청 및 확인 가능한 모델 버전·설정·종료 사유를 보존한다. 조건별 결과가 잘 나올 때까지 재생성하지 않는다. 응답 누락·전송 중단·불완전 이력은 해당 단계 결측으로 기록한다. 정상 수신한 거절·짧은 답은 그대로 판독한다.

## 포스터와 전문의가 공유하는 영문 판독표

같은 [영문 판독표](RATING_FORM.md)를 주판독 Claude Opus 5.5와 보조 판독 GPT-6.1 Sol이 각각 새 문맥에서 사용한다. GPT는 생성기와 같은 계열이다. 전문의도 이후 같은 질문·원문·선행 문답을 받는다. 화면에는 현재 질문·답과 필요할 때 직전 문답만 보인다. 사례 사실표·성향·발화기 버전·생성 프롬프트·이전 판정은 가린다. 역할·언어가 출력에서 추측될 가능성은 남는다. 판독자는 현재 답변만 평가한다.

네 항목에 각각 **present / absent / uncertain / not_assessable**을 기록한다. 가능한 사건이 있으나 여러 해석이 남으면 uncertain, 텍스트가 너무 짧거나 필요한 맥락 자체가 없으면 not_assessable이다. 모든 항목에 짧은 이유, 양성·불확실에는 현 답변의 직접 인용, 탈선 양성에는 순서대로 두 구절을 적는다. 종이 양식에는 직접 표시할 수 있고 인용이 반복되면 어느 위치인지 구별한다. 형식·정확 인용을 프로그램으로 확인한다. 양성 점수를 합한 ‘조현병 재현 점수’는 정의하지 않는다. [판독 프롬프트·양식 검증](reader.py)

**판독기 교정이 첫 실험이다.** 저작한 비임상 예제 12개에서 단순히 짧은 답, 이유가 설명된 주제 이동, 서술은 구체적이나 질문에서 벗어난 답 등을 대비한다. 예제 키를 숨기고 두 모델이 각각 12개를 읽는다. 각 모델은 12개 양식을 완전하게 제출하고, **두 주지표 각각** 명확한 양성 3/3, 명확한 음성 7/8 이상을 맞혀야 본배치에 진입한다. 남은 각 1개는 평가 기회 부족이다. 인용이 원문에 있는지 검사할 수 있지만 교정 키는 전문가 정답이 아니다. 보조지표의 분류표도 보고하되 작은 예제에서 임상 정확도를 추정하지 않는다. 어느 모델이든 기준에 미달하면 실패 위치와 기존에 검산한 판독 병목을 포스터에 보고한다. 기준 변경 후 같은 자료를 확증 결과로 사용하지 않는다. [기존 연구의 상수 점수와 결측](../2026-11-20-korean-writing/REASSESSMENT.md)

## 주분석과 결과 해석

각 판독기·항목별로 6개 조건 셀의 **있음/없음/불확실/평가 불가/결측 건수**, 판정 가능 발화 중 양성 비율, 단어 수를 먼저 표시한다. 같은 면담의 두 답과 같은 줄거리의 여러 버전은 관련된 관측이다. 효과의 비교 단위는 **사례 6개**다. 별도로 1·2턴 결과를 나란히 확인해 질문·이력의 영향을 설명한다.

| 공동 주지표 | 사례별 사전 대비 |
|---|---|
| 탈선 | 각 발화기에서 연상형과 평소형의 양성 여부 차이를 구하고, 개발판 차이에서 간소화 대조군 차이를 뺀다. |
| 내용 빈곤 | 같은 방식으로 전반적 인상형과 평소형의 차이를 두 발화기 사이에서 비교한다. |

각 대비는 먼저 동일 사례·동일 턴의 네 셀에 대해 계산한다. 두 턴이 모두 판정 가능하면 사례 안에서 평균하고, 사례별 값에는 같은 가중치를 준다. 전체 6사례 중 사용 가능 수, 사례별 효과와 한 사례씩 제외한 범위를 병기한다. 불확실·평가 불가·결측을 각각 양성 또는 음성으로 둘 때 가능한 전체 사례 효과의 최솟값과 최댓값도 계산한다. 사례 수가 작고 편의 선정했으므로 모집단 유의성 검정이나 단일 종합 통과율을 주결론으로 사용하지 않는다. [집계 코드](analyze.py)

두 사전 가설의 방향은 각각 표적 성향에서의 증가가 간소화군보다 개발판에서 크다는 것이다. 반대 성향에서 같은 증가가 생기는지와 평소형 양성을 함께 확인한다. 원문에서 이 효과가 확인될지는 미지수다. 한 조건 안에서 항목의 양성률이 높다는 사실만으로는 개발판 개선을 판정할 수 없다.

- **선택적으로 표현하는가?** 개발판의 표적 성향−평소 차이가 양수여도 간소화군이 같으면 두 조건 모두 성향에 반응한 것이다. 개발판의 추가 효과를 말하려면 판독기별 대응 차이, 평소형 양성, 반대 성향의 비표적 항목 증가를 함께 본다. 모든 성향에서 두 항목이 함께 증가하면 과장 가능성이 남는다.
- **판독이 가능한가?** 항목별 양성·음성·불확실·평가 불가의 교차표, 두 모델 모두 판정 가능한 분모의 단순 일치율, 양성 특이 일치도 `2a/(2a+b+c)`와 음성 특이 일치도를 보고한다. 양성 분모 0이면 미정의다. 사전에 균형 선택한 12개 답을 각 모델이 새 문맥에서 한 번 더 읽어 모델 내 일치도도 같은 방식으로 계산한다. 같은 판정에서 인용 구간이 다른 사례와, 문구는 같지만 해석이 다른 사례를 공개 가능한 원문과 함께 제시한다.
- **무엇을 결론으로 쓰는가?** 두 모델의 방향이 다르거나, 일부 사례에 따라 방향이 뒤집히거나, 불확실성 범위가 양·음을 모두 허용하면 항목별 혼합·불확실 결과로 보고한다. 어느 한 축에서만 효과가 나면 그 축만 기술한다. 모두 같은 판정이면 표의 높은 전체 일치율과 함께 구별 가능한 표본의 부족을 명시한다. 효과가 검출되지 않았을 때는 생성 실패와 측정 한계를 모두 고려한다.

전시할 최소 자료량도 먼저 정한다. 한 주지표에서 어느 한 판독기라도 완전 대응 사례가 5/6 미만이거나 양성 일치도의 분모가 0이면, 해당 축은 판독 가능성 결과만 강조하고 생성기의 우열 결론은 보류한다. 5/6은 자료 누락을 드러내기 위한 운영 기준이며, 임상적 타당도나 통계적 검정력의 경계가 아니다.

**포스터 이후.** 가능하면 개발에 관여하지 않은 영어 면담 판독 가능 전문의 2명이 같은 72답변 전체를 독립적으로 읽는다. 판독 순서는 각자 다르게 무작위화한다. 동일 훈련 설명을 제공하고, 실제 연구 응답이나 LLM 측정값을 보기 전에 기준을 고정한다. 한 명만 확보되면 해당 전문의와 각 모델의 비교까지만 보고한다. 사후 합의 판독이 필요하면 최초 독립 원기록을 먼저 동결한다. 전문의–전문의와 LLM–각 전문의 일치율을 항목별 n/N, 양성·음성 일치도 및 95% 구간으로 제시한다. 사례 안에서 연관된 답을 묶어 불확실성을 추정한다. 6사례의 구간은 불안정할 수 있어 새 미사용 사례를 추가할 경우 원하는 정밀도와 사례 내 상관을 고려해 표본수를 먼저 정한다. 사람 판독 계획은 후속 단계이며 지표 근거와 환자 모집 사실을 대신하지 않는다. [일치도 연구 보고 지침 GRRAS](https://pubmed.ncbi.nlm.nih.gov/21130355/)

전문의–LLM 일치는 **판독기의 성능**에 관한 결과다. **발화기 성능**은 전문가가 가린 상태에서 같은 항목으로 판독한 두 생성기 조건의 차이, 평소형에서의 과장, 비표적 변화로 별도로 평가한다. 두 판독자가 모두 “없음”으로 일치해도 생성 성과를 주장할 근거는 없다. 전문의가 해당 패턴이 임상에서 접하는 범위로 자연스러운지도 평가한다면, 별도의 후속 질문·훈련·평가 기준을 사전 정의한다. 실제 환자만큼 자주 또는 같은 양상으로 생성한다는 주장을 위해서는 동일 과제·언어·판독 정의·중증도에 맞는 독립 환자 발화 또는 동등한 외부 준거가 더 필요하다. 질환 전체 재현이나 임상 사용 가능성은 이 파일럿의 추정 대상 밖이다.

## 오프라인 실행

아래 명령은 이 폴더에서 실행한다. 입력 조립과 검증만 수행한다. 본실험은 기존 구독을 사용해 별도로 실행할 단계다. 두 생성기 조건에는 같은 전송 방식·모델·설정을 사용하고 실제 사용한 역할 매핑을 기록한다. 버전 고정에 실패하면 다른 모델로 조용히 대체하지 않고 해당 건을 표시한다. 원본 시스템 문구 재배포 권한을 확인하지 않아, 입력을 실제 생성하려면 검증된 원본 스냅샷이 필요하다. 판독표·교정·분석에는 원본 스냅샷이 필요 없다.

```bash
python3 -B reader.py self-check
python3 -B generation.py self-check --source-root "/path/to/frozen-snapshot"
python3 -B study.py schedule
python3 -B study.py prepare "/path/to/frozen-snapshot" R032
python3 -B reader.py challenge-list
python3 -B reader.py challenge B14
python3 -B reader.py calibrate one_reader_calibration_directory
python3 -B study.py reading-order claude
python3 -B study.py reading-order gpt --repeat
python3 -B study.py packet R032 replies
python3 -B analyze.py replies first_reader second_reader --repeat-a first_repeats --repeat-b second_repeats
```

`schedule`은 운영자 전용 조건 키다. 생성기에는 준비 패킷의 `messages`만, 판독기에는 `packet` 또는 `challenge`의 눈가림 양식만 전송한다. 임상가에게 운영자 키와 개발자 저장소를 제공하지 않는다. 각 면담 두 번째 요청의 `prepare`에 `--replies replies`를 추가하면 해당 면담의 첫 원답을 ID로 찾아간다. 정상 완료한 영어 응답만 분석용 `replies/Rnnn.txt`에 넣고 장애·언어 위반·미완료 건은 원자료와 제외 사유를 별도 보존한다. 각 판독 폴더는 `Rnnn.json` 원응답을 사용한다. 재판독용 ID는 조건별로 균형을 맞췄고 노출할 때는 새 세션·별도 순서를 사용한다. 인수인계 파일과 연구 원자료는 분리한다.
