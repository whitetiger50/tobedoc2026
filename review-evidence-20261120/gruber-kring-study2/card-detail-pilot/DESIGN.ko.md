# 카드의 두 세부 사실이 구체적 전개 1점 집중에 기여했는가

2026-11-21 KST · 실행 전 확정안. 기전 확인용 소규모 실험이다. 기존 360개 답 중 354개가 제공한 세부 두 개를 모두 반영했고 360개 모두 적어도 하나를 반영했다. 구체적 전개는 두 판독을 합쳐 719/720건이 1점이었다. 이번에 추정할 것은 **같은 인물·질문·생성 조건에서 두 세부를 함께 제공하는 것이 전개 1점의 빈도를 얼마나 높이는가**이다. 기존 환자군 거리, 360개 원문과 점수, 채점 지침은 그대로 보존한다. ## 1. 어느 입력을 어떻게 비교할까

고정된 카드 12장에 한 문항씩 배정했다. 기존 출력·점수·판독 근거를 읽지 않는 선택 코드가 카드 ID·기존 성향과 열 문항의 범주만 사용했다. 긍정·부정·중립은 각각 네 카드이며 각 성향에도 세 범주가 모두 들어간다. 열 문항은 전부 한 번 이상 사용하고 자부심과 마지막 식사는 두 번 사용한다. 표의 각 인물·질문에서 개발판, 기본 모델, 단답 대조를 모두 비교한다. 카드 한 장에 한 문항이므로 문항별 효과나 성향별 효과를 독립 추정할 표본은 아니다. | 범주 | 고정한 인물과 문항 |
|---|---|
| 긍정 | GK01 기쁨, GK03 자부심, GK10 연민, GK12 자부심 |
| 부정 | GK02 두려움, GK07 당혹감, GK09 혐오, GK11 슬픔 |
| 중립 | GK04 길 안내, GK05 아침 일과, GK06 마지막 식사, GK08 마지막 식사 |

**원래 카드**에는 과거에 실제 전송한 중심 사실 F1과 세부 F2·F3를 같은 순서로 둔다. **중심 사실 카드**에는 같은 입력의 `patient.facts`에서 F2·F3 객체만 삭제한다. 인물의 자기소개, 성향, 상세 회상 안내, 영어 질문, 빈 대화 이력, 각 생성 조건의 시스템 지시는 그대로 둔다. 빈칸, 삭제 표시, “아는 만큼만 말하라”는 추가 지시는 주지 않는다. 예를 들어 GK05의 아침 일과에서는 “grinding coffee by hand each morning”을 남기고 파란 통에 보관한 원두와 조리대에 고정한 분쇄기 정보를 뺀다. 원래 카드 입력 36개의 해시가 본실험과 일치하며, 삭제한 객체를 복구하면 사용자 메시지도 바이트 단위로 복원된다.

양쪽 모두 같은 실행 기간에 새로 한 번씩 생성한다. 총 **36쌍, 새 영어 답 72개, 독립 판독 144회**다. 이전 360개는 배경 근거로만 보존하고 새 원래 카드 36개가 이번 동시 대조군이다. 같은 입력의 실행 간 변동을 집단 수준에서 통제한다. 셀당 한 번이므로 개별 답 한 쌍의 차이를 카드의 효과로 단정할 수 없다.

## 2. 배정과 눈가림

1. 실행 승인 후 첫 호출 전에 카드 블록 순서와 각 블록 안의 세 생성 조건 순서를 무작위로 정한다. 카드마다 독립적인 공정한 동전 한 번으로 앞·뒤 슬롯 중 어느 쪽에 중심 사실 카드를 넣을지 배정한다. 같은 카드의 세 생성 조건에는 같은 앞·뒤 배정을 적용한다. 12회의 동전 결과와 전체 순서를 실행 키에 한 번 저장한다. 순서 균형을 위해 다시 뽑지 않는다. 각 조건의 두 슬롯은 가까운 시점에 서로 독립된 빈 세션에서 실행한다.
2. 본실험과 같은 생성 모델 `gpt-6.1-sol`, medium, 도구 꺼짐, 기본 샘플링·출력 한도를 쓴다. 제공자가 노출하지 않는 생성 시드는 통제했다고 기록하지 않는다. 응답 품질이나 길이로 재생성하지 않는다. 전송 전에 실패한 요청만 같은 슬롯으로 복구한다. 유효한 최초 응답은 보존한다. 모델 버전이 달라지면 어느 슬롯이 영향을 받았는지 남기고 서로 다른 버전의 두 슬롯을 정상적인 완전쌍으로 취급하지 않는다.
3. 별도 운영 키로 답에 무작위 ID를 붙인다. Opus와 GPT는 본실험과 같은 판독 모델·지침·출력 양식으로, 각기 다른 무작위 순서의 영어 **개별 질문과 답 한 개**만 본다. 카드, 조건명, 짝 답변, 가설, 이전 점수는 제공하지 않는다. 매 판독은 새 세션에서 하고 두 판독 파일을 모두 잠근 뒤 배정 키를 결합한다. 일치 여부는 동일한 답을 읽은 두 측정의 비교로 보고한다.

## 3. 응답별 점수와 짝 비교

**주지표는 구체적 전개**다. 기존대로 사건·활동에 관련 세부가 있고 설명이 완결되면 1점, 세부가 있지만 중요한 연결 정보가 빠지면 2점, 사건·활동을 지칭하는 데 그치면 3점이다. 두 독립 사건은 각기 채점한 뒤 질문 안에서 평균한다. 평균이 정확히 1이면 ‘전개 1점’, 1을 넘으면 ‘전개 1점 초과’로 집계한다. 단어 수로 경계를 바꾸지 않는다. 의미 명료도는 같은 방식으로 별도 보고한다. 짧고 완결된 답도 그대로 채점한다. 순수 되묻기·기억 부재는 서사 미제공, 유효한 응답·판독을 얻지 못하면 기술 결측으로 보존한다.

판독자별로 원래 카드와 중심 사실 카드 각각에 대해 ① 전개 1점 ② 전개 1점 초과 ③ 서사 미제공 ④ 기술 결측 건수를 전체 36개와 생성 조건별 12개에서 제시한다. 두 카드의 상태를 교차표로 보고하고, 점수 원값·사건 수와 평균도 남긴다. 다음 두 수를 사전 정의한다.

- **b**는 원래 카드가 1점이고 중심 사실 카드가 1점 초과인 쌍 수다.
- **c**는 원래 카드가 1점 초과이고 중심 사실 카드가 1점인 쌍 수다.

모두 채점 가능하면 **Δ = (b − c) / 36**은 중심 사실 카드에서 1점 초과 비율이 증가한 폭이자 원래 카드에서 1점 비율이 증가한 폭이다. 생성 조건별 Δ의 분모는 12다. 36개에는 세 생성 조건과 세 문항 범주가 같은 비중으로 들어간다. 서사 미제공·결측이 있으면 확인 가능한 전환만 분자에 넣은 값은 ‘계획 36쌍당 확인된 순전환’으로 표시한다. 두 원래 비율과 완전쌍 분모도 함께 제시한다.

검정은 판독자별로 카드 12장을 단위로 한다. 각 카드에서 세 생성 조건의 순전환 합을 구하고 전체 합을 통계량으로 사용한다. 카드별 앞·뒤 배정을 뒤집는 4,096가지에 대해 통계량이 관찰값 이상인 비율이 단측 정확 무작위배정 p값이다. 이는 어떤 슬롯에도 세부 제공 효과가 없다는 귀무가설에 대한 검정이다. 같은 카드의 세 답이나 두 판독자를 독립 표본으로 늘려 계산하지 않는다. 결측쌍은 확인된 전환 통계량에 0을 기여한다.

## 4. 결과를 보기 전에 정하는 해석

| 관찰 결과 | 허용할 결론 |
|---|---|
| 두 판독자 **각각**에서 새 원래 카드 36개 중 **33개 이상이 전개 1점**, 중심 사실 카드의 **Δ ≥ 25%p**(순 9쌍 이상), 카드 단위 **단측 p ≤ 0.05**, 두 판독자에게 공통인 **두 개 이상의 생성 조건에서 Δ > 0** | “이 12개 인물·문항에서 카드가 두 세부 사실을 미리 제공한 것이 전개 1점 집중에 기여했다.” 어느 생성 조건에서 얼마나 움직였는지도 병기한다. |
| 두 카드 버전 모두에서 두 판독자가 각각 **33/36 이상**을 1점으로 채점 | “이 소표본에서는 두 세부를 뺀 뒤에도 전개 1점 집중이 유지됐다.” 더 작은 효과나 반대 방향 효과의 부재, 두 버전의 동등성을 주장하지 않는다. |
| 원래 카드에서 집중이 재현됐으나 차이가 작거나, 한 판독자 또는 한 생성 조건에서만 뚜렷하거나, 어느 규칙에도 해당하지 않음 | 실제 전환 수와 조건·판독자별 방향을 보고한다. 여러 생성 조건에 걸친 카드 기여는 미확인이다. 단답 대조만 변했으면 그 관찰을 개발판에 확대하지 않는다. |
| 새 원래 카드에서 33/36 집중이 재현되지 않음 | 동시 대조에서 관찰된 차이는 제시할 수 있다. 과거 360개의 점수 집중에 대한 설명은 보류한다. |

33/36은 ‘적어도 90%가 1점’의 정수 기준이고, 25%p는 이 규모에서 설명할 가치가 있는 큰 변화로 정한 운영 기준이다. 둘 다 임상 절단값이 아니다. 예컨대 역전이 없이 9쌍이 변해도 그 변화가 카드 세 장의 세 생성 조건에만 몰려 있으면 단측 p는 1/8이다. 같은 9쌍이 카드 아홉 장에서 하나씩 움직였다면 1/512다. 둘은 규모가 같아도 여러 인물·질문에서 반복됐다는 근거가 다르다. 판독자별 판단을 평균하거나 유리한 쪽만 골라 결론을 내리지 않는다.

미제공·결측을 2·3점으로 처리하지 않는다. 카드 기여를 주장할 때에는 별도 보수적 검산으로 미채점 원래 카드를 ‘1점 초과’, 미채점 중심 카드를 ‘1점’으로 놓는 가장 불리한 경우에도 위의 효과 폭·조건 방향·정확 검정 문턱을 모두 넘는지 확인한다. 이는 보고 점수가 아닌 민감도 계산이다. 전개 점수 변화 없이 중심 사실 카드에서 서사 미제공만 늘면, 정보 삭제가 채점 가능한 서사를 얻는 데 영향을 주었을 가능성까지 보고한다.

## 5. 결과가 무엇을 설명하는가

주판독을 잠근 뒤 조건별 단어 수와 짝 내 길이 변화, 사건 분리 차이, 의미 명료도 분포를 기술한다. 길이는 카드 삭제의 결과일 수 있어 주분석에서 맞추거나 보정하지 않는다. 특히 GK04 길 안내에서는 F1에 목적지 주소가 남고 경로는 삭제된다. 이 한 문항을 뺐을 때 Δ의 방향과 크기도 보조로 제시한다. 미제공이나 길 안내 한 문항의 정보 부족이 전체 해석을 주도하는지 확인하기 위해서다.

중심 사실 카드에서도 1점인 답은 F1 자체에 들어 있는 구체성, 유지된 인물 배경, 모델이 스스로 덧붙인 설명 중 무엇이 기존 판독 근거에서 확인되는지 원문 구절로 대조한다. 삭제한 사실과 우연히 일치하거나 출처가 불분명한 내용은 따로 표시한다. 이는 이미 산출한 점수를 이해하기 위한 원문 대조이고 새 채점 축을 만들지 않는다. [고정된 영어 카드 원문](../cards/CARDS.ko.md)

두 세부를 한꺼번에 삭제하면 입력 길이와 답할 수 있는 정보량도 함께 변한다. 식별 가능한 것은 **이 질문·프롬프트에서 두 세부를 제공하는 개입 전체의 효과**다. F2와 F3 각각의 기여, 프롬프트·척도·기반 모델의 독립 기여율, 120개 인물·문항 전체의 효과 크기는 추정하기 어렵다. 실제 환자 전사나 전문의 채점이 추가되지 않으므로 이 결과로 개발판의 환자 재현도 우위 또는 임상가–LLM 일치도를 갱신하지 않는다.
