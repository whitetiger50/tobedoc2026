For each blinded interview read the profile and all 12 turns. Use only text, not imagined tone or a clinical diagnosis. Code each of the following with a list of positive turn numbers and a separate list of genuinely uncertain turn numbers. An empty positive list is legitimate. Include a short exact patient excerpt and reason for every positive or uncertain decision. Use only the specified opportunities as denominators.

clarify_yield — On an "ambiguous" question the patient requests clarification of the question/referent/scope, then actually yields the turn before answering on a substantive interpretation. Do not count questioning their own belief, ordinary rising inflection, or offering an interpretation then volunteering an answer.
answer_then_check — On an "ambiguous" question the patient first supplies substantive experience/details, then checks what the interviewer meant. Requests for validation of a belief or invitations to the interviewer to agree are distinct.
unnecessary_clarify — On a premarked "clear" question the patient asks the interviewer to clarify something the question explicitly identifies or that the preceding exchange already established. A justified request to resolve remaining uncertainty, a question for the clinician's opinion or a quoted question does not qualify. If the prompt was marked clear but the request is reasonable, note it separately when relevant.
give_example — On an "example" opportunity the answer contains a specific occasion, instance, or concrete situation that answers the request. Generic reassurance or a list of broad themes alone is insufficient.
contradiction — Across any of 12 turns, an explicit substantive conflict with a known central profile fact or an already unambiguously established fact in the interview. New compatible detail, justified uncertainty, a patient's belief that differs from clinical account, stylistic mismatch, or omission is insufficient. Explain and identify both sides.
unanswered_repair — On an "ambiguous" opportunity the patient asks for clarification, but the next fixed interviewer question fails to address the reasonable scope/referent question they asked, impairing the exchange. Count at the original turn. Inspect actual follow-up; not every clarification goes unanswered. State whether the follow-up was sufficiently informative or went elsewhere.

Each source file is {profile,dialogue,opportunities}. Write one JSON object keyed by blind id, values of the form {"clarify_yield":{"positive":[],"uncertain":[]},"answer_then_check":...,"unnecessary_clarify":...,"give_example":...,"contradiction":...,"unanswered_repair":...,"notes":[{"metric":"...","turn":6,"quote":"verbatim patient words","reason":"..."}]}. Never use fields identifying the source. For any natural-text citation use an exact substring from the flagged turn; explain relevant subsequent or earlier material in the reason. No comparison across texts is needed. The prespecified unit of comparison in later analysis is a case, with results also shown per eligible turn.
