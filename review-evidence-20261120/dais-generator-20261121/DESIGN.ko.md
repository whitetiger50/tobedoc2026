# DAIS-C 첫 질문 발화기 실험 실행 기록

2026-11-21 KST. 연구자가 생성 실험으로 진행하도록 지시했다. 질문별 환자 수, 생성 반복 수, 평가 양식, 비교 기준 및 중단 기준은 기존 [첫 답변 비교 판정안 v1](../handoff.md)에서 가져왔다. 이번 입력 자료는 해당 사례에 실제 주어진 영어 면담자 첫 질문 14개다. 환자의 첫 답변은 판독과 분석에만 사용한다. 실제 답변의 분포를 팀이 이미 관찰한 탐색 연구이다.

**생성.** 고정한 GPT-6.1 Sol 모델과 동일한 구독·도구 비활성·medium 추론 설정·이력 없는 독립 세션을 사용한다. 개발판은 개발 시 선정한 모듈 v0.2의 해시를 확인하고 출력 언어 조항 한 개를 영어로 바꾼 기존 구현이다. 기본판은 같은 모듈의 역할·사실·대화 문맥을 유지하는 기존 최소 지시판이다. 단답 대조는 기본판에 “Keep your reply brief and vague.” 한 문장만 추가한다. 언어·질문·사실·성향·첫 턴 역할과 나머지 생성 설정은 동일하다. 모델 제공자가 노출하지 않는 표본추출 온도와 난수 시드는 기본값을 쓴다. 생성기와 GPT 판독기는 같은 모델 계열이다.

**가상 사례.** 환자 전사·기존 결과·질문 원문을 보지 않은 별도 작성자가 ‘일상 언어 사용’이라는 주제만 알고 14개 영어 사실 카드를 새로 작성했다. 사람마다 가상 카드 한 개를 무작위 연결하며, 이는 실제 환자의 인물 정보나 발화를 모사한 개인별 카드가 아니다. 세 조건과 세 반복에서 같은 카드를 쓴다. 이전에 사용한 세 의사소통 성향을 Q2와 Q3에 각각 평소형 3명, 연상형 2명, 전개가 적은 성향 2명으로 같은 비율 배정하고 질문 그룹 안에서 미리 섞는다. 특정 장소 방문에 맞던 공통 문구 두 개만 이번 일상 대화에 맞춰 일반화했다. 이는 실제 환자 성향의 추정치가 아니다. 출력 정답이나 목표 반응 빈도는 입력하지 않는다. **눈가림과 반복.** 질문 14개 × 조건 3개 × 세션 3회로 생성한 126개 답과 실제 첫 답 14개를 무작위로 섞는다. 동일한 공백·외곽 따옴표·화자 접두어 정리 후 불투명한 식별키를 붙인다. 판독자는 출처·조건·카드·목표·다른 판독값 없이 한 문답과 고정한 양식만 받는다. 자연 발화의 문체로 출처를 짐작할 가능성은 남는다. 독립 판독자는 Opus 5.5와 GPT-6.1 Sol이다. 앞선 환자 단독 판정을 복사하지 않고 이번 혼합 자료에서 다시 판독한다. 실제 빈도의 분모는 질문당 7명, 생성 답의 분모는 질문·조건당 계획한 21개이며 같은 환자 질문에 연결된 세 번의 생성은 같은 비중으로 평균한다. 최초 응답을 보존한다.

**분석.** 네 반응 유형의 부호 있는 비율차와 총변동거리를 Q2·Q3 별로 구하고 두 질문을 같은 비중으로 평균한다. 비교 대상은 기본판과 단답 대조 양쪽이다. 판독자별 전체 및 질문별 우위, 연결된 사람 한 명씩 제외, 길이층 표준화, 불명확·기술 결측 응답의 가능한 배치를 모두 기존 기준대로 검사한다. 길이 측정은 라틴 알파벳 단어와 단어 안의 아포스트로피를 세는 기존 방식이다. 임상 네 항목의 상태와 분모는 판독자별로 보존한다. 결과를 본 후 유리한 판독·반복·조건을 고르지 않는다. 사람 판독·발화기 변경·추가 대조군은 이번 실행에 포함하지 않는다.
