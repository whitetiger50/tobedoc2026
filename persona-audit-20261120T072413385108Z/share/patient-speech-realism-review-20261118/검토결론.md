# 환자 발화 현실성의 대화별 LLM 독립 평정

2026-11-18. 문헌·공개 코드 검토이며 새 시뮬레이션이나 LLM 채점 실험을 실시한 결과가 아니다.

## 평가 목표와 결론

목표는 **해당 설정의 환자가 실제 면담에서 할 법한 방식으로 말하는가**이다. 증상 중증도, 진단 가능성, 의료 지식, 일반적인 문장 유창성과 구분한다. BPRS 등 증상 평점을 이 목표의 주 지표로 사용하지 않는다. 앞선 제안은 증상 내용 충실도라는 보조 목적에만 해당한다.

주 평가 출발점으로 PATIENTSIM의 원 Realism 항목을 권한다. 다른 모델의 대화를 함께 제시하지 않고, 한 대화와 환자 페르소나를 보고 1~4점 및 이유를 출력한다. 연구용 순서형 평정의 선례이지 조현병에서 검증된 임상 척도는 아니다. 기존 문항을 채택해도 한국어·조현병·다른 판정 모델에 원 연구의 타당성이 자동 이전되지 않는다.

## 직접 확인한 연구

### 1. PATIENTSIM — NeurIPS 2025 Datasets & Benchmarks

원 Realism 항목은 전체 의사소통 방식이 실제 응급실 환자에게 기대되는 모습과 맞는지를 묻는다. 공개 JSON의 4개 앵커를 한국어로 요약하면 다음과 같다. 아래는 원문 대체용 확정 번역본이 아니다.

- 1: 설정과 동떨어진 말투·행동으로 매우 인공적이다.
- 2: 다소 자연스럽지만 설정에 부분적으로만 맞고 비현실적인 요소가 눈에 띈다.
- 3: 대체로 자연스럽고 설정에 맞으며 작은 어색함만 있다.
- 4: 설정의 실제 환자에게 기대할 의사소통으로 매우 설득력 있다.

평가 코드에서 한 대화와 성격·언어 능력·회상 능력·혼돈 수준으로 구성된 페르소나를 입력한다. Realism 입력의 페르소나를 전체 의학적 증례라고 혼동하지 않는다. Gemini-2.5-Flash가 채점한다.

논문 Table F11의 Realism 일치도는 Gwet AC1=0.321(95% CI 0.211–0.437), AC2=0.884(0.861–0.906)이다. AC2는 순서 범주를 반영한 가중 일치도이고 AC1은 더 엄격한 범주 일치를 반영한다. 둘 다 정확도나 전문가 대체율이 아니다. 원 연구의 임상의 4명 검증을 조현병 전문의 검증이라고 표현하지 않는다.

우리 적용에서 ED→정신과 진료 맥락 변경, 조현병 사례 특성 입력, 한국어 번역, 판정 모델 변경은 각각 명시할 적응 사항이다. 원점수는 유지하되 ‘원 연구 그대로 재현’이라고 부르지 않는다. 혼돈 수준을 조현병 사고장애와 같은 개념으로 취급하지 않는다.

출처: [논문 Appendix D.2.1 / F.1 / Table F11](https://proceedings.neurips.cc/paper_files/paper/2025/file/24945e3bdc7b3f4b2e64b9979a16f38e-Paper-Datasets_and_Benchmarks_Track.pdf), [원 점수 앵커 JSON](https://github.com/dek924/PatientSim/blob/9c262e692bd94305d922654d05bd1741c4d97433/src/prompts/eval/llm_eval_metrics_persona.json), [평가 실행 코드](https://github.com/dek924/PatientSim/blob/9c262e692bd94305d922654d05bd1741c4d97433/src/eval/llm_eval.py).

### 2. PatientHub — 2026 프리프린트

정신건강 상담의 대화별 LLM 평가에 직접 해당한다. GPT-4o가 1~5점으로 Naturalness(발화의 자연스러움), Emotional Depth(정서 표현), Appropriate Resistance(상황에 맞는 저항), Absence of Self-Curing(갑작스러운 자기 해결 방지)를 평가한다. 이 네 측면을 증상 중증도와 구분한다.

한계: 저자들은 전문가 검증이 필요하고 길이·격식에 따라 점수가 편향될 수 있다고 명시한다. 현재 확인한 공개 커밋의 기본 client_conv.yaml에는 일관성 평가 예시만 있으며 논문 실험의 현실성 네 항목과 각 점수의 상세 앵커를 찾지 못했다. 논문에 개념과 점수 범위가 있다는 것과 실험 채점표를 그대로 재현할 수 있다는 것을 구분한다.

이 연구는 보조 분석 항목의 참고 근거다. 조현병에서는 정서 둔마·적절한 협조·보존된 병식도 가능하므로 ‘감정이 풍부하고 저항할수록 현실적’이라는 일반 규칙을 만들지 않는다. 조현병에 맞춘 상세 앵커를 새로 쓰면 그것은 우리 연구의 적응·개발임을 표시한다.

출처: [논문 §4.3 / §6](https://arxiv.org/html/2602.11684v1), [확인한 공개 평가 템플릿](https://github.com/Sahandfer/PatientHub/blob/54d5c8761a9055a1e86d153715607ef9fa26358a/data/prompts/evaluator/client_conv.yaml).

### 3. SPBench / EasyMED — ACL 2026

GPT-4o가 증례와 전체 대화를 보고 독립 채점한다. 86개 표본을 임상 평가자 2명이 맹검 검토했고 전체 평가와 전문가 평균의 Pearson r=0.81을 보고한다. 이것은 자연스러움 단일 항목의 일치도나 조현병 타당성 결과가 아니다.

본문의 Language Naturalness라는 명칭과 달리 Appendix J.5의 실제 앵커는 의학용어 사용 건수에 따라 0~5점을 준다. Patience and Demeanor는 협조적·안정적 태도에 높은 점수를 준다. 길이와 환자 설정에 따른 부당한 차이가 생길 수 있어 우리 주 지표로 채택하지 않는다. 또한 J.1의 5점 Likert 설명과 J.5의 0~5 앵커가 달라 구현 전 확인이 필요하다.

출처: [원 논문 Table 2 / Appendix J.1 / J.5](https://aclanthology.org/2026.acl-long.1243.pdf).

### 4. PATIENT-Ψ — EMNLP 2024

전체 환자 유사성, 정서, 대화 스타일, 인지를 전문가와 LLM이 평가했다. 논문 Figure 5와 Appendix F의 Figures 21–23에서 GPT-4·Llama 3 평가는 전문가 평가와 반대 방향의 모델 순위를 보였다. 대화별 수치 출력이 가능하다는 것만으로 환자 현실성 판독 능력을 보장하지 않는 직접적인 사례다.

출처: [원 논문 §6 / Appendix F](https://aclanthology.org/2024.emnlp-main.711.pdf).

## 우리 적용에 대한 제안 — 원 연구의 절차와 구분

1. 한 대화의 주 결과는 원 Realism의 1~4점 하나로 둔다. 여러 보조 항목을 섞은 새 총점이나 100점 환산은 만들지 않는다. 프롬프트·모델명과 상대 조건의 대화는 평가자에게 숨긴다. 환자 설정과 전체 면담 맥락은 제공한다.
2. 같은 사례에 같은 면담 과제·질문 기회를 제공한다. 예컨대 두 조건 모두 같은 12개의 질문으로 면담할 수 있다. 12는 원 논문의 요구가 아니라 우리 실험의 선택 예시다. 답변을 같은 글자 수로 자르거나 발화마다 증상 수를 세어 나누지 않는다. 자연스럽게 말이 적은 사례도 허용한다.
3. 전체 대화를 읽되 실제 출력 길이, 잘림 여부, 질문 기회 수를 저장한다. 길이별 결과와 점수–길이 관계를 확인한다. 필요하면 사례를 반영한 분석에 길이를 넣는 민감도 분석을 추가한다. 길이는 프롬프트의 효과 자체일 수도 있으므로 보정 결과만 주 결과로 삼지 않는다. 고정 턴 수만으로 길이 편향이 제거됐다고 주장하지 않는다.
4. ‘탈선이 많을수록 높은 점수’가 아니다. 사례에 사고장애가 없으면 정돈된 발화가 적절하다. 사례에 의심·저항·탈선이 있으면 그 설정과 앞선 질문을 고려해 자연스러운지를 판단한다. 환자 프로필 일치와 발화 현실성은 보조 결과로 분리해 보고할 수 있다.
5. 채점 전 평가자의 기능 점검을 한다. 같은 증상을 임상 보고서처럼 나열한 대화, 환자 입장에서 표현한 대화, 무작위 단어를 섞은 대화 등을 구분하는지 확인한다. 이는 우리가 만든 통제 사례 점검이며 실제 환자 정답에 대한 임상 검증은 아니다. 작은 점수 차이를 얻기 위해 통제 사례나 문항을 사후 조정하지 않는다.
6. 대화별 독립 점수를 얻은 뒤 조건별 점수 분포·중앙값·불확실성을 비교한다. 동일 사례에 속한 반복 대화를 독립된 환자 표본으로 취급하지 않는다. 원 연구처럼 평균을 함께 보고하더라도 순서형 점수이며 3→4와 1→2의 차이가 같은 임상량이라고 단정하지 않는다.
7. 전문가 확보 후 같은 대화를 LLM 점수를 숨긴 상태에서 같은 항목으로 평정받는다. 점수 일치와 조건 순위 일치를 구분한다. 전문가 1명과의 일치만으로 전문가 집단의 공통 판단 또는 실제 환자 데이터와의 동등성을 입증하지 않는다.

초기 결과에서 허용되는 표현은 ‘공개 환자 시뮬레이션 루브릭을 정신과 맥락에 적용한 LLM 평가에서 현실성 점수가 높았다’이다. 실제 조현병 발화와 임상적으로 동등하거나 연구용 데이터 증강에 검증됐다는 결론은 아직 낼 수 없다.
