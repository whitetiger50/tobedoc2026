# 원척도를 유지하는 LLM 독립 채점: 현실적인 선택

2026-11-17. 문헌·매뉴얼에 근거한 선택안이며 새 모델 실행 결과가 아니다. 이전에 철회한 TLC 수정 루브릭을 재사용하지 않는다. 아래 선택은 임상 척도의 원항목·앵커를 유지하려는 것이며, 한국어 합성 면담에 대한 LLM 채점의 타당성까지 이미 검증되었다는 뜻은 아니다.

## 결론과 추천

**즉시 구성 가능한 출발점은 BPRS Expanded Version 4.0의 원항목을 그대로 독립 채점하는 것이다.** 의심(9), 환각(10), 비정상적 사고내용(11), 개념적 와해(15)를 사전에 지정하고, 각 대화에 원래 1~7 등급을 하나씩 부여한다. 임의의 블록 평균, 재정의한 중증도, 네 항목 합계, ‘BPRS 단축판’이라는 이름은 쓰지 않는다. 이는 **기존 항목별 관찰값**을 보고하는 안이다. 전체 BPRS의 타당성을 네 항목 묶음에 승계한다고 주장하지 않는다.

이 중 9·10·11은 환자가 말한 증상 경험을, 15는 실제 발화의 조직성을 본다. 15의 자동 판독 근거가 상대적으로 약하므로 **일차 확증 지표로 즉시 확정하지 않고**, 초기에는 탐색 지표로 둔다. 사고형식장애의 개선 자체가 연구의 핵심 주장이라면 해당 항목의 외부 검증이 남아 있다. 더 높은 중증도 점수가 더 좋은 프롬프트라는 뜻은 아니다.

**한국어 증상 내용의 상세 평가 후보는 K-PSYRATS다.** 기존 망상 하위척도와 환청 하위척도를 유지하는 방향이 적절하다. 한국어판 임상 검증은 확인했지만 이번 검토에서 정식 한국어 전체 문항·앵커 양식과 LLM 채점 검증은 확보하지 못했다. 따라서 지금 바로 완성된 주 평가 명세로 포장하지 않고, 원양식을 확보한 뒤 적용하는 후속 후보로 둔다. 한국어판을 찾았는데도 영어 양식을 임의 재번역해 대체하지 않는다.

## 1. 직접적인 근거와 반례

### BPRS를 LLM으로 독립 채점한 연구

Chen·Horga·Escola, Schizophrenia Bulletin 2026, DOI 10.1093/schbul/sbag084. 임상 고위험군 409명의 전사에서 24항목을 예측했다. PSYCHS 전사에서는 총점 ICC 0.73, 비구조화 영어 면담은 0.42였다. 비영어 자료에 한국어 전사 39건이 포함되며 언어별 분석도 일부 있다. 그러나 **개념적 와해는 연구의 항목별 concordance 기준 0.75에 못 미친 세 항목 중 하나**였다. concordance는 ±1점 이내의 일치이며 정확히 같은 점수의 비율이 아니다. 총점 성능을 15번 항목·한국어만의 성능으로 바꿔 말하지 않는다.

[논문](https://doi.org/10.1093/schbul/sbag084), [세부 결과가 검색 가능한 출판사 원문](https://academic.oup.com/schizophreniabulletin/article/52/5/sbag084/8769732?login=false). 근거: Methods의 모델·프롬프트, Results의 Overall Accuracy·Foreign Language Interviews, Discussion. 현재 사용 가능한 다른 모델이 동일 성능을 낸다는 근거는 아니다.

### BPRS 원 매뉴얼

UCLA 연구진의 Expanded Version 4.0, 1993년 문서 전체를 확인했다. 정의·앵커·분기 질문과 평정 원칙이 공개돼 있다. 평정 기간은 목적에 따라 지정하며 보통 1일~1개월이고, 증상별 정보원을 구별한다. 15번은 말한 내용의 기이함 자체와 발화 조직성을 구분한다. 마지막 해설은 필요한 증상 항목을 개별적으로 모니터링할 수 있음을 설명한다. 원문은 일부 지면에서 2~7의 양성 앵커만 나열하므로, 1=부재라는 기본 코드와 NA 표기를 포함한 양식을 함께 확인·고정해야 한다. 0~6 체계의 다른 BPRS 버전과 혼용하지 않는다.

[전체 매뉴얼](https://adai.uw.edu/instruments/pdf/BPRSmanual.pdf). 확인 위치: PDF 2~8쪽의 평정 원칙, 16~19쪽의 관련 내용 항목, 22~23쪽의 15번. 원문 전체를 이 문서에 복제하지 않는다.

### K-PSYRATS 임상 검증

정순민 등, 신경정신의학 2007;46(3):201–213. 한국어판의 임상 신뢰도·타당도를 검토한 논문을 찾았다. 초록에 따르면 109명으로 타당도 등을 평가했고, 평가자 간 신뢰도는 환자 5명의 영상 평가에 기초한다. 환청 ICC 0.81, 망상 ICC 0.97을 보고했다. 한국어 **임상의 평가도구**의 근거이며, 한국어 LLM 판독이나 합성 대화의 현실성 검증은 아니다. 이번에는 원저 초록·서지만 확인했으며 원양식 전체 확보를 완료했다고 주장하지 않는다.

[KCI 원저 정보·초록](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001224101). PSYRATS 원 개발 논문: [Haddock 등, 1999](https://pubmed.ncbi.nlm.nih.gov/10473315/). 두 하위척도의 원항목·원합산법을 확보한 후 유지한다. 환청·망상 경험의 강도를 측정하는 도구이며 탈선의 판독 도구는 아니다.

### TALD: 더 구체적인 사고형식 후보

ClearThought, Multimedia Tools and Applications 2026은 이탈리아어 실제 조현병 면담 33건에서 TALD 30항목의 0~4 평점을 LLM으로 예측했다. 원 매뉴얼을 사용한 임상 평정과 비교했으며 항목별 결과 차이와 희귀 증상의 불균형을 보고했다. 다만 약 50분 면담과 음성 전처리·시간 정보가 있는 체계이고, 자료는 요청 방식이다. 텍스트 전용 12턴 면담에서 모든 항목의 동일 타당성을 보장하지 않는다. 정식 영어 매뉴얼 전체는 이번 검토에서 확보하지 못해 즉시 실행 후보로 확정하지 않는다.

[논문](https://link.springer.com/article/10.1007/s11042-026-21401-8). 근거: §2.1, §3, §4.3, Data Availability Statement. 원 매뉴얼과 질문 조건을 확보하면 텍스트 관찰이 가능한 **기존 항목**을 후속 검토할 수 있다. 스페인어 공개 초안이 존재한다는 사실을 영어·한국어 원양식 확보와 혼동하지 않는다.

### 짧은 텍스트 LLM 연구를 원 TLC 적용으로 오해하지 않기

Pugh 등, Psychiatry Research 2024는 신데렐라 이야기·세탁 절차 발화의 coherence/content/tangentiality를 기존 연구 루브릭으로 평가했다. TLC 평점은 다른 임상 면담에서 얻었으며 세 발화 점수와 동일하지 않다. 이 연구는 독립 자동 평정의 선례이지만 임의의 CPX 대화에 원 TLC를 그대로 채점해도 된다는 근거가 아니다.

[저자 공개 원문](https://ckchandler.github.io/files/publications/pugh_psychresearch.pdf). 근거: §1.1~1.2, §2.1.2. 이 루브릭을 채택하려면 원래 발화 과제도 유지해야 하며, 기존 임상 척도와 같은 것으로 부르지 않는다.

## 2. 다른 후보를 지금 채택하지 않는 이유

- **TLC 전체:** 원 앵커를 유지할 수는 있으나 짧은 대화의 관찰량 문제가 남는다. 빈도 경계 재설정이나 블록 평균으로 해결하면 다시 수정안이 된다. 기존 global rating도 사고형식의 종류를 충분히 구분하는 대체 척도는 아니다.
- **TLI:** 표준 그림 자극·시간 제한·확인 질문과 상세 매뉴얼이 필요하다. LLM 생성 지연을 환자의 발화 시간으로 대체할 수 없으며 그림을 텍스트 상황으로 바꾸면 원 절차를 유지한 것이 아니다.
- **TDI:** 원 매뉴얼은 문맥 확인을 강조하지만 총점의 생산량 보정은 Rorschach 응답 또는 WAIS 자료에 정의돼 있다. 일반 채팅 턴 수로 분모를 바꾸면 새 산출법이 된다. 현 팀 자원에서는 제외한다.
- **PANSS 전체/SAPS·SANS 전체:** 원척도는 대안이지만 텍스트에서 관찰 불가능한 행동·음성 단서를 추측해 채운 총점은 추천하지 않는다. 이번 검토에서 전체 원 매뉴얼·모든 항목의 LLM 근거를 확인한 것으로 주장하지 않는다.
- **AMDP:** 실제 면담 텍스트의 LLM 평정 연구는 있으나 3개 시나리오이며 관찰 의존 항목에서 한계가 있다. 주 언어·원 매뉴얼 확보 문제까지 고려하면 BPRS보다 우선할 이유가 부족하다.

참조: [TLC 원전](https://pubmed.ncbi.nlm.nih.gov/3764363/), [TLI 원전](https://doi.org/10.1192/bjp.181.4.326), [TDI 원 매뉴얼](https://academic.oup.com/schizophreniabulletin/article-pdf/12/3/483/5279477/12-3-483.pdf), [AMDP LLM 연구](https://pmc.ncbi.nlm.nih.gov/articles/PMC13342660/).

## 3. 실행 가능한 BPRS 항목별 평가 절차

### 유지하는 것

- 24항목 Expanded Version 4.0의 **선정한 원항목 정의·앵커·1~7 코드**를 유지한다. 번역된 새 중증도표, 블록별 점수, 임의 가중 총점은 만들지 않는다.
- 의심·환각·사고내용 항목에는 정해 둔 기간(예: 최근 1주)의 빈도·확신·행동과 기능 영향을 매뉴얼 질문으로 확인한다. 15번은 면담에서 실제 드러난 발화를 본다. ‘환자가 탈선한다고 말했음’은 15번의 관찰 근거가 아니다.
- 핵심 질문과 해당되는 추적 질문을 수집 프로토콜에 유지한다. 정보가 부족하면 NA다. 심한 와해 때문에 답변 정보를 얻지 못한 것을 환각이나 망상의 부재로 처리하지 않는다.

### 바뀌는 것과 남는 검증

평가자를 LLM으로 바꾸고 생성 환자를 평가한다는 사용 맥락은 바뀐다. 원항목을 유지하면 **새 임상 척도를 발명하는 문제**는 줄일 수 있지만, 평가자·자료 전이의 검증까지 없어지지는 않는다. 이 점은 모든 후보에 공통이다. 네 항목을 골라 보고하는 것은 항목별 관찰 연구이지 새 BPRS 단축척도 검증이 아니다.

### 한 대화의 판독

LLM에는 선정 항목의 원문 기준·필요한 일반 평정 원칙과 전체 전사를 제공한다. 원 매뉴얼을 모델 기억으로 재생하게 하지 않는다. 원문을 실제 평가 입력에 삽입한 뒤 문서 버전·입력 해시를 기록한다. 영어 원문 기준으로 한국어 자료를 평가하는 방식 자체는 BPRS 선행연구에 선례가 있지만 현재 모델에 대한 보장은 아니다.

생성 방법·프롬프트·목표 점수·다른 대화·이전 평가 결과는 숨긴다. 필요한 언어·문화·교육 맥락은 같은 기준으로 제공한다. 숨겨진 사례 설정을 보고 부족한 환자 답변을 채점자가 보충하지 않게 한다. 출력은 항목별 정수 1~7 또는 NA, 원 앵커 참조, 원문 근거와 판단 한계다. 프로그램이 하는 일은 범위·누락·인용 확인과 통계이며 임상 해석을 대체하지 않는다.

같은 대화에 서로 다른 모델 조건을 함께 보여주지 않는다. 모든 조건에 같은 평가자를 쓰고, 개발용 자료와 평가용 자료를 분리한다. 주 평정은 사전에 고정한 최초 실행으로 두고 반복 평정은 별도로 보고한다. 여러 번 중 유리한 평점을 고르지 않는다. 비용·사용 가능한 서비스 확인 없이 유료 호출이나 새 모델 설치는 하지 않는다.

## 4. 수치로 무엇을 비교할 것인가

**원측정값:** 대화 하나마다 네 개의 원항목 점수가 나온다. 예를 들어 ‘개념적 와해 4점’은 원척도의 등급이며, 같은 대화의 블록 평균을 새로 만든 값이 아니다. 점수 자체를 ‘프롬프트 성능’ 또는 ‘환자 현실성’이라고 부르지 않는다.

**실험 질문:** 사전에 임상 프로필로 지정한 증상 수준을 어느 프롬프트가 더 잘 재현하는가? 목표 점수는 실제 환자의 임상 정답이 아니라 연구 사례의 설정이다. 생성 전에 별도 LLM이 원 매뉴얼로 사례의 사실과 목표가 맞는지 검토하고 불일치를 해결한다. 이것은 내부 점검이지 전문의 검증의 대체가 아니다.

**비교 통계:** 항목별 목표×관찰 등급의 혼동행렬, 목표와 정확히 일치한 사례 비율, 과대/과소 등급의 사례 수를 제시한다. 등급 거리(MAE)는 보조적으로 제시할 수 있으나 단계의 비용을 같게 둔 분석 선택임을 밝힌다. 이 통계는 원항목의 측정 기준을 재정의하지 않는다. 항목을 합쳐 새 임상 총점을 만들지 않는다. 낮거나 높은 점수 자체가 아니라 지정한 프로필과의 일치를 평가한다.

NA는 정상 1점과 다르다. 계획한 사례 수 N 중 확인된 정확 일치가 c개, NA가 u개라면 일치율의 식별 범위는 [c/N, (c+u)/N]다. 범위와 완료율을 함께 보고한다. NA만 제거해 유리한 결과를 만들지 않는다. 이것은 신뢰구간이 아니며, 표본 불확실성은 별도로 계산한다.

같은 사례의 반복 생성 결과를 먼저 요약하고 사례를 동일 가중한다. 모델 간 비교의 신뢰구간은 사례별 묶음을 유지한 짝 재표집으로 구한다. 문장·턴을 환자 수로 세지 않는다. 한 가지 항목이 좋아졌다는 이유만으로 전체 임상 모사 우월성을 주장하지 않는다.

## 5. 길이와 맥락: 척도는 그대로, 자료 수집을 맞춘다

1. 양쪽 조건에 같은 매뉴얼 기반 질문 순서·필수 확인 항목·추가 질문 규칙을 쓴다. 무조건 12턴에서 끊거나 50분에 해당한다고 환산하지 않는다. ‘충분한 관련 정보를 수집했는가’를 기록한다.
2. 응답별 글자 수를 강제로 같게 만들거나 평가 전에 발화를 자르지 않는다. 기술적 상한에 잘리면 해당 판단은 NA로 남기고 잘림을 별도 보고한다.
3. 전체 전사와 질문 맥락으로 원 앵커를 적용한다. 질문에 따른 주제 전환·기이한 믿음 자체를 발화 조직성 장애로 바꾸지 않는다. 원앵커에 있는 빈도·상황 기준은 임의의 1,000어절당 값으로 바꾸지 않는다.
4. 항목 9~11에서 평가하는 빈도는 환자가 보고한 평가 기간의 경험 빈도이지, 대화에서 증상 단어를 몇 번 말했는지가 아니다. 따라서 응답 길이로 나누는 접근 자체가 맞지 않는다.
5. 15번은 발화량의 영향을 받을 여지가 여전히 있다. 질문·관찰 기회를 맞춰도 길이 독립성은 보장되지 않는다. 길이 분포·점수와의 관계·NA율을 보고하고, 효과가 단순한 장문 연기에만 동반되면 길이와 무관한 개선이라고 주장하지 않는다. 길이를 사후 보정해 원평점을 새 임상 점수로 바꾸지 않는다.

## 6. 전문의가 나중에 평가할 때

동일 전사를 동일 원항목으로 평가하되 생성 조건·목표·LLM 점수는 숨긴다. 무작위로 정한 표본의 일치도와, 일부러 고른 실패 사례 검토를 분리한다. 항목별 정확 일치·±1점 일치·가중 kappa·오판 방향을 본다. 하나의 총점 상관으로 판독기 검증을 끝내지 않는다. 한 명의 전문의와 비교하면 그 평가자와의 일치라는 제한을 명시한다.

이는 원 임상 항목을 유지한 상태의 LLM 채점 검증이다. 전문의에게 별도의 사례 적합성/현실성 검토도 요청할 수 있지만 그 판단을 위 원항목 점수와 동일시하지 않는다. 임상 척도 등급이 맞아도 정형화된 연기일 수 있다.

## 7. 이번에 확정할 수 있는 것과 남는 것

- **확보:** BPRS 4.0 원 매뉴얼 전체, 한국어 자료가 포함된 직접 LLM 연구, K-PSYRATS 임상 검증 논문의 존재와 초록, TALD 자동 평정 선례.
- **지금 가능한 작업:** BPRS 선정 원항목을 이용한 개발용 독립 채점과 관찰 가능성 점검. 새 임상 루브릭은 만들지 않는다.
- **미확보:** K-PSYRATS 정식 전체 양식, TALD 정식 영어 전체 매뉴얼, 현 평가 LLM의 한국어 합성 면담 항목별 외부 성능.
- **추천 주장 범위:** ‘기존 임상 항목의 LLM 평정에서 사전 설정한 증상 프로필 재현성을 비교했다.’ 실제 환자 유사성·임상 동등성·데이터 증강 유효성은 별도다.
- **아직 하지 않은 것:** 새 환자 대화 생성, 새 LLM 채점, 유료 호출, 모델 설치, 전문의 컨택. 이번 결과는 문헌에 근거한 실행 후보 선택이다.
