# 로컬 Qwen 14B에서 사고 전환 지시를 비교한 탐색 연구

2026년 11월 17일

현재 고정한 PSYCHE 스타일 프롬프트에서 구체적인 탈선 지시는 범주명만 제시한 조건보다 답변을 평균 25.5단어 길게 만들었지만, 별도로 이해 가능한 인접 구절의 연결이 명확하게 불분명한 사례는 확인하지 못했다. 미사용 합성 사례의 24응답에 대한 현재 어시스턴트 판독은 없음 21개, 불확실 3개, 명확한 양성 0개였다. 이는 로컬 구현의 다음 실험을 정하는 파일럿 결과이며 임상적 사고장애의 부재나 Qwen 전체의 능력 한계를 입증하지 않는다.

## 질문과 비교

동일한 임상 사실과 질문에서 범주명 대신 구체적인 사고 전환 지시를 추가할 때 어떤 텍스트 변화가 생기는지 조사했다. 이전에 고정된 6조건 설계를 재사용하되 과거 응답은 섞지 않고 모두 새로 생성했다. 사례는 연구자가 작성한 허구이며 실제 환자 자료가 아니다. 원형 PSYCHE의 재현이나 전체 시스템 간 우열 비교가 아니다.

4개 미사용 사례에서 질문 1개와 seed 1개를 사전 지정하고 각 블록의 6조건을 모두 생성했다. 전체적으로 질문 2종과 seed 2종의 네 조합을 한 번씩 사용했다. 미사용 사례들은 일상과 직장 정보를 교체한 유사한 구조여서 광범위한 환자 다양성을 대표하지 않는다. 각 응답은 새로운 대화의 첫 응답이며 다회차 면담이 아니다.

기존 전체 후보 설계는 120요청이지만 이번 실제 실행 범위는 개발 6개와 조사 24개, 합계 30개로 사전에 제한했다. 나머지 후보 요청은 이번 연구의 결측치가 아니다. 제한 범위와 표본 ID는 조사 생성 전에 pilot-amendment.json에 고정했다. 목표 특성이 나오지 않았다는 이유로 출력이나 지시문을 다시 만들지 않았다.

## 실행과 판독

Apple M5, 메모리 24GB의 맥북에서 Ollama 0.40.6의 qwen3:14b 14.8B Q4_K_M을 사용했다. 모델 digest는 runtime.json에 보존했다. temperature 0.6, top_p 0.95, top_k 20, repeat_penalty 1.0, num_ctx 16384, num_predict 768, think=false였다. 동일한 전체 환자 정보와 질문을 제공하고 사고과정 범주·부가 지시만 조작했다. 요청 길이는 100~140단어였으며 실제 길이 위반은 그대로 남겼다.

현재 어시스턴트가 조건 식별자를 제거한 질문과 전체 답변을 읽고, B 연결 불명확성, A 질문 시작의 대응성, C 구절 내부 이해 곤란을 별도로 기록했다. 각 판독의 인접 원문 구절과 이유를 저장한 후 조건 키를 결합했다. 조건을 숨겨도 연구 설계와 이전 사례를 알고 있으므로 독립 블라인드 검증자가 아니다. 사람·전문의 판독은 0건이며 판독을 TLC 임상 점수로 해석하지 않는다.

## 관찰 결과

- 정상 범주명: 없음 4/4, 불확실 0/4, 명확한 양성 0/4. 평균 83.50단어, 길이 조건 충족 0/4.

- 정상 구체 지시: 없음 4/4, 불확실 0/4, 명확한 양성 0/4. 평균 96.00단어, 길이 조건 충족 2/4.

전 조건에서 시작 질문에 직접 답하는 것으로 관찰됐고, 구절 내부 이해 곤란은 관찰되지 않았다. 목소리를 듣는다는 내용 자체를 연결 이상의 근거로 삼지 않았다.

불확실 3개는 중립 조건 2개와 탈선 구체 지시 조건 1개였다. E008, E016, E024에서 일상 또는 업무 설명이 목소리 경험으로 바뀌었지만, 정상적인 임상적 부연 설명과 연결이 약한 전환을 텍스트만으로 가르기 어려웠다. 예를 들어 E024의 업무 나열 뒤 “Sometimes I hear a voice”는 명시적 국소 연결이 없으나 전체 면담 맥락에서는 설명 가능한 전환이다. 불확실을 양성이나 음성으로 강제하지 않았다.

주 대비는 (구체 탈선−구체 정상)−(범주 탈선−범주 정상)이다. 확정 판독이 있는 3개 사례의 대비는 각각 0이었다. 4개 사례 전체에서 불확실값을 0 또는 1로 허용한 평균 대비 범위는 0~25%p였다. 이 범위는 신뢰구간이 아니며, 양의 효과를 확인한 결과도 아니다. 24응답을 독립 환자 24명으로 계산하는 유의성 검정은 하지 않았다.

탈선 구체 지시와 범주명 조건의 길이 차이는 사례별 +24, +30, +46, +2단어였고 평균 +25.5단어였다. 정상 조건에서의 구체 지시 효과도 빼면 길이 상호작용은 평균 +13단어이며 사례별 방향이 모두 같지는 않았다. 조사 응답의 길이 조건 충족은 8/24였다. 따라서 길이 증가 자체를 탈선 구현 성공으로 사용할 수 없다.

별도 사전 고정한 정규식으로 세 목표 사실의 표현 출현을 조사했을 때 조건별 10~11/12표현이 검출됐다. 이 결과는 표현 검출만 의미한다. 부정·문맥·다른 말로 표현한 사실의 의미 일치를 판정하는 사실 정확도나 환각률이 아니다. 예컨대 snack shelves are full과 같은 표현은 사전 동사 중심 규칙이 놓칠 수 있다. 주 결과로 사용하지 않는다.

## 결과가 정하는 다음 방향

현재 긴 프롬프트에 지시를 추가하는 방식에서 사례 수나 채점 호출을 곧바로 늘릴 근거는 부족하다. 다음 후보는 같은 사례 사실·질문·출력 조건에서 프롬프트 구조와 행동 지시를 분리하는 소규모 비교다. 전체 MFC 지시문과 결정적으로 추린 짧은 정보 제시를 비교하고, 각 구조에서 정상·구체 탈선 지시를 교차한다. 이는 구조와 사고 지시의 상호작용을 묻는다. 정보량까지 달라지면 압축과 지시 위치 효과를 분리할 수 없으므로 유지할 사실을 먼저 고정해야 한다.

그 전에 소수의 외부 근거가 있는 명확한 양성 예시와 정상 다주제 예시를 평가 묶음에 포함해 관찰 기준의 민감도와 경계를 확인하는 편이 낫다. 이번 응답에 명확한 양성이 없으므로 판독자의 양성 탐지 능력을 검증할 수 없다. 이후 팀원 또는 전문의의 독립 판독을 추가하면 현재 AI 관찰과의 차이를 조사할 수 있다.

Qwen은 이번에 합성 발화 생성 실험의 한 조건으로 사용됐으며 다른 모델과 동등한 성능의 대체재로 검증되지 않았다. 단순 집계·해시·근거 대조는 로컬 코드로 처리하고 Qwen 자체 채점은 추가하지 않았다. 생성기 교체가 연구 성능을 떨어뜨리지 않는다는 보장은 이 자료로 할 수 없다.

## 비용과 검증

새 로컬 생성 30회 모두 완료됐고, 잘림·빈 응답·API 오류·진단명 및 지시문 직접 노출은 0건이었다. 순수 생성 요청 시간 합계는 9.16분, 입력 평가 84,275토큰, 출력 3,599토큰이었다. 이 수치는 Ollama 기록이며 이번 채팅의 어시스턴트 토큰 사용량과 다르다. 유료 모델 API 호출, 모델 다운로드, 패키지 설치는 각각 0회였다. 전기·맥북 사용 비용을 산정한 것은 아니다.

24개 원문 해시와 인접 인용 쌍을 검증했고, 불확실값의 범위 계산과 인용의 순서·인접성 검사에 대한 3개 코드 테스트가 통과했다. SBERT나 GPT-2 지표를 새로 실행한 결과는 포함하지 않는다.
