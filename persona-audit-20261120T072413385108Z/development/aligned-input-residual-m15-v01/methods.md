# M15 사전 계획: 범위를 맞춘 입력에서 남는 생성 결함 확인

2026-11-19 KST. 사용자 요청에 따라 v0.2와 M12/M13 평가 기준을 유지한다. M14에서 Astra·별도 Claude가 비평한 방향을 실행하는 단계이며 새로운 개입 방향·척도 변경은 없다. 별도 멘토 재호출 없이 기존 계획의 질문별 작성 점검을 적용한다.

## 자료와 입력 작성 점검

최종12사례의 내용은 열지 않는다. M13의 기존 개발3프로필을 재사용하며 환자 사실·자기 이해·의사소통 설정·시작 이력은 그대로다. 세 프로필의8질문을 생성 전에 각자 검토했다. D01의 ‘가장’을 세 사례에서 빼 미기재된 다른 불편과의 우선순위 비교를 요구하지 않게 했다. 사례2 D08은 진료 전 활동 대신 진료 때 이야기할 내용을 묻도록 정렬했다. 나머지20문항은 유지했다. 변경 전후·대상·시간·근거 fact·환자 지식·열린 범위는 `question-audit.json`이다.

작성 검토는 의도한 질문에 답할 알려진 사실이 있다는 판단이다. 모든 가상 세부를 확정하거나 임상 타당성을 보증한 것은 아니다. 동거 사실에서 다른 가구원 부재·전체 인원수는 여전히 미정이다. 이를 임의로 보완하지 않는다. 관련 자발적 설명, 앞선 답을 다시 묻는 질문에 대한 짧은 재확인, 한국어 생략·바꿔 말하기를 허용한다. 질문의 답을 먼저 노출하거나 의도적인 정보 공백을 기억 장애로 채우지 않는다.

## 생성과 판독

3프로필에서 각각3회 독립적으로 시작해9개 새8턴 대화·72개 실제 환자 발화를 얻는다. 생성 모델은 기존 공식 구독 CLI의 GPT-6.1 Sol High, 환자 모듈은 raw v0.2를 명시한다. 이력은 각 대화의 실제 이전 응답 전체만 누적한다. 예시·필터·응답 수정·후보 선택·재생성은 없다. 최대3개 프로필 작업을 병행하되 한 대화 안의 턴은 순차적이다. 전송 실패 시 진행중 응답을 보존하고 새 턴 제출을 멈춘다. 결함이 나타났다는 이유로 원문을 버리거나 질문을 바꾸지 않는다.

완성된 원문9개를 두 모델이 대화별 새 세션에서 각각3회 판독한다. GPT-6.1 Sol High와 Claude Opus5.5 medium, 총54개 단독 판독이다. 기존 역할·앵커·M12 JSON 파서와 유효 숫자 보존 규칙은 그대로다. 각 텍스트의 입력 JSON·역할 해시는 두 모델·반복 간 같다. 생성자·실험 목적·사례/버전/반복 ID·이전 점수·작성자 노트는 평가 입력에 넣지 않는다. 외부 opaque ID로 대응하고 provider별 무작위9개 블록3회·인접 프로필 구분·최대2병행·블록 장벽을 적용한다.

기존 공식 CLI의 격리 임시 cwd, 도구·메모리·사용자 설정·세션 지속 차단을 유지한다. 명시 별칭·추론·CLI버전·Claude의 보고 모델·실제 원응답과 시각을 기록한다. 불변 서버스냅샷·temperature·seed 고정이나 서비스 수준 확률적 독립을 주장하지 않는다. 슬롯별 한 호출이며 점수 교체·자동 재시도·새 모델/API 우회는 없다. provider 안의 CLI버전 변경·전송 실패는 새 제출을 멈추고 진행중 결과를 보존한다. 의미적 NA와 기술 결측을 구별하고 유효 숫자를 다른 필드 오류 때문에 버리지 않는다.

## 입력과 생성자 결함의 귀속

생성 전에 `attribution-rules.json`을 고정한다. Codex가 새 판독 결과를 보기 전에72환자턴을 모두 읽고 원문·질문·명시 fact·이력을 연결한 정성 노트를 남긴다. 이는 비맹검 작성자 분석이며 새 임상 판독자나 추가 수치 척도가 아니다. 이 노트의 해시는 첫 수치 판독 전에 동결하고 평가 모델에는 주지 않는다.

명시 사실 모순·분명한 무근거 확정·명백한 역할 이탈·알려진 사실에 직접 답할 수 있는데도 뚜렷이 미대응한 경우를 생성자 결함 후보로 기록한다. 질문/설정의 대상·시간·지식 불일치는 입력 문제로, ‘함께→둘이’ 같은 의미 경계나 문체·임상 판단은 불확실로 남긴다. 정당한 자발성·재확인·한국어 생략은 허용 반응이다. 단일 명백한 결함도 해당 사례에서 기록할 수 있지만 그 관찰로 일반화하지 않는다.

판독 후에는 기존4축의 실제 지적을 같은 사건별로 연결해 수용·보류·반박 이유를 남긴다. 보조축·모델·회차에 반복된 같은 지적을 독립 오류로 합산하지 않는다. 입력 귀속 문제를 제외하고도 명확한 생성자 사건이 남는지 답한다. ‘입력 문제 제외’는 원인 분류의 구분이며 점수가 낮은 대화를 사후 삭제하는 절차가 아니다. 전체 원평점과 모든 대화를 유지한다. 작성자가 입력에서 문제를 못 찾았다는 것만으로 모든 입력 원인이 제거됐다고 선언하지 않는다.

## 사전 분석과 종료

- 대화별 두 모델의 세 원점수·분포·평균,6점 운영평균을 보존한다. 완전한 평균만 계산하고 결측을 대체하지 않는다. 프로필별 세 생성물의 평균·표본SD·범위는 기술값으로 보고한다. 생성물 간 변화와 같은 원문의 판독 반복을 분리한다.
- 모델별9원문×3판독의 정확 일치·세번 동일 수·범위·ordinalα/가중κ와 탐색적 일원ICC를 기술한다. 세 회차 평균 ICC를 단회 운용의 근거로 쓰지 않고 상수 계수의 미정의를1로 바꾸지 않는다. 두 모델 평균의 명목회차별 반복성은 보조로 남긴다. 모델간 점수 차이 자체는 실패 조건이 아니다.
- 보조4축의 수치 분포·불확실/NA/기술결측을 보존한다. 문제/불확실 축에서 같은 환자 턴이 몇 회 지적됐는지 모델별로 연결한다. 문제 수치와 불확실성을 합치거나 보조축을 새 총점으로 승격하지 않는다.
- 기존 M13과의 평균 차이를 입력 정렬의 인과 효과나 환자 프롬프트 개선으로 주장하지 않는다. 단일 정렬 조건에서 새로 생성한 자료이며 비정렬 대조군은 없다.3프로필의 재사용·9개 파생 대화·54반복 판독은 독립 환자54명이 아니다. 모집단CI·임상 타당성·최적화/동등성 주장은 없다.
- 9대화 생성과 예정54판독 또는 기록된 기술 중단에서 끝낸다. 정해진 범위를 다 읽은 뒤 명확한 생성자 결함 한 가지를 다음 후보로 선정하거나 v0.2를 유지하고 주기를 닫는다. 결함을 찾을 때까지 자료·평정을 추가하지 않는다. 이번에는 환자 프롬프트를 수정하지 않는다.
