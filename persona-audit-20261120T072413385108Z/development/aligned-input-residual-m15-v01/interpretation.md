# M15 잔여 문제의 귀속과 판단

## 직접 답

정렬한 자료에서도 **정형적인 긴 표현 재사용**과 **가구원 수의 의미 범위 확장 가능성**은 남았다. 다만 이번9대화에서 명시 사실 모순·역할 이탈·분명한 질문 미대응처럼 새 환자 프롬프트 개입을 바로 정당화할 명확한 사건을 선정하지 못했다. 두 모델의 사실/대응/연속성 미지적만으로 무결함이라고 결론내리지는 않는다.

## 입력 정렬 후에도 남은 가장 일관된 비평

사례2의 정렬된 D08은 다음 진료에서 무슨 이야기를 하고 싶은지 묻는다. 세 생성물의 P08은 안내 방송이 자신을 빗대는 것처럼 느껴져 신경 쓰이는 상황을 다시 이야기하고 싶다는 내용이다. Claude는 세 생성물 모두에서 세 번씩 같은 종류의 정형성 지적을 남겼다. 이는 3생성×3판독의9개 의견이며9개 독립 사례가 아니다.

이 비평은 이전의 진료 전/진료 때 시간 불일치만으로 설명되지는 않는다. 그러나 P08의 내용은 질문과 goal에 맞고, goal 역시 같은 증상 경험을 다시 언급하도록 작성돼 있다. 표현의 길이·구조를 줄일 수 있는 문체 후보는 있으나, 재진술이라는 기능과 설정 문구의 기여를 분리하지 못했다. GPT의 같은 원문 표현축은 모두2였다. 모델간 차이는 실패 조건이 아니며, 어느 문체 규범이 임상적으로 옳은지도 이번에 정하지 않았다.

**처리:** 반복된 실제 지적은 수용해 후보로 보존한다. 이를 객관적인 환자 결함·임상적 비현실성으로 승격하는 판단과, 같은 사실 답변을 모두 금지하는 수정은 보류한다. 원점수는 그대로 둔다.

## 가구원 수 후보

사례2 생성2/3의 P02에는 ‘둘이’가 있다. 환자 설정은 성인 딸과 함께 산다고만 정했다. 배타적인2인가구 확정으로 해석하면 근거 범위가 넓어진 것이다. 관용적 동거 응답과의 경계도 남아 있어 작성자 사전 노트에서 `boundary`로 고정했다. 반복 출현은 같은 프로필에서 이런 표현이 재현된다는 관찰이며 의미 정답 자체를 바꾸지는 않는다.

새 판독의 사실축은 두 모델 모두 해당 두 원문에서2·2·2였다. 지적이 없다는 이유로 정확하다고 선언하거나, 아직 확정하지 않은 오류를 판독자가 놓쳤다고 선언하지 않는다. 해당 차원의 입력 미정 상태도 보존했다. 이번에 다른 동거인 부재나 가구원 수를 임의로 설정에 덧붙이지 않았다.

**처리:** 의미 범위 후보로 보류하고 실제 문장을 보존한다. 이 자료만으로 v0.5와 같은 일반 범위 금지문을 다시 추가하지 않는다.

## 정당한 반응과 판독 경계

- 사례1 생성3 P07의 수면 기록 목표는 수면 질문과 관련되고 자발적 덧붙임이 허용된다. P08은 목표를 다시 묻는 질문에 대한 짧은 재확인이다. Claude의3회 문체 지적을 남기되, 앞으로 나올 고정 질문 순서에 맞춰 환자가 침묵해야 한다고 요구하지 않는다.
- 사례1 생성2와 사례3 생성2/3의 P05는 의사가 발생 시기를 다시 물어 같은 시간 정보를 재진술한 답변이다. Claude도 두 지적에서 불확실성을 표시했다. 필요한 사실을 지우는 반복 억제는 정당화되지 않는다.
- 사례1 생성1의 첫 Claude 판독은 ‘망설임이나 감정의 결’이 부족하다고 총점3을 줬지만 보조4축은 모두2였다. 같은 원문의 이후 판독은4·4였다. 주어진 의사소통 설정과 확보되지 않은 임상 기준을 넘어 망설임을 필수로 추가하지 않는다. 전체 인상과 보조축이 일대일 대응하지 않는다는 사실을 보존한다.

## 반복성의 현재 한계

GPT는 총점27개 모두4여서 단순 반복 일치100%지만α/ICC는 미정의다. Claude는6/9원문에서 세 점이 모두 같고21/27쌍이 일치했다. α0.518519, 탐색ICC(1,1)0.538462였다. 생성1/2/3의 서로 다른 글에서 나타난 차이와 같은 글을 다시 읽을 때 생기는 차이는 다른 축이다.

이 자연 대화 배치에서3/4점 경계가 흔들린 점을 숨기지 않는다. M12/M13의 계수가 모든 후속 자연 발화에 대한 보증은 아니다. 전체 점수의 반복성, 사례2 P08 지적9/9의 국소 반복성, 문체 비평의 임상적 옳음은 별도로 읽는다. 이를 이유로 정한54회 뒤에 평정을 추가하거나 좋은 점수를 선택하지 않았다.

## 이번 주기의 종료

전체9대화·72턴·54평정을 보존했고 입력 귀속을 이유로 대화를 사후 삭제하지 않았다. 작성자 사전/사후 검토는 비맹검 연구 노트이며 독립 전문의 평가가 아니다. 세 프로필만 재사용했고 비정렬 대조군이 없으므로 이번 평균3.6667을 입력 정렬의 개선 효과로 해석하지 않는다.

현재는 명확한 환자 프롬프트 개입을 선택하지 않고 v0.2를 유지한다. 남은 두 종류의 후보와 정확한 지적을 다음 연구 판단의 근거로 남기며, 결함을 찾을 때까지 자료를 추가하지 않는다. 환자 모듈이 최적화됐거나 모든 입력 원인을 제거했다는 결론은 아니다. 최종12사례·720회 계획·평가 기준도 그대로다.
