# M15: 범위를 맞춘 입력에서 남는 생성 문제 확인

2026-11-19 KST. **9개 새 대화·72환자턴 생성과 54/54회 실제 판독을 완료했다.** M13의 개발 프로필 3개를 재사용해 각각3회 새로 시작했다. 최종12사례의 내용은 열람·사용하지 않았다. 생성은 기존 v0.2와 GPT-6.1 Sol High, 평가는 GPT-6.1 Sol High/Claude Opus5.5 medium의 대화별 새 세션 각3회다. 환자 프롬프트·모듈·평가 역할·앵커·파서는 그대로다.

## 무엇이 남았는가

**정렬한 질문에서도 문체·의미 범위의 문제 후보는 남았다. 다만 이번 자료에서 즉시 환자 프롬프트 수정 대상으로 삼을 명확한 생성 결함은 선정하지 못했다.**

- **사례2 P08의 긴 표현 재사용:** 세 생성물 모두 첫 호소의 증상 표현을 마지막 목표 답변에 다시 엮었다. Claude가 각 생성물을3회씩, **9/9판독**에서 정형성으로 지적하고 표현 보조축1점·총점3점을 줬다. 진료 전/진료 때의 불일치를 맞춘 뒤에도 남은 일관된 문체 비평이다. 다만 질문이 같은 경험에 관해 이야기할 주제를 묻고 goal 자체도 그 경험을 재지칭한다. 내용은 설정에 맞으므로, 정당한 재진술과 불필요한 문구 반복 사이의 경계·입력 문구의 기여를 분리하지 못했다. 임상적 부자연스러움이나 생성기 고유의 확정 결함으로 선언하지 않는다.
- **가구원 수의 경계:** 사례2 P02에 ‘둘이’가 **3생성 중2회** 나왔다. 프로필은 성인 딸과 동거한다는 것만 명시한다. 가구원 수를 더 단정했을 가능성을 생성 전 고정한 분류에 따라 경계 후보로 남겼다. 두 평가자 모두 해당 원문의 사실축을3회 모두2점으로 줬다. 미지적은 무오류 증명도 탐지 실패의 증명도 아니다.
- **정당할 수 있는 반응:** 사례1의 수면 기록 목표 추가/P08 재확인, 사례1·3의 발생 시점 재진술에 일부 Claude 문체 지적이 있었다. 관련 자발성과 의사가 다시 물은 데 대한 답변을 자동 결함으로 삼지 않았다.
- **명시적 사실 모순·역할 이탈·질문 미대응:** 작성자 사전 원문 검토에서 명확한 사건을 선정하지 못했고 두 모델도 사실근거·질문대응·연속성에서 모두2점을 줬다. 이는 검토 범위의 미관찰이지 전체 무결함·최적화·임상 타당성의 증거가 아니다.

## 점수와 반복성

전체 평균은 **GPT4.0000, Claude3.3333, 두 모델 평균3.6667/4**다. 사례1/2/3의 두 모델 평균은 **3.6111/3.5000/3.8889**다. 전체54개 원평점과 모든 생성물을 보존했다.

GPT총점27개는 모두4였고 반복쌍27/27이 같았다. 상수이므로α/ICC는 미정의다. Claude는9원문 중6개에서 세 점이 모두 같았고 반복쌍 **21/27=77.78%**, ordinalα **0.5185**, 탐색적ICC(1,1) **0.5385**다. 이 자연 대화 배치에서는 3/4점 경계가 흔들렸다. M12/M13의 높은 계수를 일반적 보증으로 쓰거나 이번 계수와 직접 전후 비교하지 않는다. 특히 작은 총점 차이를 개발 우열로 확정할 수 없다. 사례2 P08 비평의 국소 반복성9/9와 전체 총점의 반복성은 구별한다.

양 모델의 사실근거·질문대응·연속성은 각각27개 모두2였다. GPT표현축도 모두2, Claude표현축은1점16개/2점11개이며불확실true2개였다. 총점과 보조축을 합산하거나 원점수를 수정하지 않았다. 스키마54/54통과·인용불일치0, 유효 총점54개·보조 수치216개다.

## 입력과 분석의 범위

24개 프로필별 문항을 생성 전에 대조했다. 첫 질문의 ‘가장’을3곳에서 빼 미기재된 다른 불편과의 우선순위 비교를 요구하지 않았고, 사례2 D08을 진료 때 이야기할 주제로 정렬했다. 나머지20문항·환자 사실·의사소통·시작 이력은 유지했다. 동거인 전체 수처럼 미정인 차원을 임의로 채우지는 않았다.

새 판독 전에72턴을 모두 읽어 작성자 정성 노트를 남기고 첫 수치 판독 전 해시 동결했다. 이 노트를 평가자에게 주지 않았다. 판독 후 지적은 사건별로 연결해 입력·생성자·경계·허용 반응을 구별했다. 같은 사건의 여러 인용·축·모델·회차를 독립 오류로 합산하지 않았다. ‘입력 문제 제외’는 귀속의 구분이며 낮은 점수 대화를 삭제한 절차가 아니다. 모든9대화를 유지했다.

이번은 정렬된 단일 조건의 새 생성이다. 입력 정렬의 인과 효과나 환자 프롬프트 개선을 입증할 비정렬 대조군이 없다. 전체 입력 원인을 제거했다고 선언하지 않는다. 세 재사용 프로필·각3생성·두모델각3판독은 독립 환자54명이 아니다. 확정 결함을 찾을 때까지 범위를 늘리지 않고 **v0.2를 유지한 채 이 배치를 종료**했다. 환자 프롬프트는 수정하지 않았다.
