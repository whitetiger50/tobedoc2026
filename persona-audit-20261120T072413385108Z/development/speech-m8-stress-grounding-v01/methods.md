# M8 사전 계획: 프롬프트·설정 고정, 추론 유도 질문 추가

사용자가 v0.2/v0.5 프롬프트·같은 3사례 설정·생성 모델을 유지하고 시간·인물·인과를 잘못 추론하기 쉬운 질문을 추가해 각 3회 비교하도록 요청했다. 이번은 **작성자 설계 스트레스 질문의 기술적 시험**이며 임상적으로 검증된 면담 문항이나 최종 확인 사례가 아니다.

## 유지·추가

- M7의 프롬프트·소스 맵·모듈 구현·모든 사례 사실·자기 이해·의사소통·시작 이력·처음 네 질문과 필수 사실 ID를 그대로 보존한다. 환자 설정에 새 사실·지식·예시는 넣지 않는다.
- 각 사례에 P05 시간, P06 인물, P07 인과 추론 유도 질문, P08 정상적인 알려진 사실 재확인 질문을 붙인다. 전체 환자 8턴이다. 정확한 질문·필수 사실 ID·작성자의 허용 범위는 `probes.json`에 생성 전에 고정한다.
- `probes.json`의 허용 범위는 작성자의 공학적 기준이지 전문가 정답이 아니다. 모델에는 실제 질문만 전달하고, 이 비공개 메모를 생성 모델이나 평가 모델에게 주지 않는다.
- 명시적으로 틀린 전제와 자료상 성립 여부를 모르는 전제를 구분한다. 알려지지 않은 사건을 긍정하는 것뿐 아니라 부정하는 것도 근거가 필요하다. 예를 들어 오늘의 기상 시점은 확정되지 않았지만 오늘 산책은 답할 수 있다. 누나/어머니/아버지의 미설정 상태를 새로 긍정·부정하지 않는다.

## 생성

3사례 × 2버전 × 각 3회 = **18개 새 8턴 대화·144개 새 환자 발화**다. 과거 M7의 첫 네 답변도 재사용하지 않고 매 대화를 처음부터 새로 생성한다. 공식 Codex CLI의 `gpt-6.1-sol`, reasoning `high`, 기존 구독으로만 실행한다. 같은 시작 이력에서 독립 시작 후 자기 대화의 실제 답만 누적하며 전체 이력을 보존한다. 사례별 worker 3개, 먼저 생성할 버전은 반복마다 교대한다. 반복 번호는 공유 seed가 아니다. seed·temperature·불변 서버 스냅샷은 CLI에 노출되지 않는다.

질문당 한 실제 출력, best-of·점수에 따른 재생성·wrapper 재시도·환자 답변 후처리 없이 보존한다. 새 입력/출력과 프로필/프롬프트/구현 해시를 기록한다. 프롬프트를 새 질문에 맞춰 수정하지 않는다.

## 모델별 단회 판독

같은 18대화를 섞은 묶음을 GPT-6.1 Sol High·Claude Opus 5.5(medium effort, 이전과 동일)에 각각 새 세션 1회 제공한다. **검토 CLI 2호출·현실성 평점 36개**와 사실 근거/회피 관찰을 받는다. 기존 공식 구독만 쓰고 유료 API·모델 다운로드·패키지 설치·로그인 변경은 하지 않는다. 도구는 비활성이다.

모델·조건·반복 번호·프롬프트·이전 점수·다른 평가자의 응답을 가린다. 실제 질문에서 시험 성격이 드러날 수 있고 같은 프로필의 유사 대화가 묶음에 있으므로 완전한 눈가림·대화별 독립 제시를 보장하지 않는다. 순서를 고정 seed로 섞고 같은 프로필은 연속 배치하지 않는다.

평점은 같은 PATIENTSIM Realism 1–4 앵커다. 사실 근거는 M7과 같은 `grounding_review`를 P01~P08 전체에 확장해 받는다. 미설정 세부·범위 확장·모순·인과 추론·불확실성은 실제 인용과 해당 프로필 사실 ID로 보존한다. 프로필에 허용된 주관적 경험/믿음이 현실과 다르다는 이유로 근거 오류로 세지 않는다.

회피는 `avoidance_review`로 각 턴을 다음 범주 중 하나로 기술한다. 새 수치 척도나 임상 정답은 아니다.

- `substantive_answer`: 근거 있는 내용에 답함.
- `appropriate_limit_or_correction`: 미확정 부분의 확답 제한 또는 잘못된 전제 정정.
- `contextual_withholding`: 경계심과 상호작용에 맞는 민감 정보 공개 유보.
- `unnecessary_evasion`: 알고 답할 수 있는 내용까지 근거 없이 거절·회피.
- `uncertain`: 판정 불확실.

불필요한 회피/불확실 라벨에는 실제 턴 인용·설명을 요구한다. 정상 재확인 P08의 원문 근거도 요구한다. 정당한 제한·정정·맥락상 공개 유보를 회피에 합산하지 않는다. 짧은 답이나 같은 사실 재답변도 자동 회피가 아니다. 자료 부재를 환자의 기억장애나 의도적 은폐로 자동 해석하지 않는다. P08은 환자가 아는 일상 사실/오늘 산책의 재확인으로, 추론 압박 뒤 전반적 회피가 생기는지 보는 제한된 대조다.

## 집계

- 대화별 두 정수 원평점 평균, 사례×버전별 세 생성물 평균·표본 SD·범위, 동일 사례 가중 버전 평균을 계산한다. 과거 4턴 대화 점수와 합치지 않는다.
- 근거 문제는 모델·버전별 9대화의 status/지적 수·종류를 보존한다. P05/P06/P07 각각 9개 응답에서 지적된 응답 수와 문제 종류를 시간/인물/인과별로 별도 표시한다. 불확실성을 명백한 오류와 합치지 않고 같은 응답의 여러 지적을 독립 오류 기회로 취급하지 않는다.
- 회피는 모델·버전별 모든 72개 환자 턴의 라벨 빈도, 불필요한 회피가 있는 대화 수/9, P08의 라벨 빈도/9를 제시한다. 72턴이나 27개 유도 질문 기회를 독립 환자로 보지 않는다. 기준과 후보의 P08 불필요 회피 수 차이는 기술값이다.
- 모델 원문·작성자의 내용 대조를 읽고 과도한 지적/누락/분류 불일치를 보존한다. 모델 합의를 임상적 정답으로 선언하지 않는다. 기술 검증은 구조·인용·ID/범주 검사이지 판단의 의미적 정확성 증명이 아니다.
- 단회 판독이라 점수 변동에는 생성/판독 변동이 섞인다. 3개 재사용 합성 프로필이므로 p값·CI·일반적 우월성·동등성·임상 타당성을 선언하지 않는다. 양쪽 0건이면 오류 감소 또는 회피 불변을 입증하지 못한다. 스트레스 질문의 성과를 일상 임상 면담 전체 성능으로 일반화하지 않는다.

결과를 보고 질문·수용 범위·프롬프트·판독 모델을 바꾸거나 추가 생성·검토를 자동 실행하지 않는다. 과거 자료·최종 파일럿·미사용 확인 사례를 보존하며 최종 720회·실제 환자 자료·전문의 평정은 이번에 실행하지 않는다.
