# M1 실제 발화 검토의 반영 결정

2026-11-18. 같은 고정 묶음을 GPT-6.1 Sol High와 Claude Opus 5.5가 각각 1회 검토했다. 원문은 `reviews/codex/response.txt`, `reviews/claude/response.txt`, 구조·인용 검증본은 각 `validated.json`이다. 각 검토자는 상대 응답과 생성 모델 정보를 받지 않았다. GPT 검토자는 생성 모델과 같은 모델 계열이므로 독립 외부 검증이 아니다.

v0.1에서 생성한 3대화·12환자 발화에 대한 개발 평정: 사례 1은 GPT 4·Claude 3 → 3.5, 사례 2는 4·3 → 3.5, 사례 3은 3·2 → 2.5. 사례 평균은 3.1667/4다. 두 모델은 세 사례 모두 1점씩 차이가 났다. 이 작은 자료로 평가자 신뢰도나 일정한 편향을 추정하지 않는다. 아래 수정으로 평점이 올랐다는 뜻은 아니다.

1. **GPT B-1 / Claude B-1: 수용, 제안 일부 반박.** 사례 3 P03의 “오늘 뭘 했는지는 구체적으로 말씀드리기 어렵네요.”는 미기록 사실을 환자의 회피로 바꾸는 위험을 실제로 보여 준다. `required_fact_ids`를 추가해 작성자가 예정 질문에 필요한 사실 ID를 지정하고, 누락되거나 환자가 모르는 사실이면 생성 전에 `MissingCaseDetail`로 중지한다. 자동으로 기억 문제나 비협조를 채우지 않는다. Claude의 “특별한 건 없었어요” 기본 답 제안은 받아들이지 않는다. 아무 일도 없었다는 것도 미설정 당일에 관한 새 사실이기 때문이다. 예상 질문의 사실을 명시적으로 보완하는 방향을 채택한다. 이 검사는 작성자 주석이 필요하며 임의의 질문에서 누락을 자동 판별하지 못한다.
2. **Claude A-1의 인과 연결: 수용.** 사례 2 P01은 “밤에 깨는 이유”에 “소리가 들려서요”로 답했다. 원 설정은 두 현상을 제시했지만 인과를 정하지 않았다. v0.2는 동시 존재를 인과로 확정하지 않도록 명시한다. 원인 질문을 예정하면 관계에 관한 사실도 의존성으로 지정한다. 기능 확인에서는 ‘환자 본인도 관계를 확실히 모른다’는 새 합성 설정을 생성 전에 추가했다. 이는 원문에서 회수한 사실이 아니며 별도 입력 변경이다.
3. **Claude A-1의 공개 속도: 부분 수용·일률적 규칙은 보류.** 첫 민감 경험 공개가 빠르다는 비평이 있으나, GPT는 걱정을 유지하며 공개하는 흐름을 자연스럽다고 판단했다. 고정 공개 단계나 ‘처음에는 반드시 숨김’을 도입하지 않는다. v0.2에서 설명을 들은 것만으로 공개 범위를 늘리지 않는 원칙을 유지하고, 일부 공개와 걱정의 공존을 허용한다. 어떤 공개 속도가 더 현실적인지는 이 평정으로 확정하지 않는다.
4. **Claude A-2의 반복: 부분 수용.** 사례 2 P03이 이전 답을 길게 되풀이한 점은 보완 대상이다. v0.2에 이전 설명 전체를 복사할 필요가 없으며, 추가 사실이 없으면 짧게 답해도 된다고 명시했다. 반면 면담자가 이웃 관련 질문에 직접 답하지 않았으므로 걱정을 다시 묻는 것 자체를 제거하지 않는다. 표현을 바꾸기 위해 새로운 사건·시간·묘사를 창작하지 않는다. GPT는 이 반복을 자연스럽다고 보았고 Claude도 문맥의 모호함을 인정했다.
5. **Claude B-2의 연상 자기 해설: 부분 수용.** 사례 3 P01은 연상 경험을 정돈된 문장으로 보고했다. v0.2는 스타일을 해설하는 문장을 기본으로 삼지 않고 환자 반응으로 표현하도록 했다. 다만 매번 반드시 탈선하게 하거나 자기 경험 설명을 금지하지 않는다. 단일 판독자의 취향을 새 증상 정답으로 삼지 않는다.
6. **Claude C-1의 질문 밖 정보: 수정 수용.** 사례 1 P02의 “오늘 아침에는 안 들렸어요.”는 밤의 목소리를 어떻게 이해하는지에 대한 질문에서 다소 부가적이다. v0.2는 질문 초점을 먼저 답하고 모든 설정 항목을 채우듯 나열하지 않도록 했다. 관련 있는 자발적 정보까지 일괄 금지하지 않는다.
7. **Claude C-2의 짧은 사실 답변: 변주 강제는 반박.** “오늘 아침에는 집에서 빵을 먹었어요.”는 간단한 사실 질문에 대한 직접 답이다. 이를 반드시 특정 구어 어순으로 바꾸거나 변주 할당량을 두지 않는다. 짧은 답과 자연스러운 표현 선택을 유지한다. GPT는 이 답변에 결함을 지적하지 않았다.

구현: `speech_module/patient_v02.txt`, `core.py`의 사실 의존성 사전 점검과 버전별 패킷 검증, CLI `--require-fact`. 원 v0.1 프롬프트·12발화·평점·원응답은 보존했다. 기존 패킷은 원래 버전의 프롬프트로 검증한다.

후속 기능 확인: 각 사례에서 문제와 관련된 질문 하나씩, 총 3발화만 v0.2로 생성했다. 사례 2의 인과 지식과 사례 3의 오늘 활동은 작성자가 새 가상 사실로 사전 보완했다. 따라서 이 결과를 순수 프롬프트 수정 효과로 해석할 수 없다. 추가 검토·추가 평점은 없고 수정 전 점수를 수정 후 점수로 옮기지 않는다. 개별 출력과 관찰은 `followup-outputs-v02.json`, `README.md`에 남긴다.
