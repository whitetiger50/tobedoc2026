# M2 설계 검토 반영

2026-11-18. GPT-6.1 Sol High·Claude Opus 5.5에 동일한 22,875바이트 자료를 각각 1회 전달했다. 두 원응답은 `reviews/*/response.txt`, 파싱본은 `parsed.json`이다. 자료는 근거·발췌·v0.3 초안·구현 요약이다. 새 환자 발화가 없어 수치 평정이나 평균은 없다. 설계 검토가 원저 전체 또는 임상 타당성을 검증한 것은 아니다.

1. **GPT I1 / 환자 지식과 정정의 우선순위 — 수용.** R7을 수정해 정정은 환자가 알고 이해하는 범위에서만 하게 했다. 모르는 임상 기록을 말하거나 주관적 믿음을 면담자 관점으로 교정하지 않는다. 환자 비인지 사실·상충 전제의 실제 생성 반응은 아직 미확인이다.
2. **GPT I2 + Claude I1 / 누락 정보에서 응답 경로가 닫힘 — 수용.** 프롬프트에 일반적인 회피문을 더하는 대신 v0.3의 live `generate`와 수동 `import_response`에 `question_reviewed=True` 확인을 요구했다. 작성자는 질문에 필요한 사실과 환자의 지식을 확인하고 `required_fact_ids`를 지정한다. 미확인 질문이나 누락된 필수 사실은 모델 호출 전에 보류한다. 오프라인 패킷 준비는 미확인 상태로 가능하지만 출력 실행·가져오기는 막는다. 이는 작성자의 명시적 확인이며 의미적 누락 자동 탐지나 임상 인증이 아니다. 작성자가 잘못 확인하면 여전히 실패할 수 있다.
3. **GPT I3 + Claude I2 / 예시의 내용 오염 — 수용.** 예시는 기본적으로 비활성이다. 활성화하려면 `allow_experimental_examples=True` 또는 CLI `--experimental-examples`를 명시해야 한다. `target_feature`, `author_checked=True`, 합성 출처 표지, 같은 사례의 알려진 fact ID를 요구한다. 작성 지침에는 예문이 새 사건·인과·확신 수준을 추가하지 않는지와 명시한 말하기 특성 범위에 맞는지 확인하도록 했다. R5는 관련 사실의 사용과 무관한 질문으로의 오염을 구분하도록 수정했다. 구조 검사만으로 의미·임상 타당성을 보증하지 않는다. 실제 환자 예문이나 전문의 인증 예문은 이번에 없다.
4. **Claude I3 / 근거 범위가 넓게 표시됨 — 수정 수용.** R6의 주 근거를 E8, 유형을 `local_engineering`으로 한정했다. E5는 프로필 일관성의 배경 참고일 뿐 patient_knows·누락·인과 규칙의 직접 근거가 아니다. R1의 학습한 용어 허용은 연구팀의 예외 설계라고 표시했다. R4는 E4의 문맥 적용성, E3의 사례·이력 사용, 채택하지 않은 CBT·MDD 규칙을 나누었다. 단, PATIENT-Ψ의 원문은 신뢰가 생겼을 때 호전될 ‘수 있다’는 표현이므로 원문 자체가 무조건 자동 호전을 명령한다는 해석은 채택하지 않는다. 우리의 자동 변화 금지는 별도 설계 선택이다.
5. **Claude I4 / 스키마와 변화 범위 설명 부족 — 부분 수용.** README에 각 필드의 의미, 값 누락 시 검증 실패, 임상 특성을 진단명에서 보충하지 않는 원칙을 추가했다. 경계심 필드가 모든 환자에게 경계심을 강제한다는 뜻은 아니다. ‘특별한 경계심 설정 없음’처럼 중립값을 명시할 수 있다. 변화 조건은 기존 서술형 communication에 명시하도록 하고 새 신뢰 수치나 추가 상태 축은 도입하지 않았다. 미지정 변화는 자동으로 가정하지 않는다. 검토 묶음의 구현 요약이 불충분했던 부분이며 실제 스키마가 없었던 것은 아니다.
6. **Claude I5 / 음성·정동을 텍스트로 대체할 위험 — 수용.** 목소리 크기·피치·속도·실제 반응 지연·눈맞춤은 현 출력 채널에서 구현·검증하지 않는다고 명시했다. 말줄임표나 문장 수로 이 항목을 측정하지 않는다. 텍스트로 제공한 감정·걱정의 내용과 실제 정동 관찰을 구분한다.

24개 초안 구조 테스트 후 위 변경을 반영했고 최종 관련 테스트는 27개 통과했다. 입력 버전 보존, 미확인 질문의 모델 호출·수동 가져오기 차단, 예시 opt-in과 작성자 확인, 원문 근거 대응 해시를 확인했다. 최종 수정은 두 검토의 지적에 대한 Codex 반영이며 다시 검토받지 않았다. 원 초안과 검토 입력은 `review-packet.json`, `review-freeze.json`에 보존했다. 새로운 임상 효과·현실성 점수·성능 향상은 주장하지 않는다.
