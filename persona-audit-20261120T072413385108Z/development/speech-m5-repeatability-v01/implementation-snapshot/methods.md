# M5: 9대화 반복성·설정 오류 민감도 점검 — 판독 전 고정

사용자의 명시적 요청으로 이번 묶음에 한해 개발 단회 검토를 **모델별 3회**로 확장한다. 최종 720회 계획과 일반적인 개발 단회 정책은 변경하지 않는다. 환자 프롬프트 수정·새 환자 발화 생성·기존 대화 재생성은 하지 않는다.

## 자료와 변형

- M4의 v0.2/v0.4 원본 6대화(같은 3프로필, 대화마다 환자 4턴)를 그대로 사용한다. M3 원본이나 과거 판독은 합치지 않는다.
- 각 사례의 v0.2를 원본으로 고정해 마지막 환자 답변 P04의 가족 지칭만 바꾼 오류 대조 3개를 만든다. 기준은 사례별 공통 원본 조건과 동일한 턴이며 평정 결과로 원본을 선택하지 않는다. 모두 v0.2 유래이므로 오류 민감도의 조건 간 일반화·비교는 하지 않는다.
- 사례 1: `어머니하고 같이 살아요.` → `아버지하고 같이 살아요.` 설정과 앞선 작성 문맥의 동거인에 모순.
- 사례 2: `누나가 와보라고 했어요.` → `엄마가 와보라고 했어요.` 설정과 앞선 작성 문맥의 면담 권유자에 모순.
- 사례 3: `아니요, 아버지랑 같이 살고 있어요.` → `아니요, 어머니랑 같이 살고 있어요.` 설정의 동거인에 모순.
- 각 변형은 한 턴의 가족 지칭 한 곳만 변경한다. 문장 수·질문·다른 환자 답변·프로필·시작 이력·Unicode 문자 수는 보존한다. 새 진단·증상·치료 내용을 넣지 않는다. 인위적 작성자 오류 대조이며 생성 모델의 실제 실패로 세지 않는다.

## 판독

GPT-6.1 Sol High와 Claude Opus 5.5(medium effort, 이전과 동일)를 기존 공식 구독 CLI로 각각 3회 호출한다. **6개 CLI 세션 × 9대화 = 54개 평점**이다. 각 세션은 별도 임시 작업 폴더·도구 비활성·비영속 문맥을 사용한다. 이전 점수, 다른 검토자의 응답, 버전, 원본/오류 여부, 프롬프트 원문을 제공하지 않는다. 같은 라운드의 두 모델에는 정확히 같은 입력을 제공한다.

매 라운드 순서와 무의미한 식별자를 고정 seed로 새로 배정하고 동일 프로필을 연속 제시하지 않는다. 아홉 대화가 한 묶음에 있으므로 관련 원본/변형의 유사성을 알아볼 수 있다. 완전한 눈가림이나 개별 대화별 문맥 독립성은 보장하지 않는다. 라운드 사이에는 이전 응답을 전달하지 않는다. 서버 스냅샷·temperature는 CLI에 노출되지 않아 통제 한계로 남긴다. 캐시 응답을 복사해 반복으로 세지 않으며 wrapper의 자동 재시도·best-of는 없다.

기존 PATIENTSIM Realism 1–4 앵커와 M4 판독 역할을 유지한다. 역할의 대화 개수와 예시 ID만 바꾼다. 오류에 대한 감점 규칙·오류 존재 힌트·정답 점수는 추가하지 않는다. 구조·정수 범위·대상 완전성·환자 원문 인용의 실제 존재를 Python으로 검증하고 원응답을 보존한다. 실패하면 누락으로 기록하며 더 나은 응답을 얻기 위한 재호출은 하지 않는다.

## 사전 분석 규칙

1. 대화별·모델별 세 원평점, 평균, 최소–최대, 표본 SD, 반복 쌍 3개 중 정확한 일치 비율을 보존한다.
2. 주 반복성 분석은 **원본 6대화만** 사용한다. 모델별 완전 일치 대화 수/6, 반복 쌍 일치 수/18, 범위 2점 이상 대화 수/6, 원평점별 빈도와 최고점 빈도/18을 제시한다. 쉬운 오류 대조를 섞어 반복성 수치를 높이지 않는다.
3. 오류 대조는 모델별 같은 라운드의 오류−원본 점수와 3회 평균 차이를 계산한다. 엄격히 낮은 경우만 탐지로 세고 동점은 탐지가 아니다. 평균이 낮은 쌍 수/3과 라운드별 하락·동점·상승 수/9를 함께 보존한다. 후자는 독립 오류 9종이 아니다.
4. 대화별 개발 참고값은 두 모델의 3회 평균을 동등하게 산술평균한다(총 6개 원평점의 평균과 같다). v0.4−v0.2를 사례별로 구하고 3사례에 같은 가중치를 준다. 과거 M4 단회 평점을 추가하지 않는다. 모델별 원평점과 방향도 남긴다.
5. 원본 6대화에서 같은 라운드의 두 모델 점수 일치 수/18도 기술한다. 모델 간 합의가 임상적 정답이라는 뜻은 아니다.
6. 3프로필의 기술적 점검이다. p값·CI·최종 파일럿 합격/탈락·임상 타당성·일반적 우월성·동등성은 선언하지 않는다. 점수는 순서형이며 평균은 기술값이다. 반복 단위를 독립 환자로 취급하지 않는다.

## 보존

계획·입력·식별자 연결표·역할·소스·프롬프트·최종 파일럿 파일의 해시를 판독 전에 동결한다. 모든 CLI 입력·명령·원출력·파싱 응답·확인 메타데이터를 모델/라운드별로 보존한다. 프롬프트는 점수와 무관하게 이번 단계에서 수정하지 않는다. 전문의 평정과 실제 환자 발화는 없다.
