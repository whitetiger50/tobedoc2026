2026-11-19 KST. 사용자 최신 요청에 따라 다른 개발보다 평가 신뢰도 확인을 선행한다. 평가 모델은 기존 GPT-6.1 Sol High·Claude Opus5.5 medium만 사용한다. 각 대화는 각 모델에 서로 다른 새 세션으로3회 제시한다. 최종12프로필은 열람·사용하지 않는다. ## 자료와 추정 대상

기존3개 개발 프로필의 M6 v02/v04 생성3(4환자턴)과 M9 none/examples 생성3(8환자턴)을 경로·반복번호로 먼저 정했다. 원문12개는 의미 입력 해시도 서로 다르다. 과거 점수를 기준으로 원문을 골라낸 것은 아니다. 생성 모델은 모두 공식 구독의 GPT-6.1 Sol High였다.

이 중 M6-v02 원본3개에서 각1턴의 동거 사실만 명백히 반전한 작성자 대조3개를 만든다. 사례1 P04는 어머니와 동거를 부정하고 혼자 산다고, 사례2 P02는 누나와 동거하며 혼자가 아니라고, 사례3 P04는 아버지와 동거를 부정하고 혼자 산다고 바꾼다. 조작 전후·대상 턴·프로필 living 근거·선행 발화는 corpus.json에 있다. 사례1은 작성된 이전 환자말에도 모순이며 사례2/3은 그 전 대화에 동거 부정/긍정이 없으므로 명확한 앞선 자기모순까지 강제하지 않는다. 대조는 모델이 생성한 발화로 표시하지 않는다.

자연12개×2모델×3회=72평정, 대조3개×2모델×3회=18평정, 총90개 단독 세션이다. 주 신뢰도는 자연12개만 계산한다. 큰 오류 대조로 점수 범위를 넓혀 주계수를 부풀리지 않는다.4턴6개/8턴6개, 프로필별 기술도 분리한다. 자연12개는12독립프로필이 아니라3프로필×4조건이며 생성단계·질문·길이가 함께 달라 조건/길이 효과를 분리하지 못한다.

목표는 **이3개 개발 프로필에서 선정한 고정12원문과 이번 동결 운영체계에 조건부인 반복성·두 모델의 일치·정해진 텍스트 대비의 순서**다. 프로필 미사용/임상/모집단 신뢰도를 확보했다고 하지 않는다. 역할 개발에 쓴 과거 원문과 생성3을 나누었지만 작성자가 일부 생성3도 이미 보았고 같은 프로필을 쓴 한계가 있다.

## 고정 평가 기준

`review-role.txt`와 `score-anchors.json`을 그대로 두 모델·세 반복에 사용한다. 기존 PatientSim Realism_w_Profile 1–4 문구의 psychiatric patient 각색본은 M9 앵커와 문자 단위로 같다. ED→psychiatric 변경과 관사 조정만 한 기존 문구이며 원척도의 임상 타당성을 승계하지 않는다. 주총점은 먼저 출력한다.

보조4축은 사실근거·질문대응·연속성/공개흐름·당사자 표현이다. 각각0=실질적 문제,1=경미한 국소 문제,2=확인한 문제 없음으로 기록하고, 불확실성 boolean과 적용 불가 null을 분리한다. 구체적인 축별 경계·증거 규칙은 역할 원문을 따른다. 사실 축은 고정 프로필, 연속성 축은 앞선 대화 관계가 기준이다. 같은 사건이 두 축에 해당해도 오류 수로 합산하지 않는다. 보조 합계/평균은 만들지 않고 주총점으로 승격하지 않는다.

0/1 또는 불확실 판단에만 정확한 환자 원문 인용을 요구한다. null이고 uncertain=true인 출력은 허용하며 적용 불가 이유를 남긴다. 인용은 선택이다. 인용 검사는 **원문 코드포인트의 비어 있지 않은 부분문자열**로 고정한다. NFC·공백·문장부호·따옴표를 사후 정규화하지 않는다. 인용 불일치는 숫자 평정과 별도 품질 항목이며 이미 존재하는 유효 숫자를 지우지 않는다.

G-Eval은 차원별 기준 명시와 구조화출력 아이디어의 참고이며, 원연구의 차원별 호출·auto-CoT·토큰확률가중을 재현하지 않는다. 우리 단일호출4축/0–2앵커나 한국어 조현병 타당성의 검증 근거가 아니다. RatingRoulette는 동일 조건의 재평정을 self/intrarater reliability로 분리하는 선례이며3회가 충분하다는 표본수 근거로 쓰지 않는다. 자세한 출처·직접 확인 범위는 references.json을 읽는다.

단독 제시와 보조 rubric을 함께 도입한 **새 통합 운영체계의 반복성**을 검증한다. 과거 묶음 평정과 합치지 않고, 차이를 단독 제시나 rubric의 인과 효과로 해석하지 않는다. 먼저 출력하라는 지시가 halo를 제거한다고 가정하지 않는다.

## 판독 절차와 격리

한 호출에는 비식별 프로필의 의미 내용·작성된 이전 문맥·해당 대화 하나만 들어간다. 버전·생성자·원문ID·원점수·대조 여부·멘토 비평은 넣지 않는다. 외부 schedule의 opaque ID로만 slot을 대응한다. 한 텍스트의 입력 본문과 역할은 두 모델·세 반복 모두 동일하다. 역할문의 사실ID 예시는 중립 `fact:<ID>`이며 조작 표적ID를 알려주지 않는다.

기존 공식 구독 CLI의 빈 임시 cwd, 도구·사용자설정·메모리·세션지속 차단, resume/continue 미사용 경로를 쓴다. 입력·역할·명령·원 stdout/stderr·원응답·시각·CLI버전·명시 모델 별칭/Claude modelUsage·해시를 보존한다. 불변 서버스냅샷·temperature·seed는 노출되지 않아 고정됐다고 주장하지 않는다. 다른 모델이나 유료API로 우회하지 않는다.

각 provider는15개 블록의 사전 무작위 제출 순서와 원본/대조 최소3위치 간격, 인접 프로필 구분을 사용한다. 최대2개 병행이며 완료 순서는 다를 수 있어 실제 slot 시각도 기록한다. 블록을 마친 후 다음 반복으로 간다. 새 문맥은 이전 결과 공유를 막지만 서비스 내 확률적 독립을 증명하지 않는다.

## 사전 분석

주 보고는 원평정·분포·직접 불일치와 계수를 함께 제시한다. 계수만으로 임의 통과 판정을 하지 않는다.

- 모델별 자연12개 전체: 세 원점수, 정확 일치쌍(최대36쌍), 세번 모두 같은 원문 수, 범위·절대편차·대화 내SD, ordinal α와D_o/D_e, 선형 가중κ의1–2/1–3/2–3회 조합. 상수의 미정의와 낮은 유한값을 구별한다.
- 반복 세션을 교환 가능한 측정으로 가정한 **일원 절대일치 ICC(1,1)/(1,3)**을 보조적 등간 민감도 지표로 사전 지정한다. 블록에 시간 변화가 있을 수 있으므로 교환 가능성이 확인된 사실이라고 하지 않는다. 이원 ICC(A,1)/(A,3)를 추가 민감도로 기록한다. ICC(1,3)는 세 회차 평균이며 단회 운용의 근거가 아니다. 음수 추정은0으로 자르지 않는다.
- 두 모델 산술평균의 회차별12×3행렬도 같은 분석을 한다. 각 셀은 같은 명목 회차의GPT/Claude 두 점수 평균이다. 명목 회차의 짝짓기가 독립 표본을 만든다고 하지 않는다.
- 모델 간에는 각 명목 회차의 단회12×2행렬을 따로 보고한다. 또한 각 모델의3회 평균을 두 열로 넣은12×2행렬의 고정모델 이원 절대일치 ICC도 따로 보고한다. 후자는3회 평균 모델 간 일치이지 단회 일치가 아니다. 각 텍스트의 독립재호출3×3조합의 일치·부호 차이도 텍스트별 같은 가중치로 기술한다.9조합을9독립 관측으로 세지 않는다.
- 보조축은 축별 α·숫자 불일치·주변분포, NA/기술결측의 개수, NA 상태와uncertain flag 자체의 반복 일치를 구별한다. 숫자 축과 불확실성을 합산하지 않는다. 같은 턴을 반복 지적했는지도 원자료로 읽는다.
- 프로필3개로 주95%CI를 보고하지 않는다. 프로필 하나를 뺀3가지 결과를 기술 민감도로 제시하고 신뢰구간 의미를 부여하지 않는다. 더 많은 원문/반복을 독립 프로필인 것처럼 세지 않는다.

## 정해진 대비와 대조

자연12개에서 프로필별 M6 v04−v02와 M9 examples−none의6텍스트 대비를 미리 정한다. 각 모델의3×3점수조합을 높음/동점/낮음으로 보고하고, 반대 방향이 모두 관측됐는지 기술한다. 운영평균은 한 원문의 GPT3회×Claude3회로 가능한9평균값, 두 원문 사이81조합을 기술할 수 있으나 이는 원평정 재사용이며81새판독/독립표본이 아니다. 동점을 억지 승패로 만들지 않는다. 어떤 패턴도 프롬프트의 일반적 우월성으로 해석하지 않는다.

대조는3쌍 각각의 원본/조작3회 분포를 나란히 보인다.1차 확인은 조작 턴을 실제로 인용했는지·grounding0인지·실제 living 사실을 참조했는지를 분리해 보고한다. 이를 만족한 결과는 정한 조작의 지목이라는 운영 정의이며 임상 오류 탐지율이 아니다. grounding의 감점 방향, 원본 기저가 이미0이었는지, 총점의 감점 방향은 각각 따로 남긴다. 동일 조작유형·v02원천4턴에 제한된다.

## 실패·결측·정지

slot별 한 번만 호출한다. 좋은 결과 선택·평점 변경·자동 재시도·형식 수정을 위한 새 추론은 없다. JSON fence를 벗기는 결정적 파싱 외에는 누락값이나 숫자를 보충하지 않는다. 부분 응답에서 유효한 숫자는 보존하고 인용·이유·다른 축의 오류는 별도 표시한다. null은 의미적NA, 필드 누락/부적절한 타입은 기술 결측이다. α는 유효값을 사용하고 ICC는 해당 행렬의 완전 행만 사용해 분모·제외 원문 수를 공개한다.

예정90개 응답 완료 또는 기록된 기술적 중단에서 멈춘다. 기술 실패가 발생하면 해당 provider는 이미 진행 중인 응답을 보존하고 새 slot 제출을 멈춘다. 쿼터를 유료API나 모델 변경으로 우회하지 않는다. 미완료를 완료로 쓰거나 missing을 추정하지 않는다.

결과 패턴의 해석도 미리 제한한다. 자연 총점이 상수면 이자료에서 순위정보 없음, 같은 원문의 점수가 바뀌면 세션 변동 존재, 대조에서 보조만 바뀌면 총점의 해당 결함 반응이 약한 가능성, 대조에도 변화가 없으면 이조작 반응 근거 부족으로 보고한다. 모두 자료 조건부 기술이다. 보조축이 더 잘 나와도 같은 세트에서 주 지표로 승격하거나 예문/기준을 고쳐 재판독하지 않는다. 일반 신뢰도·정밀CI·임상타당성·최종720완료를 선언하지 않는다.
