# M18 · 같은 새 대화에 적용한 기존 Realism과 CCF-R1

**CCF-R1이 필요한 재진술에 대한 지적을 줄이는 양상은 관찰됐다. 그러나 반복 신뢰도나 미세한 발화 질의 구분력이 개선됐다는 결론은 지지하지 않는다.** 자연 대화에서는 두 기준 모두 모델 내부의 유효 반복값이 상수였다. CCF-R1은 최고점 집중이 더 커졌고, Claude의 경험 재지칭 대조에서는 3/4 경계가 남았다. 강한 반복·질문 미대응·보고식 표현 대조는 양쪽 기준 모두 명시적으로 지적했다. 현재 주지표를 교체하거나 환자 프롬프트를 수정하지 않았다.

## 실제 수행과 보존

최종 12사례를 읽지 않고 새 합성 개발 프로필 3개를 작성했다. 환자 raw v0.2와 GPT-6.1 Sol High를 고정해 각 프로필에서 3번 새로 시작한 9대화, 72환자 발화를 실제 생성했다. 각 프로필의 첫 생성물에서 5가지 작성자 조건을 만들었다. 필요한 재답변 P 3개는 원래 답과 이미 동일해 판독을 공유했다. 총 24조건행, 21고유 평가 입력이다. 자연 원문을 점수에 따라 편집·선별·재생성하지 않았다.

21고유 입력 × 2기준 × 2모델 × 3회 = **252개 공식 구독 CLI 응답**을 모두 수신했다. GPT-6.1 Sol high와 Claude Opus 5.5 medium이 매번 대화 하나만 새 문맥에서 판독했다. 각 기준의 동일 대화 입력은 바이트까지 같았고 역할 지시만 달랐다. 판독 역할은 기존 M12 Realism 및 M17 최종 CCF-R1 제안과 각각 바이트 동일하다. 별도 Astra high와 Claude high는 설계 최초·후속을 각각 2번 비평했으며 수치 판독에 합산하지 않았다. 자동 재호출·전송 실패·유료 API 호출은 0이다.

유효 JSON 기반 총점은 **251/252**다. 기존 Realism 126/126, CCF-R1 125/126이다. Claude CCF의 `DEV-M18-01-rep01-v02` 3회 응답은 JSON 구조가 잘못되어 동결 파서에서 총점·네 축을 결측으로 보존했다. 원문에는 `realism_score:4`가 보이지만 사후 JSON 수리나 정규식 추출로 주분석을 채우지 않았다. 이 한 건을 다시 평가하지 않았다.

## 동일 모델 내부의 반복 일관성

주 분석은 작성자 대조를 섞지 않은 자연 9대화다. 한 대화의 세 판독에서 생기는 세 쌍은 서로 종속된다.

- **GPT, 기존 Realism:** 27평점 모두 4. 반복쌍 27/27 일치, 세 번 동일 9/9대화, 평균 4.000.
- **GPT, CCF-R1:** 27평점 모두 4. 반복쌍 27/27 일치, 세 번 동일 9/9대화, 평균 4.000.
- **Claude, 기존 Realism:** 27평점 모두 3. 반복쌍 27/27 일치, 세 번 동일 9/9대화, 평균 3.000.
- **Claude, CCF-R1:** 유효 26평점 모두 4. 가용 반복쌍 25/25 일치, 완전한 세 번 동일은 8/8완전대화다. 나머지 한 대화는 `[4,4,결측]`이며, 계획 9대화 중 완전 3회 일치가 확인된 것은 8개다. 평균 4.000.

네 셀 모두 관측 범주가 하나이므로 **순서형 α와 탐색 ICC(1,1)는 미정의**다. 관측 일치 100%라는 정보는 유효하지만 원문 간 미세한 질 차이를 재현성 있게 나눌 수 있는지는 확인할 수 없다. Claude의 기준 간 주 대응 비교는 양쪽 3회가 완전한 동일 8대화이며, 이 자료에서도 기존은 모두 3, CCF는 모두 4다. 두 기준은 구성개념과 앵커가 달라 이 상승을 환자 생성기의 개선량으로 해석하지 않는다.

대조별 반복성도 일률적으로 좋아지지 않았다. G의 GPT 반복쌍은 기존 7/9 → CCF 9/9, Claude는 기존 9/9 → CCF 7/9다. U 전체 3대조의 GPT는 5/9 → 9/9, Claude는 9/9 → 5/9다. F는 두 모델·두 기준 모두 9/9다. X의 GPT는 3/9 → 9/9, Claude는 9/9 → 9/9다. U의 반복성 설명에는 사전 부분 성립으로 분리한 사례3도 포함되며 주 표적 집계와 분모가 다르다.

자연과 대조를 섞으면 기존 GPT α=0.9124, 기존 Claude α=1.0000, CCF GPT α=1.0000, CCF Claude α=0.9347이다. 큰 조작과 부모 공유가 포함된 혼합 계수를 자연 발화의 미세 순위 신뢰도 근거로 쓰지 않는다. 원점수, 세 회차쌍의 가중 κ, ICC와 프로필 하나씩 제외한 기술 민감도는 `results.json`에 전부 보존했다. 모집단 신뢰구간·보편적 통과선은 추정하지 않았다.

## 필요한 재진술의 지적

**직접 재확인 D04:** 자연 9대화 × 3회에서 기존 기준과 CCF 모두, 두 모델 각각 표적 문제 지적 0건이다. Claude CCF의 1건은 판정 불가라 0/26가용, 나머지 세 셀은 0/27이다. 따라서 직접 재확인의 과잉 지적을 CCF가 추가로 줄였다는 증거는 없다. P 3별칭을 독립적인 추가 실험으로 세지 않는다.

**G: 다음 진료 목표에서 경험 재지칭:** 성립한 3대조 × 3판독에서 경험 구절을 실제 인용해 문제로 지적한 기록은 GPT 기존 1/9, CCF 0/9, Claude 기존 9/9, CCF 4/9이다. Claude CCF 나머지 **5/9는 정상 무언급이 아니라 불확실한 경계 언급**이었다. 따라서 판정가능한 4건만 분모로 삼아 4/4라는 ‘오류율’을 제시하지 않는다.

Claude CCF의 실제 G 총점은 사례1 `[3,3,3]`, 사례2 `[4,3,4]`, 사례3 `[4,4,4]`다. 사례2는 같은 원문을 한 번은 ‘이미 전제된 증상 설명의 재시작’, 두 번은 ‘목표에 연결되는 경험 재지칭’으로 읽었다. 기존 Claude는 모두 3점이었다. CCF가 표현 반복을 전혀 못 보는 것은 아니지만 **기능이 있는 재진술과 국소적인 표현 문제를 가르는 판단 경계는 남는다.**

이 수치는 판독 전 작성자의 ‘기능적으로 허용 가능한 재지칭’ 가설과 얼마나 정렬되는지에 관한 것이다. 전문가 참조가 없으므로 임상적 과잉 지적률이 아니다. 재지칭 기능을 인정하면서 표현 형태를 비평하는 것도 가능하므로, G의 모든 감점을 오판으로 확정하지 않았다.

자연 원문의 P08 전체에 대한 기존 Claude의 불리한 인용은 27/27에서 관찰됐으나, CCF는 0건의 확정 지적·23건의 무지적·3건의 불확실 언급·1건 판정 불가였다. 이것도 원문 질 변화가 아니라 기준에 따른 기록 차이다. 기존 Claude 일부 이유는 요구되지 않은 망설임·개인적 반응을 더 기대했다. 해당 문장은 원문 그대로 보존하고 필수 설정 사실과 구분했다.

## 불필요 반복의 누락과 천장

**U: 앞서 한 활동 답을 순간 대처 질문에 재사용:** 판독 전 성립한 사례1·2의 6판독에서 두 모델·두 기준 모두 표적 문제를 **6/6 지적**했다. 각 판독에서 반복 문제와 질문 미대응을 함께 확인할 수 있었다. 사례3은 활동 장소와 경험 상황이 겹쳐 사전 부분 성립으로 분리했으며 원점수는 전부 보존했다. U는 순수한 반복 효과를 검증하지 않는다.

**F: 세 턴의 같은 보고식 도입·종결 틀:** 두 모델·두 기준 모두 9/9판독에서 표적을 지적했다. 세 턴은 한 패턴이므로 독립 오류 3개로 세지 않는다. 형식 반복과 보고 말투의 영향을 분리할 수 없다. **X: 제삼자 환자 소개 문구**도 네 셀 모두 9/9 지적했지만 이는 역할 이탈 표적이며 반복 누락 분모에 포함하지 않는다. X의 이유문에 다른 턴의 반복이 함께 등장한 경우를 반복 표적 탐지로 잘못 세지 않도록 저자 주석에서 연결을 보수적으로 남겼다.

주 U/F 표적의 명시 지적 미관찰은 네 셀 모두 0이다. 그러나 강하고 작성자 정의에 가까운 대조에서의 결과라 실제 미묘한 반복을 놓치지 않는다는 증명은 아니다. CCF가 기존보다 누락을 줄였다는 추가 이득도 이번 자료에서는 확인하지 못했다. U/F/X에서 4점으로 남은 응답은 모두 0건이다.

자연 대화의 최고점 비율은 GPT 두 기준 27/27, Claude 기존 0/27, Claude CCF 26/26이다. **CCF의 자연 유효 총점은 두 모델 모두 전부 최고점이다.** G에서는 GPT 기존 8/9 → CCF 9/9, Claude 기존 0/9 → CCF 5/9다. 강한 대조는 최고점 아래로 구분하지만, 현재 자연 대화에서 세밀한 개선량을 재는 총점으로서는 최고점 집중 문제가 남는다. 반복 일치와 천장은 함께 관찰된 것이며 인과관계가 입증된 것은 아니다.

## 출력 규약의 문제

기존 Realism의 엄격 스키마 통과는 GPT 63/63, Claude 63/63이다. CCF는 GPT **7/63**, Claude **14/63**이다. CCF 105응답에서 하나 이상 스키마 오류가 있었다. 이 중 102응답은 참조 표기 어휘만 문제였고, 3응답은 관찰의 `function` 누락 2건 또는 JSON 구조 오류 1건을 포함했다. Claude CCF의 추가 관찰에 원문을 말줄임표로 연결한 정확 인용 오류 1건도 있다. 해당 공통 필드의 유효 인용·숫자는 다른 필드 오류 때문에 삭제하지 않았다.

이 문제는 내가 만든 **CCF 출력 문안과 검증기의 참조 규약이 충분히 맞지 않았던 점**도 반영한다. 문안은 프로필·의사소통의 실제 참조를 요구하면서 예시 뒤에 ‘등’을 썼고, 검증기는 기존 `fact:<실제ID>`, `turn:<실제ID>`, `authored_context`만 허용했다. 모델은 실제 입력의 `communication.expression`, `patient_profile.self_understanding` 등을 자주 적었다. 이것을 미설정 환자 사실의 생성이나 무의미한 참조로 단정하지 않는다. 원응답과 엄격 판정은 유지했으며 사후 별칭 치환으로 통과율을 높이지 않았다.

출력 길이도 기존 GPT 평균 1,145자·Claude 1,191자에서 CCF GPT 4,074자·Claude 3,281자로 늘었다. 자동 정합성 경고는 0건이나 이는 구현된 검사 범위에서의 결과이며 모든 의미적 정합성을 검증한 것은 아니다. `operational-diagnostics.json`에 셀별 분모·오류·원응답 위치를 기록했다. 이 상태로 CCF를 최종 운영 기준으로 채택하지 않는다.

## 이유문 검토와 해석의 한계

집계 점수와 모델/기준 대응키를 열기 전에 공통 이유문을 정확 문자열 해시로만 중복 제거해 **1,236개 고유 텍스트**를 읽고 주석을 고정했다. 252개 가림 행에는 JSON 실패 1개의 추출 불가 행도 포함되며, 그 원문 전체는 집계 개방 후 확인했다. 숫자 필드는 가렸지만 일부 이유문 안의 등급 숫자, 불리함 표지, 문체는 드러났다. 완전 맹검이나 독립 재평정이 아니다. 저자 주석은 새 품질 점수가 아니고 기계 집계를 바꾸지 않았다.

추출기의 ‘인용 없는 표적 반복 주장’에는 P04를 명시적으로 허용하면서 다른 턴을 지적한 기존 Claude 자연 응답 2건이 들어갔다. 이는 단순 턴명 연결의 한계이며 **P04 과잉 지적 2건으로 해석하지 않는다.** 정확 표적 인용을 요구한 주 집계는 0건을 유지한다. 반복 지적·다른 표적 문제·허용·불확실 범주는 중첩될 수 있다.

3합성 프로필, 부모 공유 대조, 반복 추출이라는 조건부 실험이다. GPT는 생성과 판독에 같은 모델 계열을 사용했고 실제 서버 스냅숏·시드·온도는 고정할 수 없었다. 새 세션은 별개의 임상 판독자가 아니다. 환자 원자료·전문의 평정·임상 타당성은 없다. 최종12/720은 사용하지 않았다.

## 이번 주기의 판단

환자 v0.2는 유지한다. CCF-R1은 **맥락 기능을 기록하는 보조 도구의 후보**로 남기고 원래 Realism 주지표를 자동 교체하지 않는다. 반복 점수를 더 얻는 것만으로 이번 상수·경계·출력 규약 문제를 해결했다고 보지 않는다.

다음 평가 체계 작업의 우선순위는 출력 문안과 파서의 참조 규약을 명시적으로 맞추는 일이다. 그 뒤 미묘한 표현 반복과 필요한 재지칭을 기능·표현의 별개 관찰로 남기는 경계 사례를 검토할 수 있다. 이를 근거 없이 총점의 더 많은 단계로 쪼개거나 이미 사용한 자료의 점수를 다시 받아 성공으로 만들지 않는다. 이번 요청의 정한 252회는 종료했으며 추가 호출·새 기준·환자 프롬프트 수정은 수행하지 않았다.

원자료 `runs/`, `inputs/`, `reviews/`; 사전 기록 `generation-freeze.json`, `author-prejudge-audit.json`, `freeze.json`; 모든 점수와 통계 `results.json`; 기계 추출과 저자 해석 `author-claim-extraction.json`, `author-extraction-summary.json`; 실제 기록 대조 `verification.json`; 설계 비평 `../../collaboration/strategy/M18-rubric-comparison-v01/`를 함께 보존했다.
