# M13: 고정 평가체계의 단계 대조 구분력 검증

2026-11-19 KST. **108/108회 실제 판독을 완료했다.** 새 개발 프로필 3개에서 기존 raw v0.2와 GPT-6.1 Sol High로 기준 원문 3대화·24환자턴을 생성했다. 같은 P02만 편집한 작성자 대조 15개를 더해, 18텍스트를 GPT와 Claude가 대화별 새 세션에서 각각 3회 평가했다. 최종 12사례의 내용은 열람하거나 사용하지 않았다.

환자 생성 프롬프트·모듈, M12의 평가 역할·앵커·파서는 그대로다. Astra와 별도 Claude high의 최초·후속 설계 비평을 각각 2회 받았으며, 실제 응답과 지적별 판단을 보존했다.

## 결과

- **표현 대조 총점:** 원문 → 격식 표현 → 명백한 설정 보고의 두 모델 평균은 **3.4444 → 3.0000 → 2.0000**이었다. 격식 N1은 18평정 모두 3점, 역할 이탈 N2는 18평정 모두 2점이었다. 이 인접 두 단계는 두 모델·세 프로필·세 반복에서 구별됐다. 원문과 격식 표현은 일부 셀에서 동점이므로 모든 3단계가 항상 분리된 것은 아니다.
- **사실 대조 총점:** 원문 → 사소한 미설정 층수 → 핵심 동거 사실 반전은 **3.4444 → 3.0000 → 3.0000**이었다. F1과 F2는 두 모델에서 각각 9평정이 모두 3점으로, 총점에서 분리되지 않았다. 반면 사실근거 보조축은 F1의 18판독 모두 **1점**, F2의 18판독 모두 **0점**이었고 실제 편집 구절을 지목했다. 문제를 인식하는 것과 전체 점수 범주를 달리 주는 것은 구별된다.
- **같은 평가자의 총점 반복 일치:** GPT **52/54쌍=96.30%**, 세 번 모두 동일한 원문 **17/18개**, ordinal α **0.9510**. Claude **50/54쌍=92.59%**, **16/18개**, α **0.8557**. 큰 조작을 섞은 고정 자료의 계수이므로 M12보다 신뢰도가 개선되거나 하락한 효과로 해석하지 않는다.
- **의미보존 대조 I:** 전체 평균은 원문과 I 모두 **3.4444**였지만, GPT는 **3.6667→3.7778**, Claude는 **3.2222→3.1111**로 작은 차이가 반대 방향으로 상쇄됐다. GPT 사례2 I는 3·4·3, Claude 사례3 원문은 4·4·3/I는 3·4·3이었다. 평균 동점만으로 동등성이나 미세 점수 차이의 안정성을 확보한 것은 아니다.
- **응답 검증:** 유효 총점 108개·보조 수치 432개, 스키마 108/108 통과, 인용 불일치 0건이다. 72개 조작 판독 모두 목표축 0/1점·정확한 P02 인용·변경 단어를 함께 기록했다. 이는 12개 작성자 편집을 각 6번 읽은 결과이며 72종의 독립 오류나 임상 탐지율이 아니다.

조건 순서 R/I/F1/F2/N1/N2의 모델별 평균은 GPT **3.6667/3.7778/3/3/3/2**, Claude **3.2222/3.1111/3/3/3/2**다. 원점수·프로필별 인접/양끝 대비는 `results.json`에 있다. 모델 간 점수 일치 자체를 성공 조건으로 삼지 않는다.

## 설계와 해석 범위

[CheckList](https://aclanthology.org/2020.acl-main.442/)의 의미보존·방향 기대 행동검사 개념을 참고했다. 이번 조작과 단계는 저자 정의이며, 그 문헌이 한국어 조현병 발화의 임상 등급을 검증한 것은 아니다. N2는 노골적인 ‘설정되어 있다’ 표현이다. 관측한 차이를 미묘한 자연 발화의 문체 전반으로 일반화하지 않는다. 주총점과 탐색 보조축을 합산하거나 보조축을 사후에 주지표로 승격하지 않았다.

**사례2는 원래 적격성·중단 규칙에서 이탈했다.** 원문의 ‘다 큰 딸/둘이’를 생략하지 않도록 I/N의 세 편집문을 원문 열람 후, 수치 판독 전에 개정하고 진행 예외를 기록했다. 원문 재생성이나 선택은 없었다. ‘둘이’ 자체가 프로필에 없는 가구원 수 구체화일 수 있다는 기저 문제도 남겼다. 이 사례를 제외한 두 프로필에서도 N1/N2 총점은 각각 3/2, F1/F2는 각각 3/3으로 주요 패턴이 같았다. 전체를 변경 없는 생성 전 사전등록이라고 보고하지 않는다.

결론은 **정한 표현 대조는 총점에서, 정한 사실 대조는 보조축에서 구별됐고, 두 사실 단계의 총점 구별은 확인되지 않았다**는 것이다. 같은 자료의 작은 총점 차이를 임상적 개선으로 선언하거나, 결과에 맞춰 기준을 바꾸고 재판독하지 않는다.
