# M13 사전 생성 고정

최종12사례의 내용을 열지 않고 DEV-M13-01/02/03 세 개의 신규 합성 개발 프로필을 작성했다. 기존 M0 세 프로필과도 다르다. 프로필별8개 중립 면담 질문과 필수 사실을 `cases.json`에 고정했다. 실제 환자 또는 임상가 인증 설정이 아니다.

raw v0.2 프롬프트·기존 모듈·공식 GPT-6.1 Sol high 경로를 유지한다. 각 프로필에서1대화만 생성하고 각 질문에 첫 응답 하나만 쓴다. 총24개 실제 환자역할 출력 계획이다. 이전 실제 응답 전체를 다음 질문의 이력에 넣는다. 후보 선택·재생성·출력 수정은 없다. 모델 별칭·CLI설정은 기록하되 불변 서버스냅샷·temperature·seed 고정은 주장하지 않는다.

P02가 동거 사실에, P04가 아침식사에 직접 답하도록 질문과 알려진 사실을 사전 대조했다. 모든 조작 대상은 P02로 통일했고 정확한 치환문을 `perturbation-spec.json`에 생성 전에 고정했다. 생성 후에는 적격 조건 충족 여부, 이미 존재하는 근거/표현 문제, 앞뒤 같은 사실의 재언급을 점수 없이 기록한다. 기준원문이 최상이라는 가정은 하지 않는다. 부적격 원문도 버리거나 재생성하지 않는다. P02의 명제 불일치나 후속 같은 사실 재진술 등 사전 적격 조건이 불충족이면 조작불가를 기록하고 수치판독 전 중단한다. 대체 턴이나 재생성은 하지 않는다. 치명적 입력/기술 오류이면 보존하고 중단한다.

생성 설계는 Astra/별도 Claude의1차 설계 비평 반영을 `generation-decision.md`에 기록한 뒤 동결한다. 실제 원문·편집 대조·명제보존표를 작성해 후속 설계 검토를 받고, 첫 수치 판독 전에 역할/입력/순서/분석까지 별도 동결한다. 환자 생성 프롬프트와 M12 평가 역할·앵커·파서는 변경하지 않는다. 최종12자료는 내용 열람 없이 바이트 해시만 보존 확인한다. 최종720, 유료API, 새 모델/패키지 사용은 없다.
