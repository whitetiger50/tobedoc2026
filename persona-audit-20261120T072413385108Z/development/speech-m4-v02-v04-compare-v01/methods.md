# M4: v0.4 생성과 v0.2 동일 입력 비교 명세

2026-11-18. 이번 작업은 M3의 정보 공개·반복 비평을 반영한 v0.4를 만들고, 사용자가 지정한 v0.2와 비교하는 개발 실험이다. 출력 전 `plan.json`과 프롬프트·구현 해시를 고정했다. 이 명세는 평점을 보기 전에 작성했다.

## 변경 범위

v0.3의 R4 정보 공개와 R7 대화 연속성만 변경했다. 질문이 사실 재확인인지 추가 설명인지 구별하고, 이미 공개한 정보·아직 공개하지 않은 관련 정보·해소되지 않은 걱정을 따로 고려하도록 한다. 같은 짧은 사실 답과 답을 듣지 못한 걱정의 반복은 허용한다. 추가 설명을 위해 설정 밖 사건·감정·인과를 만들지 않는다. 환자가 이전 말을 참조하는 특정 문구를 쓰도록 강제하지 않는다.

민감 경험의 공개 흐름은 경계심·질문의 구체성·실제 상호작용에 따르도록 했다. 확인을 먼저 하는 것, 일부를 말하면서 우려를 남기는 것, 공개를 제한하는 것 중 한 순서를 모든 사례에 강제하지 않는다. 이미 일부를 공개했다고 나머지도 전부 말하게 하거나, 처음부터 다시 숨기게 하지 않는다. 공개 지연·확대의 고정 일정은 없다.

이 변경은 M3 모델 비평과 사용자 제약에 대한 개발 가설이다. M3의 두 모델이 공개 속도의 적절성에 동의한 것은 아니며, 새 규칙이 임상적으로 검증되었다고 주장하지 않는다. `patient_v04.sources.json`은 이전 문헌 근거와 이번 개발 판단을 구분한다.

## 동일하게 고정한 것

- **사례·설정·질문:** M3의 `plan.json`에서 세 사례의 `input`, `questions`, `required_fact_ids`를 그대로 복사했다. 새 환자 사실·감정·반응 조건을 추가하지 않았다. M3의 공통 입력에는 당시 사전 보완한 약물 지식 상태·수면 인과 지식·당일 활동이 이미 들어 있다. 원 설정 파일은 변경하지 않는다.
- **시작과 후속 이력:** 각 사례의 시작 문맥은 두 조건 및 M3와 같다. 이후 각 조건의 실제 새 답변을 자신의 전체 이력에 누적한다. 따라서 후속 이력은 프롬프트의 이전 응답에 따라 달라질 수 있다.
- **모델·접근:** 공식 Codex CLI와 기존 ChatGPT 구독의 `gpt-6.1-sol`, reasoning effort `high`. 노출되지 않는 temperature·불변 서버 snapshot을 고정했다고 가정하지 않는다. 두 조건 모두 예시를 사용하지 않는다.
- **표본:** 각 조건에서 세 사례×4환자 턴, 총 6대화·24새 발화다. 과거 v0.2 출력을 재사용하지 않고 이번에도 새로 생성한다. 답변을 골라 쓰거나 자동으로 재시도하지 않는다.
- **순서:** 사례 1·3은 v0.2 먼저, 사례 2는 v0.4 먼저다. 세 사례는 병렬로, 사례 안에서는 조건별 순차로 진행한다.
- **검토:** GPT-6.1 Sol High와 Claude Opus 5.5가 같은 6대화를 각각 한 묶음으로 1회 검토하고 대화마다 원평점 1개를 준다. 기존 PATIENTSIM Realism 1~4 앵커의 정신과 맥락 적응을 유지한다. 프롬프트·버전명·생성 출처·과거 평점·상대 검토자의 응답은 숨긴다. 공유 프로필·문체로 짝이나 조건을 추측할 수 있어 완전 맹검을 보장하지 않는다.

## 집계와 해석

각 대화의 두 원평점 산술평균, 사례별 v0.4−v0.2, 세 사례를 같은 비중으로 한 조건 평균을 계산한다. 각 검토자의 조건 평균·차이와 원문 근거도 보존한다. 누락 평점이나 인용 오류를 임의로 대체하지 않는다. 이번 검토는 각 1회로 끝내며 추가 평정을 요청하지 않는다.

평균 차이와 반복·정보 공개에 대한 지적을 함께 보고 개선 여부를 판단한다. 점수가 오르더라도 새로운 설정 모순이나 일괄적인 공개 지연이 생겼는지 원문을 읽는다. 이 비교는 v0.2와 v0.4의 전체 차이이며 R4/R7만의 독립 효과를 추정하는 실험은 아니다. 조건당 생성 1회, 개발 사례 3개이므로 일반적 우월성·통계적 유의성·반복 안정성·임상 타당성을 주장하지 않는다.

GPT 검토자는 생성 모델과 같으므로 독립 외부 임상 평가가 아니다. M3 등 과거 평점을 이번 점수와 합치지 않는다. 최종 720회 판독·전문의 평가·미사용 확인 사례는 이번에 실행하거나 사용하지 않는다.
