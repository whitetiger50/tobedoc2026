# M7 사전 계획: v0.2 기반 사실 경계만 수정한 v0.5

사용자 요청에 따라 v0.2의 사실 범위 부분에 세 문단만 추가한다. 평소 경향/특정 날짜, 빈도·확신·인물·사건 관계를 보존하고, 서로 다른 사실을 합쳐 새 사건 순서를 만들지 않으며, 근거 없는 수식만 덜어낸다. 임상 표준이 아니라 M6 관측에 따른 공학적 가설이다. `make_v05.py`와 `diff-v02-v05.patch`에 정확한 변경이 있다.

## 유지 범위

- 원래 v0.2의 모든 문장을 보존하고 `의사소통과 질문 대응`부터 끝까지 공개·반복·환자 역할 규칙이 문자 단위로 같음을 검사한다. v0.4의 공개/반복 지시를 옮겨 오지 않는다.
- 사례 설정·질문·필수 사실 ID·시작 이력은 M6 계획에서 그대로 복사한다. 새 시간 범위 필드·사실·예시를 입력에 추가하지 않는다. 예시는 비활성이다.
- v0.5는 명시적 `V05_VERSION` 후보로 등록한다. 기존 기본값 v0.4를 바꾸지 않고, 비교 호출에서는 항상 v0.2/v0.5를 명시한다. v0.5에는 기존 v0.3 이후의 작성자 질문 확인·소스 해시 경계를 유지한다. 이 메타데이터는 모델 입력을 바꾸지 않는다.

## 실제 실행 계획

3사례 × 2버전 × 3회 = **18개 새 대화**, 환자 4턴씩 **72개 새 발화**를 생성한다. 이전 생성물을 첫 반복으로 재사용하지 않는다. 공식 Codex CLI의 `gpt-6.1-sol`, reasoning high, 기존 구독을 사용한다. 각 대화는 같은 시작 이력에서 독립 시작하고 그 대화의 실제 답만 누적한다. 전체 이력을 유지한다. 사례별 worker 3개, 사례 안에서 먼저 생성할 버전은 반복마다 교대한다. 반복 번호는 공유 seed가 아니다. seed·temperature·불변 서버 스냅샷은 CLI에 노출되지 않는다.

best-of·점수에 따른 재생성·wrapper 자동 재시도·사후 환자 답변 편집은 없다. 추가 규칙의 내부 점검이 실제로 수행됐다고 증명할 수는 없고 관측된 출력으로만 평가한다. 기술 오류와 완료 출력을 구분하고 모두 보존한다.

18대화 묶음을 GPT-6.1 Sol High·Claude Opus 5.5(medium effort, 이전과 동일)에 각각 새 세션 **1회** 제공한다. 총 검토 CLI 2호출·36개 원평점이다. 생성/검토 모두 기존 공식 구독으로만 실행하며 유료 API·모델 다운로드·패키지 설치·로그인 변경은 하지 않는다.

## 판독과 사실 근거 점검

기존 PATIENTSIM Realism 1–4 앵커·기본 역할은 유지하고 사실 근거 관찰을 추가한다. 버전·반복 번호·변경 목적·생성 모델·이전 점수·다른 평가자 응답·환자 프롬프트는 가린다. 같은 18대화를 섞은 묶음과 같은 역할을 두 모델에 제공한다. 고정 seed로 순서를 섞고 같은 프로필을 연속 제시하지 않는다. 유사 대화가 같은 묶음에 있어 관련성을 알아볼 수 있으며 완전한 독립 제시·완전 눈가림은 보장하지 않는다.

각 대화는 score·reason·evidence·issues·uncertainty 외에 `grounding_review`를 받는다. P01~P04를 설정/자기 이해/문맥과 대조하고 `no_issue_identified`/`concern`/`uncertain`을 기록한다. 문제 후보는 실제 환자 인용·사실 ID·문제 종류(`unsupported_detail`, `scope_shift`, `contradiction`, `causal_inference`, `uncertain`)·설정 근거/부재 설명을 남긴다. 이는 새 수치 척도나 임상 정답이 아니다. 없는 사건인지 확정할 수 없는 구체화는 확인 불가 우려로 구분한다. 주관적 믿음이 외부 현실과 다르다는 이유로 설정 오류로 세지 않는다. 자연스러운 바꿔 말하기를 억지로 오류로 만들지 않는다.

모든 대상·정수 점수·실제 인용·검사 턴·허용 범주·프로필 내 사실 참조를 Python으로 검증한다. 구조 검증은 지적의 의미적 정확성 검증이 아니다. 원응답을 직접 읽고 과도한 지적/누락 가능성을 별도로 해석한다. 누락을 추정하지 않으며 추가 평정으로 답변을 교체하지 않는다.

## 사전 집계와 해석

- 대화별 두 원평점의 산술평균, 사례×버전별 세 생성물의 평균·표본 SD·최소/최대, 세 사례에 같은 가중치를 준 버전 평균을 계산한다. 평가자별 점수와 방향도 유지한다. 과거 M6/M5 점수는 합치지 않는다.
- 사실 문제는 평가자별·조건별 9대화에서 status 빈도, 지적 수·종류를 보존한다. 모호한 지적을 명백한 오류와 자동 합치지 않는다. 작성자의 원문 판정은 모델 평점과 구분하고 임상의 주석으로 표시하지 않는다.
- **v0.2에서도 문제가 관측되지 않으면 v0.5에서 0건이어도 오류 감소 효과를 입증했다고 하지 않는다.** 희귀 사건의 바닥 효과와 이번 질문의 한계를 기록한다. 더 어려운 질문·오류 대조·추가 호출을 결과를 보고 자동으로 만들지 않는다.
- 회피나 지나친 정보 축소로 지적이 줄었는지도 원문과 Realism에서 확인한다. 정보 공개/반복 규칙을 유지했다고 생성 행동까지 같다고 가정하지 않는다.
- 문자열 시퀀스 고유 수와 문자 수 범위는 기술값으로 남긴다. 점수 변동에는 생성과 단회 판독 변동이 섞인다. 3사례를 독립 환자 18명처럼 취급하지 않는다.
- p값·CI·일반적 우월성/동등성/최적화·임상 타당성은 선언하지 않는다. 최종 720회·미사용 확인 사례·전문의 평가·실제 환자 발화는 없다. 평정 후 프롬프트를 재수정하지 않는다.
