# M7: v0.2 기반 사실 범위만 수정한 v0.5 비교

2026-11-18. v0.5를 구현하고 같은 3사례·설정·질문·시작 이력·GPT-6.1 Sol High에서 v0.2/v0.5를 각각 새로 3회 생성했다. **18개 새 대화·72개 실제 생성 환자 발화**가 완료됐고, GPT-6.1 Sol High·Claude Opus 5.5에 같은 묶음을 각각 1회 검토받아 **36개 원평점과 사실 근거 관찰**을 얻었다. 생성 72호출·검토 2호출이며 기존 공식 구독만 사용했다.

**평균은 v0.2 3.9444/4, v0.5 3.8333/4, 차이 −0.1111점이다.** 두 평가자는 v0.2에서 근거 문제를 지적하지 않았고, v0.5에서는 같은 한 대화의 주체 모호함을 `uncertain`으로 남겼다. 명백한 미설정 사건 추가가 줄었다는 효과는 이번 자료에서 확인하지 못했다. 기준 버전에서도 해당 문제가 관측되지 않는 바닥 효과가 있어, 후보의 오류 감소·일반적 우월성·동등성을 주장하지 않는다.

## v0.5의 정확한 변경

`speech_module/patient_v05.txt`는 v0.2 원문에 **사실 범위 문단 세 개만 추가**했다.

1. 사실의 인물·시간·일상/특정날·빈도·확실성 범위를 유지한다. 일상적 경향을 특정 날짜의 경과로 바꾸거나 가능성을 확정으로 강화하지 않는다.
2. 별개의 사실에 공통된 행동이 있어도 시간 범위와 관계를 자동 합치지 않는다. 평소 행동 순서와 특정 날짜의 일부 행동이 주어졌다고 그 순서의 다른 행동도 당일 있었다고 확정하지 않는다. 모델 자신의 이전 덧붙임도 자동 근거가 되지 않는다.
3. 답변에 담기로 한 내용 중 근거 없는 구체적 주장·수식만 덜어내고 나머지 사실·말투는 유지한다. 새 거절·기억 문제·무지로 대체하지 않고, 이 점검을 기존 공개·반복 규칙을 바꾸는 근거로 삼지 않는다.

v0.2의 기존 문장을 삭제하거나 고치지 않았다. **`의사소통과 질문 대응`부터 끝까지 공개·반복·역할 규칙은 문자 단위로 같다.** `diff-v02-v05.patch`와 구조 테스트에서 확인했다. 새로운 사례별 답변 예시, 시간 범위 입력 필드, 자동 후처리·필터·재생성은 추가하지 않았다. 실제 내부 점검 수행 여부는 관측할 수 없고 결과 발화로만 평가한다.

구현 경로:

- 프롬프트: `speech_module/patient_v05.txt`.
- 출처/변경 범위: `speech_module/patient_v05.sources.json`. 이번 추가는 M6 개발 사례와 사용자 지시에 따른 공학적 설계이며 임상 근거가 직접 검증한 조현병 지시로 표시하지 않았다.
- 등록: `speech_module.core.V05_VERSION = "schizophrenia-speech-m7-v0.5"`.
- 비교 호출은 항상 버전을 명시했다. 기존 기본값 `VERSION`은 v0.4로 남겨 과거 호출의 의미를 보존했고, 후보의 자동 승격은 하지 않았다. v0.5 사용 시 `module_version=V05_VERSION`을 명시한다.
- 기존 v0.3 이후의 질문별 작성자 확인·소스 맵 해시는 유지한다. 가상 예시는 사용하지 않았다. 작성자 확인 메타데이터는 모델에 보낸 사례 내용을 바꾸지 않는다.

## 비교 조건과 검토

M6 `plan.json`에서 `case_id`, `input`, `questions`, `required_fact_ids`를 그대로 복사했다. 같은 시작 이력에서 새 대화 18개를 만들고, 각 대화 안에서 자신의 실제 답변만 누적했다. 질문당 1회 실제 생성이며 출력 선택·best-of·점수에 따른 재생성·환자 발화 사후 편집은 없다. 같은 생성 번호는 실행 블록이지 두 버전에 공유한 난수 seed가 아니다.

생성은 공식 Codex CLI의 `gpt-6.1-sol`, reasoning effort `high`다. 판독은 같은 GPT 설정과 공식 Claude Pro CLI의 `claude-opus-5-5`, effort `medium`이다. 불변 서버 스냅샷·temperature·seed는 노출되지 않아 고정했다고 주장하지 않는다. 입력·명령·시각·원응답·메타데이터를 모두 보존했다.

평가자에게 버전·반복 번호·변경 목적·환자 프롬프트·생성 모델·과거 평점을 가렸다. 같은 프로필의 유사 대화가 한 묶음에 있어 완전한 눈가림이나 대화별 독립 제시는 보장하지 않는다. 입력 순서는 섞고 같은 프로필을 연속 제시하지 않았다. 이전과 같은 Realism 1–4 앵커를 사용했고 모든 환자 턴의 사실 근거 관찰을 추가했다. M6는 흐름 관찰, 이번은 근거 관찰을 함께 요청했으므로 과거 점수를 직접 합치거나 문맥이 동일하다고 가정하지 않는다.

## 원평점과 변동

아래 값은 새 생성 1·2·3 순서다. 대화별 두 원평점의 산술평균을 구한 뒤 세 생성물·세 사례에 같은 가중치를 줬다.

- 사례 1 v0.2: GPT **4·4·4**, Claude **4·4·4** → **4·4·4**, 그룹 평균 **4.0000**, SD **0**, 범위 **4.0–4.0**.
- 사례 1 v0.5: GPT **4·4·4**, Claude **4·4·4** → **4·4·4**, 그룹 평균 **4.0000**, SD **0**, 범위 **4.0–4.0**.
- 사례 2 v0.2: GPT **4·4·4**, Claude **3·4·4** → **3.5·4·4**, 그룹 평균 **3.8333**, SD **0.2887**, 범위 **3.5–4.0**.
- 사례 2 v0.5: GPT **4·4·4**, Claude **3·3·3** → **3.5·3.5·3.5**, 그룹 평균 **3.5000**, SD **0**, 범위 **3.5–3.5**.
- 사례 3 v0.2: GPT **4·4·4**, Claude **4·4·4** → **4·4·4**, 그룹 평균 **4.0000**, SD **0**, 범위 **4.0–4.0**.
- 사례 3 v0.5: GPT **4·4·4**, Claude **4·4·4** → **4·4·4**, 그룹 평균 **4.0000**, SD **0**, 범위 **4.0–4.0**.

전체 **v0.2 3.9444, v0.5 3.8333, 차이 −0.1111점**이다. 사례별 차이는 **0/−0.3333/0점**이다. 평가자별 평균은 GPT **4.0000/4.0000**, Claude **3.8889/3.6667**이다. GPT는 모든 18대화에 최고점을 줬다. Claude는 4점 14개·3점 4개였다.

이 SD는 세 생성물에 부여된 점수의 표본 SD로, 생성과 단회 판독의 변동이 함께 들어 있다. 평가자 하나가 매번 같은 점수를 주는 것은 임상적 정확성 인증이 아니다.

## 사실 근거: 모델별 관찰

두 모델은 **같은 결과 분포**를 남겼다.

- v0.2: 각 모델에서 **9/9대화 `no_issue_identified`**, concern 0, uncertain 0, finding 0.
- v0.5: 각 모델에서 **8/9대화 `no_issue_identified`, 1/9 `uncertain`**, concern 0, finding 1.
- 두 finding은 서로 다른 오류 두 건이 아니라 **같은 한 대화의 같은 표현에 대한 두 평가자의 지적**이다. 단순 합산해 후보 오류가 두 배라고 쓰지 않는다.
- 지적된 문장: 사례 2, v0.5, 생성 3, P04 **“누나가 잠을 잘 못 자니까 와보라고 했어요.”**

설정은 환자 본인의 수면 문제로 누나의 권유를 받아 왔다는 것이다. 이 문장도 그 뜻으로 자연스럽게 읽을 수 있지만, 문장 구조만 보면 누나가 잠을 못 자는 것으로 읽힐 수 있다. GPT는 구어체 주어 생략 자체는 부자연스럽지 않다며 Realism 4점, Claude는 주체 모호함으로 3점을 줬다. 두 모델 모두 이를 명백한 인물 변경/새 사실이라고 확정하지 않고 **불확실성으로 보존**했다.

작성자도 평가 점수를 읽기 전에 같은 모호함을 기록했다(`author-grounding-observations.json`). 수용 결정은 **‘주체 모호함 우려를 보존’**이며, ‘누나에게 수면장애를 새로 만들었다’는 확정 판정은 하지 않는다. 모든 구어적 생략을 금지하거나 평정 후 문장을 고쳐 저장하지 않는다.

사례 3은 두 버전 각 3회 모두 오늘 산책과 평소 기상/일과를 구분했다. **오늘의 기상 시점을 추가한 발화는 이번에는 양쪽 모두 관측되지 않았다.** 따라서 M6의 v0.4에서 나타났던 문제를 v0.5가 없앴다고 비교하면 안 된다. 이번 대조군은 새 v0.2이고, 여기서도 0건이었다.

명백한 모순·새 사건·인과 추가가 확인되지 않았다는 것은 이번 3프로필·네 질문에서의 **미지적**이다. 모든 주장을 임상적으로 검증했거나 발생률이 0이라는 뜻이 아니다. model status의 구조·인용·프로필 내 사실 ID를 검사했지만 판단의 의미적 정확성이 자동으로 검증되지는 않는다.

## 점수가 낮아진 이유와 공개·반복 유지

평균 차이는 사례 2의 Claude 점수에만 집중됐다.

- v0.2 생성 1과 v0.5 생성 1·2: P01/P03의 이웃 전달 우려가 거의 같은 문장 틀로 반복돼 다소 기계적이라는 지적이다. GPT는 답을 듣지 못한 우려의 자연스러운 재확인으로 보고 전부 4점을 줬다. Claude 자신도 같은 상황에서 어느 정도 반복이 자연스러운지 모호하다고 적었다.
- v0.5 생성 3: 위 주체 모호함이 감점 사유다. 이 대화는 우려 표현 자체는 달라졌다고 Claude도 보았다.
- v0.2 생성 2·3: Claude는 우려를 유지하되 표현이 달라 자연스럽다고 4점을 줬다.

이것은 facts 규칙의 변경이 임상적으로 더 나쁘다는 입증이 아니다. 부가 지시가 전체 출력 분포에 영향을 줄 가능성과 생성/판독 변동이 남는다. **공개·반복 규칙의 텍스트가 같다는 것은 실제 단어 선택·행동·점수까지 같음을 보장하지 않는다.** 지적은 보존하되 이번 요청 범위를 넘어 반복 표현·공개 속도 지시를 고치지 않았다.

원문상 사례 2는 양쪽 세 번 모두 P01에서 원인 불확실성과 이웃 전달 우려를 말하고, P03에서 소리 경험을 처음 공개했다. 관찰당한다는 믿음을 직접 말한 대화는 없었다. 사례 3은 양쪽 세 번 모두 오늘 산책을 P03에서 처음 답했다. 과거 다른 실행의 v0.2가 공개를 유보했던 결과와 이번을 합쳐 같은 확률이라고 가정하지 않는다.

## 이번 결정

1. **v0.5 구현은 완료했지만 개선 효과는 미확인**이다. 사실 근거 문제가 적은 기존 사례라 감소 효과를 판별하기 어려웠다.
2. 주체 모호함은 두 평가자와 작성자가 공통으로 남긴 제한적 우려로 수용한다. 명백한 새 사실로 재분류하거나 반대로 높은 점수 때문에 지우지 않는다.
3. 반복 표현 지적은 미해결 우려의 재질문이라는 정당성과 함께 보류한다. 표현 다양성 자체를 목표로 설정 사실을 바꾸지 않고, 반복 규칙도 수정하지 않는다.
4. 후보를 최고점 버전으로 자동 승격하거나 평정 후 재수정하지 않는다. 추가 오류 대조·질문 변경·판독·생성은 이번 결과를 보고 자동 실행하지 않는다. 최종 미사용 사례와 720회는 그대로 남긴다.

## 검증과 재현 자료

- 관련 모듈 구조·호환성 테스트 **40개 통과**. v0.5가 세 문단만 추가했는지, 사례 입력 해시가 두 버전에서 같은지, 과거 v0.2/v0.3/v0.4 패킷이 검증되는지, 작성자 확인 경계가 유지되는지 포함한다. LLM 행동/임상 효과를 증명하는 테스트는 아니다.
- 집계·근거 인용 fixture **2개 통과**. 같은 자료의 평균과 근거 집계는 Python으로 처리했다.
- `verification.json`: 18개 실제 대화, 72개 실제 생성 호출·원문·이력 연결, 2개 실제 검토 호출·36평점, 동결 파일 해시, 같은 평가 입력, 근거 인용·사실 ID, 별도 조건 평균 재계산, 공개/반복 원문 동일성을 확인한다.
- 계획·정확한 조건: `methods.md`, `plan.json`; 원문과 모델 증거: `runs/{case}/rep{01,02,03}/{v02,v05}/`와 각 턴의 `transport/`.
- 검토 원응답: `reviews/{codex,claude}/response.txt`, 검증 JSON `validated.json`; 숫자와 근거 집계: `scores.json`.
- 판독 전 작성자의 원문 관찰: `author-grounding-observations.json`. 실제 인용은 확인했지만 임상의·독립 인간 주석이 아니다.
- 당시 구현·역할·프롬프트·방법: `implementation-snapshot/`; 시각화: `patient-speech-v02-v05-grounding.canvas.tsx`.

3개 재사용 합성 프로필과 18대화의 기술적 비교다. p값·CI·일반적 우월성/동등성/최적화·임상 타당성을 선언하지 않는다. 실제 환자 발화·전문의 평정·새 학습·유료 API·새 모델·새 패키지·자격 증명 출력은 없었다. 과거 파일과 최종 파일럿 계획은 보존했다.
