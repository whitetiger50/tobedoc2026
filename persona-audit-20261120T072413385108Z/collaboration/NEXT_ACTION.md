# 다음 활성 작업 · 기존 면담이 무엇을 측정할 수 있었나

**Astra 책임, Sol 실행.** 두 환자 연구의 근거표는 M23의 patient-language-evidence-brief.md로 완료했다. 다시 문헌을 검색하거나 새 실험안을 만들지 않는다. 이번에 확인할 질문은 **기존 합성 면담을 만들 때, 두 연구의 현상을 같은 정의로 볼 기회가 실제로 있었는가**이다. 포스터에 과장 없이 쓸 결과 문장을 정한다. 여기서 확정하는 것은 현재 증거로 말할 수 있는 경계다. 문헌 요약과 측정 예비연구를 마쳐도 조현병 언어를 LLM이 어디까지 재현하는지는 미해결이며 장기 목적은 유지한다.

1. 개발 누적 수가 기록된 기존 집계/레지스트리의 식별자를 출발점으로 삼는다. 그중 **개발용으로 명시적으로 확인한** 입력의 과제 명세·질문 스크립트·메타데이터만 읽는다. 최종12/720·민감자료·미분류 파일과 실제 출력/평정은 읽지 않는다. 일괄 디렉터리 탐색으로 보호자료를 재료에 넣지 않는다. 참여자나 자료를 새로 모집하지 않는다.
2. 그림·같은 사건에 대한 명제 기준, 동일 이야기에 대한 사전 문맥 및 질문구조의 비교 여부를 각 개발 입력군에서 확인한다. ‘표적과 동일한 조건’, ‘부분 기회’, ‘다른 과제’, ‘입력기록 부족’을 근거 파일 위치와 함께 표시한다. 일반 면담에 긴 대답이나 비슷한 단어가 있다는 이유로 동일 과제로 분류하지 않는다. 그림이 없다고 해서 언어현상도 없었다고 결론 내리지 않는다.
3. 확인한 고유 개발 입력군/대화 수와 미연결·미확인 범위를 적는다. 108대화·663턴이라는 누적 집계와 연결해 검증할 수 있는 범위까지만 표시한다. 모호한 부분은 그대로 미확인으로 둔다. 독립 관찰 단위와 문장 수를 혼동하지 않는다.
4. **완료 파일 1개**를 collaboration/strategy/M23-astra-led-operations-v01/opportunity-audit.md에 저장한다. 근거 목록, 적용 가능/불가능/미확인 이유, ‘실제로 관찰한 것·현 설계가 시험하지 못한 것’을 나란히 쓴 포스터용 문장 두 개를 포함한다. 일치 기회가 발견되면 해당 입력과 인과 해석 한계를 기록한다. 이번 카드는 실제 발화 재채점까지 확장하지 않는다. 입력이 불충분해도 확인된 범위만으로 산출물을 닫는다.

**상한:** 활성 작업 1회, 45분 권장, 완료 파일 1개, 새 자료·발화·평정·외부 연락 0회. 일반 처리에는 Sol과 로컬 코드만 사용한다. Astra는 증거와 주장 문장의 일치를 결정한다. 새 임상 주장을 추가하려는 실질적 이견이 생길 때만 Opus 별도 문맥 1회 이내. 권한이 필요한 작업은 현 카드에 없다. 기회 확인 또는 결손을 기록한 뒤 같은 질문의 재감사를 반복하지 않는다.
