- 개발 평균·최종720계획의 패널/중앙값 집계·미사용 사례 보호는 변경하지 않았다. 기존구독·유료API금지·과거파일보존도 유지한다.

사용자 지시로 현재 개발 단계의 검토 횟수와 집계 방식을 간소화한다. 이 문서가 이전 인계문의 개발 검토·720회 판독 시점 설명보다 우선한다. 과거 요청·원응답·설계 파일은 당시 기록으로 보존한다.

## 최신 지시: 전략 멘토와 발화 평가 문맥 분리

2026-11-18 사용자는 발화 사후 평가와 별개로 Codex의 개발 방향·연구 설계도 Claude와 **별도 채팅 문맥에서 자율적으로 논의**하도록 명시했다. 필요한 경우 더 높은 모델/추론을 검토할 수 있으나 기존 구독·유료 API 금지·새 모델 다운로드 금지는 유지한다.

- 새 개입 선택, 비교/평가 설계 변경, 반복적인 정체로 가설을 바꿀 때는 구현·대량 생성 전에 작은 전략 검토 묶음을 작성하고 별도 Claude 멘토 문맥에 보낸다. 이 통상적 검토를 할지 사용자에게 매번 되묻지 않는다. 사소한 파일 수정마다 호출하지 않는다.
- 멘토 묶음에는 목표·고정 조건·누적 결과 요약·대표 근거·Codex의 제안과 대안을 넣는다. 전체 저장소·전체 개발 채팅을 매번 읽히지 않는다. 임상 근거의 부재·원형 미확보·기준 B 미구현도 숨기지 않는다.
- 한 방향성 검토에서 최초 비평을 받은 뒤 Codex가 지적별 수용/보류/반박과 수정안을 제시하고 실질적 후속 답변을 받는다. 새 근거 없는 합의 유도·무한 토론은 하지 않는다. 범위·사용량을 기록하고 추가 왕복은 구체적 미해결 쟁점이 있을 때만 한다.
- 멘토는 환자 발화 점수를 재평정하는 역할이 아니다. 발화 평가자의 기존 세션을 이어 쓰지 않는다. 멘토 논의는 새 역할·문맥·기록 경로로 분리하며, 후속 왕복에는 해당 전략 논의만 명시적으로 전달한다. 이후 발화 판독에는 멘토 응답·개발 목적·다른 평가자의 판단을 제공하지 않는다.
- 현재 구현은 기존 공식 Claude Pro CLI의 Opus 5.5 `high`를 사용한다. 기존 발화 판독의 Opus 5.5 `medium` 설정을 바꾼 것이 아니며 다른 신규 모델을 썼다고 주장하지 않는다. 별도 문맥이 별도 기반 모델·임상의 검증·통계적 독립성을 뜻하지 않는다.
- 멘토의 제안을 자동 정답으로 채택하지 않는다. 사용자 고정 조건을 유지하면서 적용하고, 필요한 조건 변경은 이유와 범위를 분명히 한다. 점수 최적화나 임상 근거를 꾸며내는 방향은 채택하지 않는다.
- 첫 분리 전략 논의는 `strategy/M9-direction-review-v01/`에 보존한다. 실제 호출·원응답·Codex의 후속 답변·지적별 결정·채택 계획을 구분해 기록한다.

이 지시는 아래의 **발화 묶음별 두 모델 단회 평가와 산술평균 규칙**을 바꾸지 않는다. 별도 멘토 왕복을 발화 점수로 세거나 최종 720회 판독으로 합산하지 않는다.

## M5의 명시적 예외 — 반복성·오류 민감도 점검

2026-11-18 사용자가 프롬프트 수정을 잠시 멈추고 기존 6대화와 오류 대조 3개를 GPT-6.1 Sol High·Claude Opus 5.5에 **각각 3회** 평가하도록 명시적으로 요청했다. 이 M5 묶음에 한해 모델별 3개 새 CLI 세션(총 6개 호출·54개 평점)을 사용한다. 대화별 참고 평균은 각 모델의 세 원평점 평균을 동등하게 평균하고, 원평점·반복성·오류−원본 차이를 별도로 보존한다. 과거 단회 점수를 합치지 않는다. 판독 전 계획은 `../development/speech-m5-repeatability-v01/methods.md`와 `plan.json`이다. 이는 최종 720회 실행이나 일반적인 모든 개발 묶음의 3회 반복으로의 변경이 아니다. 프롬프트·원본 발화는 고정한다.

## 개발 단계

- 각 개발 묶음의 검토자는 GPT-6.1 Sol High와 Claude Opus 5.5다. 동일한 자료와 동일한 항목을 각각 **1회** 검토한다. Gemini는 개발 검토에 포함하지 않는다.
- 실제 발화의 수치 평정에는 기존 PATIENTSIM Realism 1~4점 문항을 동일하게 제공한다. 개발 참고값은 두 원평점의 산술평균 `(GPT 점수 + Claude 점수) / 2`로 계산한다. 중앙값이나 모델별 5회 반복을 사용하지 않는다. 소수점 .5도 보존한다.
- 두 원평점·검토 근거·검토 대상의 해시를 함께 보존한다. 한쪽 응답이 없거나 형식이 잘못되면 평균은 미완료로 둔다. 누락값을 추정하거나 한쪽 점수로 평균을 대체하지 않는다.
- 수치가 없는 설계·코드 비평은 두 검토의 서술형 지적을 종합해 수용·보류·반박 근거를 남긴다. 비평문에서 임의의 숫자를 만들어 평균내거나, 구현만 보고 발화 현실성 점수를 매기지 않는다.
- 평균값과 원문 지적을 개발 수정에 반영한다. 점수 하나로 사실 모순이나 역할 이탈 지적을 무시하지 않는다. 점수 불일치 자체를 줄이려고 반복 호출하지 않는다. 단계당 추가 검토는 자동 실행하지 않는다.
- 각 모델에 같은 작은 묶음을 제공하고 기존 구독 접근을 사용한다. 전체 저장소·대화 기록을 매번 보내거나 별도 유료 API를 사용하지 않는다. 요청 모델과 실제 확인된 모델/설정은 구분해 기록한다.
- 개발 사례와 최종 성능 비교의 미사용 사례를 계속 구분한다. 개발 검토에 쓴 자료는 최종 미사용 사례가 아니다.

## 최종 결과 단계

48대화 × 3모델 × 각 5회 = 720회 판독 계획은 **최종 결과 단계로 이연**한다. 현재 개발을 시작하거나 계속하기 위한 선행 실행 조건으로 두지 않는다. 기존 12개 합성 프로필·48대화 구성과 GPT-6.1 Sol / Claude Opus 5.5 / Gemini 4 Argon 패널, 모델별 5회 중앙값 → 세 중앙값의 중앙값이라는 최종 집계 계획은 이번 지시로 변경하지 않는다.

720회는 기존 평가자 신뢰도·일치도 점검 묶음의 계획값이다. 이를 미사용 사례에서의 최종 B/T 성능 비교까지 완료했다는 뜻으로 쓰지 않는다. 최종 보고에서 평가자 검증과 프롬프트 성능 비교는 구분하며, 현재 모두 미실시다.

개발 2모델 평균은 반복 신뢰도나 임상 타당성의 검증값이 아니다. 이번 변경은 개발 비용과 시간에 관한 운영 선택이다. 실제 비교 자료 없이 ‘1회 평균과 다회 판독에 실질적인 차이가 없음’을 관측 결과로 기록하지 않는다.

## 기존 M0의 처리

`reviews/M0-design-round1/`은 이미 받은 Claude의 **설계 비평 1회**다. 원응답에 수치 평정은 없고 실제 생성 발화도 제공하지 않았다. Codex의 구현·반영 결정 기록을 별도의 GPT 단회 평점으로 소급 변환하지 않는다. 따라서 M0의 2모델 평균값은 **없음**으로 남긴다. 평균을 채우기 위한 Claude 재호출은 하지 않는다.

다음 실제 발화 검토 묶음부터 두 모델 각각 1회와 산술평균 규칙을 적용한다. 설계/코드 검토 역시 같은 묶음을 각 1회 검토하되 서술형으로 종합한다.
