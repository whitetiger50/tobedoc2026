# M10 독립 전략·측정 검토 (2026-11-19 KST)

**범위**: 입력으로 받은 근거만 검토했습니다. 도구 호출, 저장소 탐색, API 호출은 하지 않았습니다. 새 Realism 점수, 환자 발화, 프롬프트 수정안은 만들지 않았습니다.

**표기**
- **[관찰]**: 제공 파일의 수치와 원문에서 바로 확인되는 내용입니다.
- **[추론]**: 제가 텍스트를 대조해 해석한 내용입니다. 원 키 파일로 확인해야 합니다.
- **[제안]**: 승인되거나 실행된 것이 아닙니다.

이 검토 자체는 모델의 비평입니다. 검증된 과학적 근거가 아닙니다.

## 1. 핵심 진단

1. **판독 패널은 프롬프트 버전 사이의 차이를 식별할 정보를 거의 만들지 못했습니다.**
   - M3부터 M9까지의 모든 조건 차이는 3점과 4점 사이에서 뒤집힌 평점 0~2개로 설명됩니다.
   - 같은 텍스트를 Claude가 다시 평정할 때도 이와 같은 크기(1점)의 변동이 이미 관찰됐습니다.
   - 따라서 현재 설계로는 프롬프트 효과와 재평정 변동을 분리할 수 없습니다. 이는 "오차 범위 안"이라는 통계적 주장이 아닙니다. 두 현상의 크기가 같다는 서술적 관찰입니다.

2. **척도가 사실상 퇴화했습니다.**
   - 제공 원장 기준으로 자연 대화에 대한 Codex 평점은 102개 중 101개가 4점입니다(M3 6, M4 6, M5 원본 18, M6 18, M7 18, M8 18, M9 17/18).
   - Claude는 M8과 M9에서 36개 모두 3점입니다.
   - 따라서 산술평균은 사실상 "4 + Claude 점수"를 2로 나눈 값입니다. 판독자 간 불일치는 무작위 잡음이라기보다 체계적인 **수준 차이**입니다.

3. **민감도는 비특이적입니다.**
   - 노골적인 사실 모순(M5 오류 대조군)에는 두 판독자 모두 반응했습니다.
   - 미묘한 범위 확장으로 보이는 사례(아래 Q927)에는 반응하지 않았습니다.
   - 반대로 어미 하나(`거든요`와 `어서요`)의 차이에는 GPT 평점이 반응한 것과 양립합니다.

4. **구성 타당도는 확인되지 않았습니다.**
   - ED용 앵커를 정신과 환자로 바꾼 것이고, 조현병에 대한 타당성은 검증되지 않았습니다.
   - Realism 점수 하나에 사실 근거, 공개 속도, 격식·복창, 프로브 질문에 대한 반응이 섞여 있습니다.

5. **결론**
   - 버전 순위는 개발 방향을 정할 근거가 되지 못합니다.
   - 그러나 "추가 구성요소의 이득이 확인되지 않았다"는 판단에는 충분합니다.
   - 이 판단은 같은 3사례에서의 버전 경쟁을 멈추는 데 필요한 정보로 이미 충분합니다. 반복 평정을 더 해도 이 결론은 바뀌지 않습니다.

## 3. 혼입 요인 (질문 2)

1. **버전 간 다중 요소 변경**
   - v02→v03은 전면 재구성입니다(R1~R8 구조, 서두 변경, 면책 문구 제거, 예시 조항 추가).
   - v04는 v03에 R4·R7을 확장한 것입니다.
   - M4(v02 대 v04)는 두 단계의 차이를 한 번에 비교하므로, 어떤 규칙 때문인지 귀속할 수 없습니다.
   - v05(v02에 근거 관련 3개 항목만 추가)는 단일 요소 비교로 가장 깨끗했습니다. 하지만 기준 버전에서 관찰된 오류가 0이어서 감소를 보일 수 없는 구조였습니다.

2. **질문 세트, 검토 과제, 수준 이동이 동시에 바뀜**
   - M7에서 M8로 가면서 Claude는 14/18이 4점이던 상태에서 18/18이 3점으로 바뀌었습니다. 같은 시점에 질문 세트(스트레스 프로브 P05~P07)가 바뀌었고, 회피 검토 과제도 추가된 것으로 보입니다(M8 limits 문구 기준 [추론]).
   - 두 조건이 함께 이동했으므로 프롬프트 효과는 아닙니다. 다만 프로브 탓인지 과제 부하 탓인지는 분리되지 않습니다.
   - M7의 턴 수와 검토 역할 원문은 제공 자료에 없습니다.

3. **고정 프로브가 아티팩트를 유도함 [모델 비평]**
   - D07 같은 질문("원인과 결과인지… 알려주세요", "확실히 말씀하실 수 있는 경험만")은 실제 면담에서 흔치 않은 메타 질문입니다. 이런 질문은 복창형 답변을 유도합니다.
   - 예: `DEV-M0-01-rep03-examples` P07 "말씀드릴 수 있어요"는 Claude가 형식적이라고 지적한 표현입니다.
   - 또 고정 스크립트는 환자가 무엇을 공개했는지와 무관하게 진행됩니다. `DEV-M0-02-rep01-examples`에서는 P03에서 소리 경험을 유보한 경계적 생성이, D07에서 소리를 전제한 질문을 받으며 감점 요인이 되었습니다.
   - 즉 **경계적 행동과 스크립트의 충돌이 점수에 섞입니다.**

4. **묶음 구성과 맥락 효과**
   - M5는 거의 같은 오류 대조군을 같은 묶음에 넣었습니다(대비 효과 가능성).
   - M9는 비슷한 대화 18개를 한 묶음으로 평정했습니다(Claude의 일괄 3점이 묶음 수준의 기본값일 가능성).
   - "독립 평정" 지시만으로는 이를 막을 수 없습니다.

5. **생성의 확률성**: seed와 temperature는 공개되지 않았습니다. M6 이후 점수 변동에는 생성 변동과 판독 변동이 섞여 있습니다.

6. **생성기와 판독자가 같은 계열**: Codex의 천장은 같은 계열 출력에 대한 관대함일 수 있습니다(경쟁 설명).

7. **작성자 사전 지식**
   - 프로브는 과거 출력의 실패를 겨냥해 작성된 것으로 보입니다. 예: D05 "오늘 일어난 시각까지"는 Q927 유형의 오류를 겨냥한 것으로 보입니다 [추론].
   - v02의 일부 규칙("특별한 일은 없었다" 등)도 같은 3사례를 반복 개발하면서 생겼습니다. 따라서 **v02 자체가 3사례에 과적합됐을 가능성**을 숨기면 안 됩니다.

8. **출처 가용성이 B 선택에 섞일 위험**
   - E1 전문은 확보되지 않았습니다. E3, E4, E6만 실제로 있습니다.
   - "있는 것"이 "목적에 맞는 것"으로 둔갑하지 않도록 선택 기준을 먼저 고정해야 합니다.
   - 확보된 자료 중 검증된 한국어 조현병 템플릿은 없습니다. 따라서 B/T 비교에는 언어·포팅 충실도라는 혼입이 필연적으로 들어갑니다.

9. **런타임 기본값과 선택 버전의 불일치**
   - 이력상 기본값은 v04이고, 명시적으로 선택된 잠정 T는 v02입니다.
   - 버전 플래그가 빠지면 v04로 조용히 실행될 위험이 있습니다. 실행 전 차단 게이트가 필요합니다.

**v06 공통 scaffold 비교에 대한 평가**
- **잘된 점**
  - 예시 내용만 조작했습니다.
  - 예시를 해시로 동결했습니다.
  - 복사 위험 정의를 사전에 정하고 none 조건에서도 대조했습니다.
  - 사례 입력 해시로 두 조건의 사례 내용이 같음을 확인했습니다.
- **한계**
  - raw v02 대 scaffold의 차이는 측정되지 않았습니다. none 조건에서도 "예시가 비어 있다"는 안내 문단 자체가 개입입니다.
  - 주 결과(요구되지 않은 메타 설명)는 M8 어휘 감사에서 이미 바닥이 예견돼 있었습니다.
  - 예시는 손목, 피부, 안경 같은 일반 미니사례입니다. 문제가 실제로 발생한 지점(프로브에 대한 요청된 설명의 격식성)과 겹치는 부분은 STYLE-C의 정정 형식 정도입니다.
  - **사전 기대 효과가 낮은 실험이었습니다.**
- **얻은 것**
  - 예시를 넣어도 복사나 사실 전이가 관찰되지 않았습니다(0/72).
  - 출력 길이가 줄었습니다(2795→2545자). 다만 현실성 향상과는 무관한 형식 변화입니다.

## 4. v02 단순성 선택 (질문 3)

**잠정적으로 정당합니다.**
- 사전에 정한 동률·바닥 시의 단순성 규칙을 그대로 적용했습니다.
- interpretation.md도 "raw v02 우월성을 직접 확인한 결정이 아니다"라고 정확히 썼습니다.

**단서**
- "단순"은 상대적입니다. v01은 더 짧지만 v02와의 비교는 제공 원장에 없습니다. 따라서 "가장 단순한 무난한 버전"이라고 부르지 말고, **"이득이 확인된 추가 요소가 없는 기존 기준 버전"**이라고 불러야 합니다.
- v02는 모든 비교에서 기준 버전이었고 오류 대조군의 출처였습니다. 이 비대칭을 밝혀야 합니다.
- 포스터에는 "개발 3사례로 조정된 T"라고 명시해야 합니다.

**문체 0건과 반복적인 3점에 대한 비판 [모델 비평]**
- 두 결과는 모순이 아니라 서로 정합합니다.
- 분류 체계상 `requested_explanation`은 질문이 설명을 요구하면 면책됩니다. 그래서 요청된 설명 안의 **격식성과 질문 복창**이라는 Claude가 실제로 감점한 결함이 범주에서 사라집니다.
- 실제로 Claude는 P07을 `requested_explanation`으로 분류하면서도 같은 턴을 issue로 지적했습니다(`DEV-M0-01-rep03-examples`).
- 측정하려던 문제와 조작적 정의가 어긋났습니다. 바닥 0건은 "문제가 없다"가 아니라 **"이 범주로는 볼 수 없다"**는 뜻입니다.

**사실 지적과 공개 지적의 합산에 대한 비판**
- Claude의 grounding 지적 "양쪽 2건"은 서로 다른 세 종류를 섞고 있습니다.
  - P02의 인과 함축
  - P04의 주어 생략 모호성
  - P07의 공개 연속성 문제(이 문제를 Claude가 grounding 칸에 uncertain으로 넣음)
- interpretation은 이들을 사실 오류로 확정하지 않은 점에서 옳습니다.
- 그러나 "지적 수"를 나란히 제시하면 다른 구성개념을 같은 단위로 세는 셈입니다. 앞으로는 종류별로 보고하고, 공개 연속성은 grounding과 분리해야 합니다.
- P02 인과 함축은 v02의 "자동 인과 금지" 규칙과 자연스러운 한국어 담화표지(`거든요`)가 긴장하는 지점입니다. D07 프로브가 이 긴장을 드러내어 "불일치"로 만듭니다. 이것이 결함인지는 임상 앵커 없이는 판정할 수 없습니다.

## 5. 경쟁 설명 (작은 차이의 출처)

1. 실제로 작은 프롬프트 효과가 있음
2. Claude의 재평정 변동(같은 텍스트가 3점 또는 4점을 받음)
3. 회차·세션 순서 효과, 묶음 ID 오염(M5)
4. 묶음 구성: 대비 효과(오류 대조군)와 유사 대화 18개에 대한 일괄 기본값
5. 검토 과제 누적(grounding, avoidance, style 하위 과제)이 Realism 판단에 영향
6. 프로브 질문의 부자연스러움이 대화 전체 점수를 끌어내림
7. 미세한 어휘 단서(`거든요`/`어서요`)
8. 생성기와 판독자가 같은 계열이라 생기는 관대함(Codex 천장)
9. 항목별 경계 사례와 판독자 규범의 충돌
   - [추론] Q921로 추정되는 `DEV-M0-02-v04`는 P01에서 소리를 조기 공개합니다. Claude의 4,3,3 평점은 M9에서 Claude가 보인 공개 시점 규범과 양립합니다.
   - 이는 잡음이 아니라 **판독자 간 구성 개념의 이견**이므로 반복을 늘려도 해소되지 않습니다.
10. 기준 버전의 비대칭(v02가 기준이자 대조군 출처)

현재 자료로는 1을 2~10과 분리할 수 없습니다.

## 7. 다음 계획 (질문 4, 5)

### 7.1 우선순위

1. **B 출처·입력 감사** (평정·생성 없음)
2. 최종 스크립트와 분석 계획 동결
3. 이후에만 B/T 확인 생성

새 버전 생성이나 평정은 B 감사보다 앞서지 않습니다.

### 7.2 B 감사 게이트 [제안]

**B0. 목록화**
- E3(원저자 코드), E4(부록 템플릿), E6(역할 프롬프트) 각각에 대해 파일, 해시, 원래 목적, 대상 집단, 언어, 필요한 입력을 기록합니다.
- E1은 "전문 미확보, 재현 주장 불가"로 표기합니다.

**B1. 선택 기준을 새 B 출력 전에 동결**
- 목적 적합성(환자 역할 대화 생성)
- 필수 의미 변경량
- 입력 스키마 호환성(facts, patient_knows, disclosure, communication, history, current_question)
- 동률일 때의 순서 규칙
- 기존 T 출력을 이미 봤다는 한계를 명시합니다. 기존 T 점수를 기준으로 B를 고르지 않습니다.

**B2. 변경 분류**
- 각 변경을 원문 그대로 / 최소 포팅(필드 매핑, 형식만 변경) / 재구성(지시 내용 변경) 중 하나로 분류하고 변경 목록과 해시를 남깁니다.
- 번역이 필요하면 최소 포팅 이상으로 분류합니다.

**Stop/Go**
- 원문 그대로 또는 최소 포팅이 가능한 후보가 있으면 → B로 확정하고 원 출처 기준선이라고 부릅니다.
- 후보가 재구성만 가능하면 → "작성자 재구성 기준선"으로 주장 범위를 축소합니다. 이 경우 B/T 비교를 "원저자 기준선 대비"라고 쓰지 않습니다.
- 어느 후보도 목적이나 입력에서 성립하지 않으면 → B/T 비교 주장을 철회합니다. 포스터는 T에 대한 기술과 측정 한계 보고로 범위를 좁힙니다.

### 7.3 측정 진단 1건 [제안·미승인·미실행]

**필요성**
- 현재 개발 결정(버전 경쟁 종료, v02 잠정 동결)에는 기존 증거로 충분합니다. 이를 위한 추가 평정은 제안하지 않습니다.

**단계 0 (무비용, 먼저)**

  - 판단이 모호할 때만 단계 1을 고려합니다.

**단계 1 (단계 0이 모호하고 사용자가 승인할 때만)**
- **고정 텍스트 재사용**: 이미 생성된 M9 대화 중 사전 규칙으로 rep01의 사례 3개 × 조건 2개, 총 6개를 고릅니다. D01~P04 구간만 그대로 제시합니다. 새 생성이나 텍스트 편집은 없고, 구간만 자릅니다.

- **표본 단위**: 대화입니다. 독립 군집은 3개입니다.

- **평정 수**: 12개. 기존 36개 평정은 보존하고 합치지 않습니다.
- **정직한 종료점**: Claude가 같은 대화의 전체 구간(전부 3점)과 앞부분 구간에 준 점수 분포를 서술합니다. 조건 비교는 하지 않습니다. GPT 결과는 천장 예상과 함께 따로 보고합니다.
- **사전 결정 규칙** (통계 임계값이 아닌 결정 규칙)
  - Claude가 6개 중 5개 이상에 4점 → 프로브가 수준을 낮춘다는 설명과 양립 → 평정 분리 설계를 검토합니다.

  - 4개 → 모호함 → 반복 평정을 추가하지 않고 설계 논리로 결정합니다.
- **남는 한계**: 길이 차이, 묶음 차이, Claude 재평정 변동이 남습니다(M5에서 같은 텍스트가 1점 변동). 반복을 늘려도 타당도는 해결되지 않습니다.
