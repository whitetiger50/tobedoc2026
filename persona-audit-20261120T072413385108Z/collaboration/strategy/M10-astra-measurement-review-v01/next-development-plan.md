# 재검토 후 다음 개발 계획 — 2026-11-19 KST

**현재 자료로 관측한 미세한 점수 차이를 확정적인 프롬프트 개선 순위로 사용할 근거가 부족하다.** 같은 세 사례의 버전 경쟁은 종료하고, v0.2는 개발된 공학 참조로 유지한다. 이는 최적화 완료·임상 우월성·다른 사례에서의 동등성이라는 결론이 아니다.

이 계획은 Astra의 독립 검토와 후속 답변, 발화 평가와 분리된 Claude Opus5.5 high의 최초 비평과 Codex 반론에 대한 후속 답변을 실제로 읽고 정리했다. 모델 간 동의 자체를 새로운 과학적 근거로 삼지 않는다. 기존 수치는 Python으로 재집계했고 새 환자 발화·새 Realism 평정은 만들지 않았다.

## 1. 평가 일관성에 관한 현재 답

- **같은 원문 반복성:** M5의 원본6대화/3프로필을 각3회 평가했을 때 GPT는 모든18평점이4였다. Claude는 6대화 중3개에서만 세번 모두 같았고, 동일 원문에서 두 회차씩 짝지은 점수의 일치는12/18이다. 그18쌍은 독립 표본이 아니다.
- **평가자 간 기준 차이:** M8의18대화는 GPT가 모두4, Claude가 모두3이었다. M9도 GPT17/18이4, Claude18/18이3이었다. 일관된 수준 차이와 미세 구분의 부족은 재평정의 무작위 변동과 다른 문제다. 어느 판독자의 기준이 임상적으로 옳은지 확인한 자료가 없다.
- **민감도 범위:** M5에서는 설정·선행 답변이 지지하는 가족 지칭을 연구자가 다른 가족으로 교체했을 때, 원본과 교체본이 같은 묶음에 함께 제시된 조건에서 두 판독자의 점수가 매회 낮아졌다. 이 결과는 단독 제시의 재현, 임상적 모순 탐지율, 미세한 현실성 차이의 구분력을 입증하지 않는다.
- **작은 평균 차이:** M9의3.5000 대3.4444는 단 한 원평점의1단계 차이에서 생겼다. 한 평점의 산술적 영향1/18과 M5에서 관측한 라운드 차이0/−1/6/−1/6은 측정오차 한계·최소검출차이·임상적 중요도 기준이 아니다.
- **최초 버전의 맥락:** M1에서는 GPT3점·Claude2점도 사용했다. v0.2 이후의 천장 양상을 모든 가능한 발화에 일반화하지 않는다. M1 이후 설정 보완과 프롬프트 변경이 함께 있었으므로 이전 평균3.1667과 이후 점수를 순수한 개선 효과로 비교하지 않는다.

현재 근거로 할 수 있는 결정은 추가 요소의 이득이 확인되지 않았으므로 더 얹지 않는다는 것이다. 점수를 더 반복하면 해결되는지, 새 강제 쌍비교가 더 타당한지, 프롬프트가 이미 최적인지는 확인되지 않았다.

## 2. 먼저 목표를 구별한다

**자연 면담의 발화 그럴듯함:** 유도하지 않는 질문에서 현재 환자의 관점·한국어 대화 맥락·설정에 맞는 답변인가를 다룬다. 모델이 부여한 Realism과 전문가가 확인한 임상 현실성을 구분해 보고한다. 실제 환자·전문의 기준은 미확보다.

**유도 질문에서 설정 근거 보존:** 잘못된 전제나 시간·인물·인과 구분을 요구하는 질문에서 합성 프로필이 지지하지 않는 사실을 새로 확정하는지 다룬다. 참조 기준은 합성 설정과 이력이다. 이것을 조현병 발화의 임상 현실성 지표로 대체하지 않는다.

M8·M9의 기존 Realism 총점은 두 종류의 질문을 포함한 대화 전체의 평정이다. 기존 점수를 자연 면담만의 점수로 다시 이름 붙이거나 재분류하지 않는다. 앞으로 어떤 질문을 평가에 포함할지는 연구의 주장 목적에 맞춰 사전 문서화한다. 유도 질문을 자동 삭제하거나 기존 결과를 보고 더 높은 점수가 나오는 구간을 선택하지 않는다.

## 3. 기록과 해석의 기준

- 설정 밖 구체화·범위/확신 변화·모순·인과 함축을 구별한다. 단순한 말바꾸기와 생략은 문맥을 보고 불확실성을 보존한다.
- 공개 연속성과 사실 근거를 별도로 기록한다. 아직 공개하지 않은 소리를 의사가 먼저 물었다는 이유만으로 환자의 답변을 새로운 사실 생성 오류로 세지 않는다. 놀라거나 특정 문구로 반문하는 반응을 일괄 정답으로 정하지 않는다.
- 요청된 설명에서도 격식·복창 문제가 있을 수 있다. unrequested 분류0건은 전체 문체 문제0건이 아니다.
- 한 사건이 issues/grounding 등에 중복 기록되면 사건 연결을 남긴다. 단순 지적 수를 확정 오류율로 사용하지 않는다.
- 단회 전체 점수의 평균, 원점수 분포, 사례별 기여와 실제 인용을 함께 보존한다. 기준을 맞추기 위해 GPT에서1점을 빼거나 Claude를 제외하지 않는다.

## 4. 호출 없는 다음 작업: B 원형과 정보 대등성 감사

이 감사는 **계획이며 이번 재검토에서 실행 완료한 것이 아니다.** 확보된 E3 원저자 코드·E4 부록 템플릿·E6 역할 지시와 E1의 미확보 범위를 후보별로 대조한다. 과거 M2의 원문 확인을 새 B 구현·재현 완료로 표시하지 않는다.

새 B/T 확인 생성 전에 다음을 기록한다.

1. 원 출처, 원래 대상·목적, 라이선스/사용 조건, 고정 버전·커밋과 원문 해시.
2. 목적 적합성, 필요한 의미 변경량, 정보 손실, 동률 선택 원칙. 기존 T 출력을 이미 보았다는 한계를 명시하고 T가 이기기 쉬운 B를 고르지 않는다.
3. facts·환자가 아는 범위·공개 조건·의사소통·전체 이력·현재 질문이 B/T에 어떤 의미로 전달되는지 필드별 대조. 형식이 같다는 사실과 의미가 대등하다는 판단은 다르다.
4. 질문별 필수 사실의 작성자 점검은 양쪽에 대칭으로 적용할 입력 품질 관리인지, T만의 개입인지 명시한다. 한쪽만 완성된 설정을 받게 하지 않는다.
5. 번역·변환 주체와 변경 목록·결과 해시를 새 B 출력을 보기 전에 동결한다. 원문 그대로/최소 포팅/재구성은 실제 변경에 따라 판정한다. 다단계 원형을 단일 호출로 바꾼 것을 전체 재현이라고 하지 않는다.
6. 같은 생성 모델·추론 설정·이력 처리·질문·실행 경로를 명시한다. T는 v0.2 버전과 프롬프트 해시를 명시적으로 확인하고, 역사적 기본 v0.4가 조용히 선택되면 실행을 중단한다.
7. B의 출처와 평가 앵커의 출처 관계를 기록한다. 출처가 같거나 다르다는 사실만으로 측정의 유불리를 단정하지 않는다.

B와 T의 정보가 대등하지 않으면 프롬프트 단독 효과 주장을 보류하고, 비교 가능한 구성이나 전체 파이프라인 비교라는 주장 범위를 검토한다. B가 성립하더라도 **평가가 임상적으로 타당해졌다고 간주하거나 자동으로 대량 생성하지 않는다.**

## 5. 측정 쪽 진행 조건과 허용 주장

현재 허용되는 것은 특정 합성 개발 설정·질문·모델에서 얻은 모델 평점과 관찰의 기술이다. 미세한 버전 우월성, 최적화 완료, 일반 신뢰도 확보, 실제 조현병 환자와의 동등성, 전문가 인증은 주장하지 않는다.

새 수치 실험을 제안하려면 먼저 어떤 결정을 바꿀 것인지, 그 결정에 현재 정보가 왜 부족한지, 고정 원문의 재평정 변동과 조건 효과를 어떤 설계로 구별할지 문서화한다. 작은 표본의 소수점 차이를 통계적으로 유의하게 만들기 위해 평정 수를 늘리지 않는다. 판독자가 같은 값만 반환하면 그 관측 사실과 정보 부족을 보고하고, 원하는 순위가 나올 때까지 판독하지 않는다.

**이번 검토에서 나온 두 진단은 실행하지 않는다.** Astra의 고정2대화8평정은 해당 원문에 대한 단독 제시 반응의 반복만 확인할 수 있어 현재 결정에 필요하지 않다. Claude의 앞부분6대화12평정과5/6·3/6 기준은 혼입과 근거 없는 임계값 때문에 철회됐다. 새 평가 설계가 필요해지면 당시의 구체적 질문을 대상으로 다시 검토한다.

기존 지적의 위치는 호출 없이 재집계했다. M8 Claude의 지적된 대화-턴 위치18개 중17개, M9의15개 중10개는 P05~P07이었다. 이는 제한된 서술형 비평의 위치이며 오류율이나 프로브의 인과 효과가 아니다. 묶음·새 생성·검토 과제·지적0~2개 제한이 섞여 있다. 이 숫자로 새 임계값이나 프로브 삭제 규칙을 만들지 않는다.

## 6. 최종 자료와 집계 계획 보호

개발의 두 판독자 단회 원평점 산술평균은 유지한다. 최종 계획의48대화×3판독자×5회=720판독, GPT-6.1 Sol/Claude Opus5.5/Gemini4Argon 패널, 모델별5회 중앙값→세 중앙값의 중앙값도 변경하지 않았다. 최종 미사용12프로필을 이번 검토·스크립트 조정에 열람하거나 사용하지 않았다.

향후 최종 보고 계획을 동결할 때 모델별 원분포와 중앙값, 최종 중앙값과 같은 값을 준 모델들(동률 포함)을 함께 보이는 방식을 검토한다. 이는 집계 변경이 아니다. 개발에서 관측한 상수 양상이 최종에도 지속된다고 예측하지 않는다.

새 B/T 생성 전에 원형/포팅의 범위, B/T 정보 대등성, 명시 버전/해시, 질문 목적·스크립트, 검토 역할과 분석·보고 계획을 함께 확인한다. 실제 환자·전문의 근거가 끝내 없으면 결과의 주장 범위를 합성 설정에서의 모델 판독 기반 탐색 결과로 제한한다.
