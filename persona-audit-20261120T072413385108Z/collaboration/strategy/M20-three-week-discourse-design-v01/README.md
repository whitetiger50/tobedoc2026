# M20 · 3주 담화 연구 설계 검토 완료

사용자 요청은 TOPSY 없이 3주 안에 끝낼 담화 특성·가설·대조 조건을 구체화하고 Astra와 별도 Claude 문맥에서 비평받는 것이었다. 단순히 언어장애를 지시하고 비슷하게 말했는지 평가하는 순환을 피하도록 요구했다.

실제 Astra high 최초·후속2응답, 공식 Pro CLI Claude Opus5.5 high 최초·후속2응답을 모두 읽었다. 최초의 중립적 문맥 순서×목표환기안은 일반적인 최근성/지시반응 연구에 그친다는 비판을 받아 채택하지 않았다. 최종 제안은 **동일 사건·경험에서 진단 문구가 초기 목적에 따른 상대적 행동 전개를 바꾸는지** 묻는 한 모델의 행동 감사다.

제안 조건은 새8골격×진단3(미제공/조현병/제2형당뇨병)×목적A/B2×지원블록순서2×새생성2로192문단이다. 두판독모델의주판독384+관계교정48+반복점검48=480판독을계획한다. 별도개발상한을포함하면216생성·528판독이다. 이수는예정량이며실행되지않았다. 기존최종12/720계획을바꾸거나승인받은것이아니다.

연구 대상은 LLM의 진단 문구 반응이고 실제 환자의 사고장애 재현·질환 특이 인지기제·고정관념의 임상적 오류율이 아니다. 임상 재현이 필수 산출물이라면 이 연구로는 충족하지 못한다. 제한된 행동 감사의 의미와 이 경계를 함께 제시한다. 실제로 어느 결과가 나올지 아직 알 수 없다.

다음 파일을 순서대로 읽는다.

- `protocol.md`: 최종 연구 질문, 조건, 자극 예시, 가설, 추출·분석·불확실성, 3주 일정.
- `decision.md`: 실제 비평에 대한 수용·반박·축소. 두 비평자가 모두 처음부터 찬성한 것처럼 기록하지 않는다.
- `request-round01.md`, `astra-round01.md`, `claude-round01/response.txt`: 최초안과 실제 반대 근거.
- `codex-response-round01.md`, `request-round02.md`, `astra-round02.md`, `claude-round02/response.txt`: 중대 수정과 실제 마지막 비평.
- `formula-checks.json`: 대비식과호출량의오프라인산술점검. 실험결과아님.
- `verification.json`: 공식CLI응답/문맥/해시와보존검증.

192문단 최종안은 후속 비평의8골격 축소와 비교 진단 추가를 종합한 것으로, 이 정확한 최종 문안을 세 번째로 재심받지는 않았다. 새생성·수치평정·모듈수정·TOPSY신청·외부메시지발송은0이다. 현재 완료한 작업은 구체 설계와 실제 비평 처리이며, 본시험이나 임상 검증은 아니다.
