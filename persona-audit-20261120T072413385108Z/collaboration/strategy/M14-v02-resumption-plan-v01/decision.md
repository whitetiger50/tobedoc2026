# M14 지적별 수용·보류·반박

실제 Astra 최초/후속 응답 2개, 별도 Claude Opus 5.5 high 최초/후속 CLI 응답 2개를 파일에서 읽었다. Codex의 반론은 `codex-response-round01.md`, 실제 전달 입력은 `round02-request.md`다. 합의 자체를 새로운 실험 근거나 전문가 검증으로 합산하지 않는다.

- **수용 — 조건부 개발 재개:** 동일 평가자의 반복 일관성과 명시적 편집 지목의 범위에서 작은 개발 가설을 시험할 수 있다. 일반 임상 신뢰도·미세 총점 순위 확보로 확대하지 않는다. 모델 간 점수 차이 자체는 실패 조건이 아니다.
- **수용 — A를 다음 행동으로 선택:** 질문·프로필의 대상과 시간 범위를 맞추는 작성 점검을 먼저 명확히 한다. 환자 프롬프트 효과와 구별해 제목에도 ‘입력 과제 정비’라고 썼다. 새 자동 모듈·스키마·상태 추론기를 만들 필요는 없다.
- **수용 — B·D 개입 보류:** M13 사례1의 관련 자발적 목표 설명, 재질문에 대한 짧은 답, 사례3의 질문에 필요한 시점 재진술은 정당할 수 있다. 특정 문체 비평을 임상 정답으로 만들거나 앞으로 나올 질문 순서를 환자에게 강요하지 않는다. 인위적인 역할 이탈 대조의 성공을 자연 발생 결함의 빈도로 바꾸지 않는다.
- **수용 — C의 경계와 판독 부재 해석:** ‘둘이’는 의미 범위 강화 후보이지 확정 오류가 아니다. 기존 R의 사실축 6개가 모두 2였다는 사실은 무오류 증명이나 오탐지 증명 어느 쪽도 아니다. 편집 N2에서만 나온 일부 불확실 지적도 원문 탐지력 검증이 아니다. 30대화·168턴의 문자 검색은 발생률이 아니며 동거 언급 기회가 있는 분모를 확보한 것도 아니다.
- **반박 후 철회 확인 — v0.5 결과의 사후 교체:** Claude 최초의 ‘총점으로 판별 불가로 정정’ 제안을 반박했다. 후속 응답에서 Claude가 철회했다. 기존 ‘해당 설계에서 이득 미확인’을 유지하며 판독 해상도는 가능한 설명 중 하나로만 남긴다.
- **정정 수용 — 자발성 등급:** Claude 최초의 ‘고자발성’은 원 설정을 넘은 표현이다. 후속에서 정정을 받았다. ‘관련 경험을 필요한 만큼 덧붙일 수 있다’는 실제 문구만 근거로 쓴다.
- **범위 축소 후 수용 — 오류 기원 검토:** Claude의 M6~M9 전체 감사 제안 대신 이미 읽은 M13 원문 3대화의 기존 지적 다섯 위치만 한 번 정리했다. 후속에서 범위 축소에 동의했다. 이는 비맹검 작성자 노트로 새 평정·척도·전체 오류율이 아니다. 해당 검토는 완료했고 재개를 막는 새 일반 검증 장벽을 두지 않는다.
- **반박 후 수용 — 감사 결정 주체:** routine 계획·기존 자료 분석의 규칙을 사용자가 다시 정해야 한다는 조건을 반박했다. Claude 후속에서 과도했음을 인정했다. 새 출력이 생길 향후 실험은 목적·입력·분석을 먼저 고정한다. 현재는 사용자가 계획을 요청했으므로 프롬프트 변경·새 생성·평정을 실행하지 않는다. 별도의 일반 승인 절차를 새로 만들지 않는다.
- **부분 반박 — 단일 프로필의 무조건 제외:** Claude 후속은 단일 프로필을 개입 근거에서 제외하자고 제안했다. 모호한 한 표현만으로 광범위한 프롬프트 변경을 정당화하지 않는 취지는 수용한다. 그러나 한 사례의 명시적 사실 반전까지 결함 기록에서 제외할 이유는 없다. Astra 후속처럼 개별 진단과 여러 사례에서의 개입 이익·일반화를 구별한다. 반복 프로필 수를 임의 통과 역치로 만들지 않는다.
- **수용 — 유한 종료와 인과 귀속:** 이번 다섯 위치 검토와 계획 문서 확정으로 M14를 끝낸다. 다음 정해진 개발 범위를 본 뒤 명확한 생성자 결함 한 가지를 선택하거나 v0.2 유지로 주기를 닫는다. 특정 턴 비교와 전체 자유 생성 면담 비교를 구별하고 입력 개선을 프롬프트 효과로 기록하지 않는다.

최종 계획은 `next-development-plan.md`, 작성 점검 항목은 `question-readiness-plan.md`다. 환자 프롬프트와 평가 기준을 수정하지 않았고 새 환자 발화·수치 평정도 만들지 않았다.
