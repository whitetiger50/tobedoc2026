# M12 실행 전 결정 — 2026-11-19 KST

사용자가 요청한 두 모델·대화별 새 세션·각3회·최종12사례 미사용 조건으로 **개발 원문12개+작성자 대조3개,90회 단독 판독**을 한 번 실행한다. 새 환자 발화 생성은 없다. 주추정 대상은 고정3개 개발프로필의 선정 원문과 새로운 통합 판독체계에 조건부인 반복성이다. 보편적 임상/모집단 신뢰도를 확보하는 연구라고 하지 않는다.

실제 Astra(`gpt-6.2-astra` high) 최초/후속 비평과, 발화 판독과 별도 문맥의 Claude Opus5.5 high 최초/후속 비평을 읽고 Codex가 반론·수정했다. 최초 두 검토는 서로의 이번 응답을 보지 않았고 후속 Claude에 실제 비평과 반론을 전달했다. 이번 멘토를 새 수치 판독자로 추가하지 않는다. 원응답은 각 round 파일에 보존한다.

## 수용한 수정

- 0/1/2의 문제 정도와 불확실 boolean·적용불가NA를 분리하고, 사실/앞선대화/질문 관계별로 보조축을 구별했다. 같은 사건을 합산하지 않는다.
- 문제/불확실 판단에만 실제 인용을 요구한다. 숫자2의 억지 인용을 줄이고, 오류/인용 실패 때문에 다른 유효 숫자를 버리지 않는 파서를 고정했다.
- 입력에 프로필 의미 내용은 그대로 주고 연구ID·조건·기존평점·대조정보를 제거했다. blindID도 입력에서 빼 반복과 모델 사이 본문이 완전히 같다. 호출 경로는 opaque ID다. 기존 빈임시cwd·도구/사용자설정/메모리/세션지속 차단 CLI경로를 재사용한다.
- 일원ICC(1,1)/(1,3)을 보조 주모형으로 사전 지정하고, 블록의 교환 가능성은 가정임을 적었다. 이원A는 민감도다. 모델 간에는 회차별 단회와 모델별3회 평균의 이원 절대일치를 구별하며 완전자료 수를 공개한다.
- 표본이3프로필뿐이어서 주95%CI를 보고하지 않고 프로필 하나 제외의3가지 기술 민감도·원자료를 보고한다.27재표집을 정밀CI로 포장하지 않는다.
- 자연12개와 조작3개를 분리하고, 조작 턴의 정확지목·grounding0·감점방향을 따로 보고한다.3×3교차조합을 독립표본으로 세지 않는다. 자연원문의 사전6대비는 텍스트별 관측이지 프롬프트의 일반적 승패가 아니다.
-90응답 또는 기록된 기술 중단에서 멈추고, 추가표결/재추론/유료API우회/기준 사후변경을 하지 않는다. 보조축도 상수면 미정의로 남기고 주지표로 승격하지 않는다.

## 후속 비평의 마지막 수정과 대조

1. 역할의 ‘판독자 자신의 점수’는 ‘판독자 자기평가’로 고쳤다. 임의 자기평가와 지정 총점 출력을 구별한다.
2. 역할의 사실ID 예시 `fact:living`이 조작 표적을 암시한다는 지적을 수용해 `fact:<ID>`로 중립화했다. 실제 입력은 사실ID를 제공한다.
3. v02와v04의 생성 원문 규칙을 직접 대조했다. 둘 다 설정 밖 사건·인물·수치 확정과 자동 인과 연결을 금지한다. v06도v02 원문을 포함한다. 추가 사실 불허의 평가 기준이 한 조건만 받은 생성 지시라고 하지는 않는다. 그래도 이번 조건 대비는 서로 다른 고정 출력의 기술이고 규칙 효과 추정이 아니다.
4. 인용은 코드포인트 그대로의 비어있지 않은 부분문자열 검사로 동결했다. 공백/문장부호/NFC 등을 사후 보정하지 않는다. null+uncertain=true는 허용하고 적용불가 이유를 남긴다. 숫자와 인용 품질을 분리한다.
5. 일원ICC는 원 중심화 구현과 독립적인 쌍차이 항등식 구현을 대조했고, M5값·상수·서로다른열상수 fixture를 검사했다. 서로다른열상수에서 일원은 음수가 될 수 있고 이원절대일치는0, 일관성은미정의라는 구별을 보존한다.

## 범위를 좁히거나 반박한 점

Claude는 모든 상수열의 모델 간ICC가 미정의라고 한 최초 표현을 반박 후 정정했다. 또한 범위 제한이 계수의 조건부 의미까지 없애는 것은 아니므로, 단순 일치·분포·D_o/D_e와 계수 모두 실제 계산해 보고한다.

G-Eval 원문 Methods/부록에서 차원별 기준과 정수 점수 집중 문제를 확인했지만 원 연구의 차원별 호출·auto-CoT·토큰확률가중을 재현하지 않는다. 보조4축0–2나 단일호출 다항목의 임상타당성을 원연구가 검증했다고 하지 않는다. PatientSim은 보존된 원JSON과 과거각색 문구의 출처로만 사용한다. 새모델이나30대화 권고를 기계적으로 추가하지 않는다.

Shrout–Fleiss1979의 서지는 확인했으나 미러 전문PDF는 웹 도구에서 타임아웃이었다. 전문을 읽었다고 쓰지 않는다. 일원공식은 Koo–Li 정정과 공식psych의ICC.R89–94행을 직접 대조하고 분석적fixture로 확인했다. 새R/통계패키지는 설치하거나 호출하지 않았다.
