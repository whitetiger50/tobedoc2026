# M12 독립 설계 검토 1차

**판정.** 기존 개발 대화 12개와 작성자 대조 3개, 두 모델, 모델별 3회, 총 90개 단독 세션으로 진행할 수 있다. 핵심 질문은 고정된 대화에서 같은 모델을 다시 호출할 때 운영 총점이 얼마나 달라지며, 이 변동 속에서 어떤 대화 사이의 점수 차이를 재현할 수 있는가이다. 표본 추가에 앞서 아래의 분석 단위, 보조 판정 규칙, 의사결정 규칙을 동결하는 편이 이 질문에 직접 답한다. 이 검토는 설계에 대한 판단이며 신규 관찰이나 평정은 없다.

## 실행 전에 고칠 사항

1. **표본과 추정 대상.** 프로필 3개 각각에서 조건별 고정 대화 하나를 관찰한다. 모집단에서 프로필을 무작위 추출했다는 전제도 없다. 추정 대상을 “이 3개 개발 프로필에서 선정한 12개 대화와 동결한 호출 환경에 조건부인 반복성 및 두 고정 모델의 일치”로 명시한다. 4턴과 8턴은 생성 단계와 조건도 함께 달라서 집단별 원자료의 기술에 사용한다. 턴 길이 효과, 생성조건 효과 또는 새 프로필에서의 반복성을 분리할 설계는 아니다. 작성자 대조와 대응 원본은 자연 대화 12개의 계수 계산에서 원본 하나만 기여한다.
2. **판독 단위와 반복.** 한 세션에 동일한 비식별 프로필 본문과 해당 전체 대화 한 개만 제시한다. 모델이 사실 일치를 판정하려면 프로필의 의미 내용이 필요하다. 연구용 프로필 식별자와 조건 표지만 숨긴다. 세션 간 대화·메모리·파일·도구를 통한 결과 공유를 차단하고 동일한 지시, 원문, 모델 버전·설정 및 입력 순서를 유지한다. blind ID는 외부 매핑에 두면 입력 일치 확인이 쉽다. 각 라운드에서 두 모델의 호출은 가능한 한 비슷한 시간대에 분산하고 실행 순서·시각·버전 정보를 기록한다. 새 세션은 이전 대화 문맥을 제거하지만 같은 서비스 내 호출의 확률적 독립을 보장하지 않는다. 버전 변경이 확인되면 해당 구간을 구분한다.
3. **보조축의 증거와 채점 부담.** 주총점을 출력 양식의 첫 필드에 고정하고 기존 앵커를 그대로 제시한다. 같은 응답 안에서 뒤의 축을 예상할 수 있으므로 이 결과는 새 통합 양식의 반복성이다. 보조축은 대화 단위로 판정하되 한 지점의 명백한 결함이 있을 때와 여러 지점에 가벼운 우려가 있을 때의 집계 방식을 동결한다. 예를 들어 적용 가능한 턴 중 가장 분명하게 근거를 댈 수 있는 결함을 판정에 사용하고 빈도를 합산하지 않는다. 관찰 기회가 긴 대화에서 더 많다는 점도 함께 명시한다.
   - 사실근거에서 프로필이 해당 사실을 배제하는지, 서술하지 않았는지를 구별한다. 열린 프로필이라면 양립 가능한 미기재 세부사항은 그 자체로 명시적 모순이 아니다. 설정 밖 구체화도 별도로 잡으려면 원래 과제가 허용하는 추론·보충 범위를 문장으로 고정한다.
   - 질문대응은 직전 의사 질문과 답의 관계, 연속성은 이전 발화와 현재 발화의 관계, 자연성은 환자 역할을 벗어난 표현의 관찰에 근거한다. 같은 구절을 두 번 인용할 수 있지만 각 축의 근거관계는 따로 적는다. 망상적 믿음·경계심·언어 양식을 진단명만으로 감점하지 않는다.
   - 1은 판단에 쓸 자료가 있고 특정 경미한 우려나 해석 충돌을 지목할 수 있을 때 사용한다. 자료·적용 기회 자체가 없으면 NA와 이유를 남긴다. 0/1이면 핵심 환자 구절 하나와 필요한 프로필·질문·이전 턴의 위치 하나, 2이면 대표 턴 위치와 짧은 이유, NA이면 적용 기회가 없는 이유를 기록하는 방식이면 네 축의 설명 부담을 줄일 수 있다. 원문 문자 인용을 의무화하면 문자 일치 검사는 로컬에서 수행하고 경미한 인용 형식 오류와 숫자 평정 누락을 구분한다.
4. **주분석과 불확실성.** 자연 대화별로 모델별 세 원점수를 보존한다. 모델 내에서는 3쌍 중 정확히 같은 쌍의 비율, 세 번 모두 같은 대화 수, 대화별 범위, 주변점수 빈도 및 ordinal α를 보고한다. 완전 자료에서 쌍비교 36개는 12대화에서 파생된다. 모델 간에는 두 모델의 독립적 재호출이 목적이면 대화별 3×3 교차조합의 정확일치 비율과 부호 있는 차이 분포를 대화에 같은 가중치로 평균한다. 9개 조합을 독립 표본으로 삼지 않는다. 동일 라운드끼리의 시간대 대응에 의미가 있다면 3개의 대응 결과를 추가한다. 모델별 일정한 수준 차이나 전원 동점은 분포와 교차표로 읽을 수 있다.
   - 계수 목록을 줄일 수 있다. α의 순서형 거리 계산법을 동결하고, 가중 κ를 유지하면 가중치와 비교하는 두 열을 미리 지정한다. 모델별 주총점의 단회 재현성, 두 모델 평균점수의 단회 재현성, 세 회차 평균의 재현성은 다른 양이다. ICC를 유지한다면 행은 대화, 열은 해당 지표의 세 회차로 명시한다. 모델 평균 ICC의 한 셀은 두 모델의 같은 회차 총점 평균이다. ICC(A,3)는 그러한 세 회차 평균에 해당하므로 실제 단회 운영의 정당화에 쓸 수 없다. 적용한 분산모형과 등간격 가정을 밝히며 값이 음수이면 그대로 보고한다. 분모 0, 추정 곤란, 낮은 유한값을 구별한다.
   - 3개 프로필을 재추출한 퍼센타일을 주 95% CI로 제시하지 않는 안을 권한다. 대화별 점수와 프로필별 요약이 직접 검토 가능하다. 불확실성을 더 보여 주려면 프로필을 하나씩 뺀 세 결과를 민감도 점검으로 제시한다. 이 세 값의 범위에는 확률적 피복 해석이 없다. 층별 6개에 대해서도 계수 표를 반복하기보다 점수분포·일치 분자를 먼저 보여 준다.
   - 기술 실패·필드 누락·실질적 NA를 구분한다. 예정 슬롯과 유효 숫자 수를 함께 남기고, 축별로 NA 판정 자체의 일치와 양쪽 모두 평가 가능했던 쌍의 숫자 일치를 별도로 보고한다. 비교 가능 대화가 한쪽에 몰리는지 확인하며 불능 슬롯의 재추론이나 유리한 완전 사례 선별을 하지 않는다.
5. **조작 대조와 정지 결정.** 세 원본 각각에 대해 바꾼 턴과 프로필의 충돌 근거를 사전에 봉인한다. 다른 환자 턴까지 함께 바꿔야 일관성이 유지되는 조작이라면 원문을 확인해 한 턴 수정의 파급을 표시한다. 1차 조작 확인은 정확한 충돌 지목과 사실근거 축의 방향이고 총점 하락은 부차적이다. 원본이 이미 해당 축 최저점이면 추가 하락 기회가 없으므로 근거 지목과 수치 방향을 분리한다. 두 독립 세션의 차이를 회차별로 보여 주고 세 프로필별 결과를 유지한다. 동일 유형의 조작 3개에서 다른 축의 구분력이나 실제 오류 전반의 탐지 성능을 추론할 수 없다.
   - 90개 예정 슬롯 완료 또는 기록된 기술적 중단에서 판독을 끝낸다. 총점으로 미세순위를 쓰려는 구체적 비교가 있다면 **점수를 보기 전에** 비교 대화쌍, 운영 점수(단회 또는 평균), 우열 및 동점 처리법을 등록한다. 예컨대 같은 프로필·같은 단계 내 두 조건을 비교할 때 모델별 재호출에서 우열·동점·역전이 각각 얼마나 자주 나타나는지 원자료와 함께 제시한다. 동점은 구분 실패, 역전은 순서 불안정으로 구분한다. 두 모델의 일정한 점수 차이는 고정된 모델 내 순위와 두 모델 간 점수 호환성에 각각 다르게 작용한다. 사전 지정한 비교에서 점수 방향이 지지된 경우에도 결론은 그 비교에 한정한다. 비교가 지정되지 않았거나 유효 판독이 부족하면 순위 사용 여부는 미결로 두고 기술 결과로 마친다. 결과 확인 뒤 보조축 승격·호출 추가·임계값 변경은 별도 연구 질문이다.

## 있으면 좋은 사항

- 네 축의 적용 이유를 사용 목적과 한 줄씩 연결한다. 기존 Realism 앵커의 출처, 구조화된 다차원 판독의 방법론적 선례, 반복 및 평가자 간 일치의 구분, 저자 정의 축을 문서에서 구별한다. 제시된 문헌 설명만으로 네 보조축의 한국어 정신과 면담 타당성이나 0/1/2 간격을 확립할 수 없다. 설계 멘토는 판독에 기여하지 않으므로 평가자는 기존 두 모델로 유지된다.
- 결과에 모델별 소요 시간과 응답 길이, 형식 실패 건수를 덧붙이면 통합 양식의 비용을 판단할 수 있다. 짧은 데이터 검사는 기존 스키마의 비평정 더미로 수행할 수 있으며 추가 환자 발화나 모델 호출은 필요하지 않다.
