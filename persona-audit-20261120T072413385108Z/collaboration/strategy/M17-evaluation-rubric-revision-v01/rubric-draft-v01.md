# Realism-R1 · 평가 기준 개정 초안1

상태: 설계 검토용·미시행. 환자 프롬프트 및 기존 판독 기준을 교체하지 않는다. M15의 불일치는 설계 동기일 뿐 새 기준으로 다시 점수를 매기지 않는다. 이 문안은 문헌에 근거한 저자 개정안이며 한국어 조현병 환자 발화 척도로 검증되지 않았다.

## 1. 측정 대상

주어진 합성 환자 프로필·의사소통 설정·대화 이력·현재 질문을 함께 볼 때, 환자 역할의 의사소통이 얼마나 그럴듯하게 유지되는지를 대화 단위로 평가한다. 진단 정확도·증상 중증도·실제 환자와의 임상 동등성은 측정하지 않는다. 사실근거·질문대응·연속성·당사자표현의 기존 보조축을 유지한다.

전체1–4점은 유지하되 최고점의 절대적 완벽함을 관찰 범위의 판정으로 바꾸므로 별도 버전 `Realism-R1-draft`로 명명한다. 기존 Realism과 새 점수를 합쳐 버전 개선이나 신뢰도 향상으로 해석하지 않는다. 현재 운영상의 기존 주지표는 변경하지 않는다.

## 2. 재진술의 기능과 표현 형태

먼저 같은 정보를 다시 말했는지를 확인한다. 의미 반복과 문자 반복은 서로 다르며 어느 쪽도 그 자체로 결함이 아니다. 관련 후보에서는 현재 질문·앞선 턴·설정에 비추어 다음 기능이 지지되는지 기록한다.

- 직접 재질문에 대한 답변·확인·수정.
- 목표·대처·결과를 설명하기 위한 경험 재지칭 또는 부연.
- 이해 확인·강조·요약.
- 설정과 문맥에 근거한 걱정·경계심의 재표현.
- 지지되는 기능을 찾지 못함 또는 문맥상 불명확함.

‘필요한 재진술’은 의미 손실 없이 가장 짧게 말해야 한다는 뜻이 아니다. 항상 새 정보를 추가하거나 다른 단어로 바꿔야 하는 것도 아니다. 맥락상 자연스러운 기능이 지지되는 재진술을 포함한다. 같은 질문을 다시 받은 환자에게 새로운 사건을 만들도록 기대하지 않는다.

기능이 있다고 모든 표현 형태가 자동 허용되는 것도 아니다. 불필요한 표현 반복으로 지적하려면 (a) 앞선 실제 구절과 현재 구절, (b) 현재 질문/목표, (c) 해당 기능만으로 설명되지 않는 표현상 부적절함을 제시한다. 예컨대 질문의 초점이 달라졌는데 동일한 설정 설명 블록이 반복돼 초점에 대응하지 못하거나, 환자가 상대와 대화하는 대신 항목을 낭독하는 패턴이 나타나는 경우다. 길이·문자 중복·정돈됨·프로필 문장과 가까움만으로는(c)를 충족하지 않는다.

문제를 분명히 지목하지 못하면 불확실한 후보로 남긴다. 모든 재진술을 면제하거나 모든 동일 문구를 감점하는 일괄 규칙은 쓰지 않는다. 축별0/1/2의 정도와 uncertain을 구별한다. 기능상 허용할 수 있다는 반대 근거도 짧게 기록한다. 대안 환자 답변을 생성하거나 원문을 고치지 않는다.

## 3. 3·4점 및 전체 단계의 경계

- **4:** 주어진 설정과 질문에 맞는 환자 역할의 대화가 유지되고, 관찰 자료에서 구체적으로 뒷받침되는 부적절한 표현/행동을 식별하지 못했다. 임상적 완벽함·모든 실제 환자의 대표성·누락된 정서의 풍부함을 뜻하지 않는다.
- **3:** 전체적으로 환자 역할과 대화가 그럴듯하게 유지되지만, 구체적 구절과 문맥 관계로 지목할 수 있는 경미하고 국소적인 부적절함이 있다. 그 사건이 전체 역할을 실질적으로 무너뜨리지는 않는다. 단순 취향·설정에 없는 감정 기대·반복 그 자체는 경계 근거가 아니다.
- **2:** 식별 가능한 문제가 국소적인 어색함을 넘어 대화의 반응성·persona 유지·역할의 그럴듯함을 상당히 약화시킨다. 일부 환자 대화는 유지된다. 문제 수·길이만으로 정하지 않는다.
- **1:** 환자 역할/문맥의 그럴듯함이 전반적으로 무너져 대화가 주로 설정 보고·면담자 대행 등으로 진행되거나, 해당 persona의 반응으로 보기 어려운 실질적인 문제가 지배적이다. 단일 역할 언급을 자동1로 만들지 않는다.

이는 관찰 가능한 부적절함을 기준으로 단계의 경계를 좁히려는 저자 규칙이다. 임상 중증도 척도나 객관적 정답이 아니다. 경미한 문제가 확인되지 않는데 추상적으로 더 생생할 수 있다는 이유만으로3을 주지 않는다. 판단이3/4 사이에서 불확실하면 강제 확신 대신 별도 `boundary_34=true`와 이유를 남긴다. 기본 출력은 여전히 가장 지지되는1–4점이다. 희박한 우려만 있고 확인된 문제가 없으면4와 불확실성 표지가 가능하며 이를 확정 정상으로 해석하지 않는다. 이 정책은 천장효과를 늘릴 수 있어 향후 검증 대상이다. 불확실 평정을 사후 삭제하지 않는다.

## 4. 전체 점수와 보조축의 관계

네 보조축은0=명백한 실질 문제,1=확인된 국소 문제,2=문제 미지적,자료상 적용 불가능할 때만null을 유지한다. 합산·가중합·최저축으로 전체 점수를 정하지 않는다. 같은 사건이 두 축에 관련돼도 독립 오류 두 건으로 더하지 않는다.

다만 전체 감점에는 구체적인 사건 근거와 관련 축을 연결한다. 알려진 네 축으로 설명되지 않는 전체적 문제는 `other`에 설명하고 적용한 문맥상의 이유를 공개한다. `other`가 망설임·감정이 없다는 진단명 기반 기대의 우회로가 되어서는 안 된다. 전축2/전체3이면 논리적 오류로 자동 무효화하지 말고, 기존 축이 놓친 무엇을 지적했는지 또는 불확실한 전체 인상인지 표시한다. 숨은 사고과정 대신 최종 근거만 출력한다.

사실근거·질문대응은 기존 정의를 유지한다. 연속성의 반복은 대화 연결/질문 흐름을 해친 관계를, 당사자표현의 반복은 해당 문맥에서 드러난 정형적인 표현 형태를 본다. 같은 정보가 다시 나왔다는 한 관찰로 두 축을 동시에 감점하지 않는다. 각 관계를 설명할 수 있을 때만 동일 사건을 참조한다. 설정에 근거한 정돈되지 않은 말이나 반복은 예상 persona 특성이며, 그 자체로 일반적인 유창성 기준에 감점하지 않는다.

## 5. 판독 절차·기록안

자료를 한 번의 새 세션에 제시하고 전체 대화를 읽는다. 구체적 관찰을 기록한 뒤 전체 단계에 연결하는 순서를 제안한다. 모든 턴의 긴 설명이나 반드시 오류를 찾는 지시는 두지 않는다. 기능이 있는 재진술과 문제 후보를 검토하되 해당 사건이 없으면 후보 배열은 비운다. 원문/설정의 실제 인용과 참조만 사용한다.

기존 총점·보조축 출력에 다음 보조 기록을 더하는 제안이다.

- `criteria_version`: Realism-R1-draft.
- `observations`: 사건별id,실제 환자 구절,관련 질문·앞선 턴·fact참조,확인된 문제/허용되는 재진술/판단 불확실의 구분,지지되는 기능,표현상의 문제 근거,허용 가능성을 지지하는 문맥,관련 축. 재진술 후보라면 앞선 구절도 남긴다.
- `global_basis`: 전체 단계 판단에 사용한 사건id와 영향 범위의 짧은 최종 설명.4이면 문제 미지적의 범위와 미확인 부분을 기록할 수 있다.
- `global_uncertain`, `boundary_34`: 판정 확실성과3/4 경계의 불확실성. 모델의 확률 보정된 신뢰도로 해석하지 않는다.

JSON 파서·실행 코드에 아직 연결하지 않는다. 현재 단계는 기준 설계이며 새 판독 예시·점수·환자 발화는 만들지 않는다.

## 6. 바꾸지 않는 것과 검증 필요

환자 프롬프트, 기존 원문/점수, 기존 기준 파일/파서, 최종12사례와720계획, 모델 패널과 집계는 그대로다. 이 개정안의 채택·최종 주지표 변경은 아직 하지 않았다. 예전 자료를 사후에 새 기준으로 다시 읽어 원점수를 바꾸지 않는다.

향후 별도 개발 자료로 원 기준/개정안의 동일 모델 반복성, 필요한 재진술의 오탐, 분명한 반복/역할 실패의 누락, 구분력과 천장효과를 함께 확인해야 한다. 점수가 높아지거나 α만 높아지는 것을 성공으로 정하지 않는다. 이번에는 그 평정을 실행하지 않는다.
