# M17 · 평가 기준 개정 설계

**환자 프롬프트를 유지하고 평가 기준 개정 제안을 만들었다. 새 평정은0회다.** 기존 Realism을 참고하되 범위를 명시한 **CCF-R1: 맥락 기반 환자 의사소통 적합성** 후보이며,현재 주지표·운영 기준은 교체하지 않았다. 임상 타당성이나 반복 일관성 향상을 확보했다고 주장하지 않는다.

- 읽기용 최종 개정안: `proposal.md`
- 평가자에게 제시할 정확한 문안: `evaluator-instructions-proposal.txt`

- Astra/Claude 실제 비평과 반영: `decision.md`, `astra-round01.md`, `astra-round02.md`, `claude-round01/response.txt`, `claude-round02/response.txt`
- 전달한 반론: `codex-response-round01.md`
- 기존/초안 비교와 보존: `change-map-draft-v01.md`, `rubric-draft-v01.md`, `evaluator-instructions-draft-v02.txt`, `post-review-diff.patch`

- 실제 문헌 원본/텍스트/지침 이미지: `sources/`, `text/`, `qa/abc2023-p24.png`
- 동결 입력·CLI 설정·범위 보존: `scope-freeze.json`, `request-freeze.json`, `round02-freeze.json`, `verification.json`
