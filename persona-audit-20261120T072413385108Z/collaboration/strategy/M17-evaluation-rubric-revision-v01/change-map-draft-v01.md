# 기존 기준과 개정 초안의 차이

이 비교는 설계 변경의 설명이며 점수 재판정이 아니다.

- **재진술 허용:** 기존은 ‘짧은 재확인’과 ‘요청된 설명’ 허용이 서로 다른 축에 흩어져 있었다. 초안은 현재 질문·대화 목적에서 정보 재지칭이 수행하는 기능을 먼저 확인하고 짧음/새로움 자체를 조건으로 쓰지 않는다. S1의 맥락적 반복 구분을 저자가 환자 면담에 확장한 것이다.
- **표현 반복의 문제:** 기존은 ‘국소 정형 반복’이라는 이름만으로 적용할 여지가 컸다. 초안은 앞선 구절·현재 구절·현재 질문과 기능만으로 설명되지 않는 부적절한 관계를 지목하게 한다. 문구 일치/길이/정돈됨을 독립 감점 근거로 삼지 않는다.
- **전체3/4:** 기존4점의 절대적 완벽함과3점의 경미한 어색함 사이를 관찰 가능한 국소 문제의 지목 여부로 좁힌다. 이는 원 앵커에 대한 저자 수정이며 단순 번역/해석 정리라고 주장하지 않는다.
- **고정관념 방지:** 기존은 당사자표현축에 있던 제한을 전체 판단에도 적용한다. 설정에 없는 감정·망설임을 필수로 기대하지 않고 실제 명시된 의사소통 특성은 평가에 사용한다.
- **전체와 보조축:** 합산 공식은 추가하지 않는다. 같은 관찰을 공동 사건으로 연결하고 전체 감점의 근거가 알려진 축 밖에 있으면 공개한다. 전축2/총점3을 기계적 오류로 지우지는 않는다.
- **불확실성:** 기존은 축별 uncertain 중심이었다. 초안은 전체 판단의 불확실성과3/4 경계를 별도 표시하는 안을 추가한다. 무근거한 점수 확신을 줄이려는 목적이며 불확실 평정의 사후 배제나 임의 중간점 부여는 하지 않는다.
- **절차:** 기존 전체 점수 먼저에서 구체 관찰을 기록한 뒤 전체 단계에 연결하는 안으로 바꾼다. 근거 연결이 내부 사고의 진실성이나 채점 개선을 보증하지는 않으며 새 순서의 편향도 향후 검증 대상이다.
- **유지:**1–4형식·네0/1/2보조축·기존 개발 평균과 최종 계획, 환자 프롬프트, 원점수·기준 파일/파서는 유지한다. 개정안은 별도 설계 파일이며 운영 적용 전이다.
