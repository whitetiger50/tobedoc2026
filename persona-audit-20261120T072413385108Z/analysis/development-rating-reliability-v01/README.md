# 평가 신뢰도 우선: 기존 반복 평정의 통계 재분석

2026-11-19 KST. 사용자가 B 비교보다 평가 방식·평가 결과의 일관성을 먼저 수치화해야 한다고 지적해 우선순위를 정정했다. **프롬프트 성능 비교를 재개하기 전에 평가 시스템의 반복성·평가자 간 일치·합산 점수의 재현성을 확인하는 것이 우선이다.** B 원형 감사는 병행 가능한 문서 작업이며 이 측정 단계를 대신하지 않는다.

앞선 M10은 ‘같은3사례의 버전 경쟁을 종료하는 결정에는 추가 평정이 필요하지 않다’는 판단이었다. 이를 ‘이후 개발을 위해서도 신뢰도 검증을 우선할 필요가 없다’고 확대해 B 감사부터 제시한 것은 잘못된 우선순위였다. 이 문서는 과거의 응답·점수·멘토 결정을 덮어쓰지 않는 후속 정정이다. 사용자의 지적에 따라 Codex가 수행한 통계 재분석이며 새 Astra/Claude 합의를 받았다고 주장하지 않는다.

## 실제 계산

M5의 **원본6대화·3합성프로필·각 모델3회** 원평정을 사용했다. 가족 지칭을 바꾼3개 파생 대조는 자연 대화의 신뢰도를 인위적으로 높일 수 있어 주 분석에서 제외했다. 원본/대조가 같은9항목 묶음에 제시됐다는 맥락은 그대로 남는다. 반복 평정 쌍18개는 독립 표본18개가 아니다.

- Claude 단순 반복쌍 일치율12/18=66.7%, 같은원문의 세평정이 모두 같은 대화3/6.
- Claude **ordinal Krippendorff’s α = 0.089286**.
- Claude **ICC(A,1) = 0.166667**, **ICC(A,3) = 0.375000**. A는 절대일치,1은 한 회차의 측정,k=3은 세 회차 평균이다. 두 방향의 ANOVA 계산에 관측 회차를 열로 둔 탐색 값이다.
- Claude의 대화 내 합동 표준편차는 **0.408248점**이다. 대화별 반복 평균에서의 제곱편차를6×(3−1)의 자유도로 나눈 분산의 제곱근이다. 모집단의 SEM이나 최소검출차이로 정한 값은 아니다.
- GPT 단순 일치율은100%이지만 원평정18개가 전부4여서 ordinal α와 이 자료의 ICC는 **정의되지 않는다**. 이를1이나 신뢰도 검증 통과로 바꾸지 않는다.
- 개발에서 사용하는 두 모델의 산술평균을 회차별로 만든6×3행렬도 계산했다. **ICC(A,1)=0.166667**, 대화 내 합동 SD는 **0.204124점**이다. GPT가 상수4이므로 이 행렬은 `2 + Claude/2`다. 절대 변동과 대화 간 차이를 함께 축소하므로 상대적인 신뢰도 비율 ICC는 같게 남는다. α도 같은 순서·범주 빈도를 유지해0.089286이다. 이 결과는 독립된 추가 증거가 아닌 같은 자료의 변환이다.

반복 회차쌍의 Claude 선형 가중κ는1–2회0,1–3회0,2–3회1/3이었다. 상수 또는 최고점에 몰린 주변분포 때문에 단순 일치율과 우연일치 보정 지표의 값이 다를 수 있다. 수치 하나로 통과/실패를 판정하거나 κ와α를 같은 계수로 취급하지 않는다.

M8의 같은18대화에 대한 두 모델의 평가자 간 선형 가중κ는0, 절대일치형 ICC(A,1)는0이었다. GPT모두4/Claude모두3으로 대화 간 점수 차이가 없어서 일관성형 ICC(C,1)는0/0으로 정의되지 않는다. 이 역시 동일한3프로필의 단회 관측이다. 계수는 현재 점수 분포의 특성을 보여주며, 다른 자료에서도 같은 결과라는 뜻은 아니다.

## 해석의 범위

1. 점추정은 계산할 수 있다. 다만 원본6개·독립 프로필3개이고 점수3/4집중·묶음 대비·회차 변화가 있어 안정적인 일반화와 정밀한95%신뢰구간이 확보된 자료는 아니다. ‘작으니 계수를 계산할 수 없다’와 ‘계수의 불확실성이 크다’는 다르다.
2. α는 순서척도 거리를 사용했다. ICC는1~4점을 등간으로 다루는 추가 가정이 있어 **보조적 민감도 분석**으로 보고한다. 평균 점수의 재현성 평가에는 이 가정을 명시해야 한다.
3. 현재ICC/α가 작다는 사실만으로 어떤 모델이 임상적으로 틀렸다고 하거나 평가 시스템 전체의 보편적 신뢰도가 이 값이라고 하지 않는다. 대화 간 변동이 작은 사용 구간에서 상대적 신뢰도가 낮게 나올 수 있다. 그래서 원평정 분포·절대 불일치·대화 내SD와 함께 읽는다.
4. 평가자 평균은 자동으로 신뢰도를 확보하지 않는다. 두 모델의 오차/기준이 다르고 GPT가 상수인 이번 자료처럼 신호와 변동을 함께 줄일 수도 있다.
5. 반복성을 높이거나 다른 값을 쓰게 만드는 것만으로 임상 현실성을 제대로 측정하는지가 확인되지는 않는다. 설정 불일치 대조의 반응과 현실성의 외부 타당성은 별도로 남는다.

## 다음 단계: 평가 신뢰도 검증 설계가 우선

**추가 모델 호출을 실행한 계획이 아니라, 다음에 구체화할 평가 검증의 조건이다.** 최종720계획과 미사용12프로필은 그대로 보호한다. 프롬프트 생성 모델·환자 모듈을 이 단계에서 바꾸지 않는다.

1. **평가 대상과 운용 단위를 고정한다.** 자연 면담 총점인지 스트레스 질문 포함 총점인지, 한 대화/세션인지 고정 묶음인지, 앵커·근거 요청·이력·순서·모델·추론 설정을 명시한다. 단독 제시로 바꾼 실험이 기존18개 묶음 방식의 신뢰도를 검증한 것이라고 하지 않는다.
2. **고정 텍스트×평가 모델×반복 회차를 교차시킨다.** 반복할 때 환자 발화를 재생성하지 않는다. 조건명·버전·기존 점수는 숨긴다. 같은 원문에서 생기는 판독 변동과 다른 원문 생성 변동을 분리할 수 있게 한다. 사용자가 정한 개발 판독자2개와 평균 방식을 유지한다.
3. **신뢰도 평가용 사례를 보호한다.** 기존3프로필 조건부 결과와 더 다양한 프로필에 대한 일반화는 다르다. 최종12프로필을 소모하지 않고, 별도 개발/검증 분할을 계획한다. 기준을 고치는 데 쓴 텍스트로 같은 기준의 최종 신뢰도를 주장하지 않는다.
4. **자연 대화와 조작 대조를 층화한다.** 큰 오류가 있는 파생본을 섞어 점수 범위가 넓어지면 ICC가 좋아 보일 수 있다. 목표인 자연 대화 구간의 신뢰도와 대조 반응을 따로 보고한다. 층별 주변분포와 퇴화 여부도 남긴다.
5. **사전 분석 지표를 고정한다.** 모델별 반복성은 ordinal α·회차쌍 가중κ·단순 일치율·절대 불일치를 함께 보고한다. 모델 간 절대일치와 운영상 두모델 평균의 반복 재현성도 별도로 계산한다. ICC를 쓰면 모형·단회/평균·절대일치/일관성과 등간 가정을 명시한다. 모든 계수가 필요한 경우와 식별되지 않는 경우를 사전에 정하고 높은 것만 골라 쓰지 않는다.
6. **정밀도를 설계한다.** 신뢰구간은 프로필 내 여러 대화와 반복 평정을 독립으로 세지 않는 모형/재표집으로 산출한다. 더 많은 독립 프로필과 반복에 대한 표본 수는 목표 신뢰구간 폭, 실제 비교에서 판별하려는 차이, 상수 점수 위험을 고려해 정한다. 현재3군집만으로 얻는 불안정한 구간을 정밀한 추정처럼 제시하지 않는다.
7. **진행 판단을 사전에 정한다.** 관측 순위가 반복 조건에서 유지되는지, 운영 평균의 변동이 의도한 비교에 충분히 작은지, 해당 구간에서 판독자가 실제 차이를 구별하는지를 함께 판단한다. ICC>0.75 같은 관행값 하나나 p값만으로 자동 통과시키지 않는다. 목표 차이/허용 정밀도는 결과를 본 뒤 정하지 않는다. 계수가 퇴화하거나 구간이 넓으면 평가 기준/운용의 개정을 검토하고 별도 검증 자료로 재확인한다.

이 과정 뒤에 B/T 성능 비교를 재개할지 판단한다. B 출처·정보 대등성 감사는 병행할 수 있지만 순위 비교의 측정 전제를 대체하지 않는다. 720회 전체 판독을 지금 자동 실행하거나 특정 소규모 새 평정 수를 승인받은 것으로 취급하지 않는다. 이번 두모델 평균의 신뢰도를 최종 세모델 중앙값 집계의 신뢰도 대신 쓰지 않는다.

## 계산·검증·출처

`reliability.py`는 Python 표준 라이브러리만 사용한다. 원 점수의 SHA-256과 계수·평균제곱·정의되지 않은 분모는 `results.json`에 남겼다. 원저자의 이진 worked example(α=2/21), 변동 있는 완전 일치·상수 퇴화·일정한+1평가자 편향의 분석적 ICC·가중κ fixture로 검증했다. 새 패키지·새 모델·유료API·새 수치평정은 없다.

- Ordinal α의 우연 불일치와 순서거리: [Krippendorff 원저자 계산 자료](https://www.asc.upenn.edu/sites/default/files/2021-03/Computing%20Krippendorff%27s%20Alpha-Reliability.pdf).
- ICC의 모형·절대일치/일관성·단회/평균 선택: [Koo와 Li](https://pmc.ncbi.nlm.nih.gov/articles/PMC4913118/), [Table3 정정](https://pmc.ncbi.nlm.nih.gov/articles/PMC5731844/).
- 선형 가중κ 거리 정의 확인: [statsmodels 공식 문서](https://www.statsmodels.org/stable/generated/statsmodels.stats.inter_rater.cohens_kappa.html). 라이브러리를 새로 설치하거나 호출한 것은 아니다.
