# MindCraft 중간보고서와 DAIS-C 주석 예측 파일럿

[중간보고서](MindCraft-interim-report.pptx) · [분석 노트북](DAIS-C-annotation-pilot.ipynb)

화자 단위 교차검증으로 조현병군과 비교군 28명의 발화 1,378행에서 DAIS-C의 네 언어 주석 중 하나 이상이 붙은 행(428개)을 예측했다. 저장된 AUROC는 0.7453이다. 노트북은 셀 출력을 비워 공개하고 입력 자료는 [UK Data Service 공식 배포본](https://reshare.ukdataservice.ac.uk/855021/)에서 별도로 받는다. 영어 첫 응답 비교의 임상군 14명 및 가상 12턴 면담과는 별개의 분석이다.
